---

## 이 조사의 계율

```
읽기만 한다. 배포하지 않는다. 코드를 고치지 않는다.
「무엇이 있는가」만 가져온다.
```

**「배포까지」는 시저님 지시이지만, 배포는 이 조사 다음이다.**
무엇이 있는지 모르는 채로 배포하면 반쪽이 나간다.

---

```
[뭉클이 — 사주·손금 배포 현황 조사]

■ 누가 말하는가
  안토니우스(설계). 시저님이 오늘 사주·손금을 배포까지 하자고 하셨다.

■ 순서
  그래프 2차 시험(graph/03)이 끝난 뒤에 한다.

■ 성격
  조사다. 배포가 아니다. 읽기만 해라. 아무것도 고치지 마라.

■ 안토니우스가 이미 잰 것 — 다시 하지 마라
  · saengui 4엔진 시험 4/4 통과 (저장소에서 직접 돌렸다)
  · CV 코드 0건 · saju_engine 저장소에 없음
  이 넷은 확인됐다. 아래만 답해라.

■ 답할 것 — 다섯

  1) saju_engine 이 어디에 있나
     VPS 인가 PC 인가. 정확한 경로.
     · 있으면 → 무엇을 입력받고 무엇을 내놓나 (함수 이름과 인자)
     · 대운 산출이 되나 (ROADMAP 의 「대운 어댑터」 전제다)
     · 시험이 있나. 돌아가나
     없으면 "없다"고 써라.

  2) 십성 정정이 원본에 반영됐나
     ROADMAP 4장: 「십성 정정을 원본 문서·뭉클이 메모리에 반영 — 미반영」
     · 원본 문서가 어디에 있고 지금 옛 표인가 새 표인가
     · 네 기억에는 어느 쪽이 들어 있나
     ★ 안 하면 옛 표가 계속 돈다. 이건 조용히 틀리는 종류다

  3) 화면(UI)이 있나
     사용자가 생년월일시를 넣고 결과를 보는 화면이 어디든 있나.
     웹인가 · 스트림릿인가 · 챗봇 안인가 · 없는가.
     경로와 함께. **없으면 "없다"고 써라. 만들지 마라**

  4) 지금 이 상태로 사람이 쓸 수 있나 — 사주만
     생년월일시를 넣으면 결과가 나오는 데까지 **실제로 한 번 돌려봐라.**
     · 되면 → 어떤 명령으로 어떻게 돌렸는지, 출력 앞 10줄
     · 안 되면 → 어디서 막혔는지 오류 원문
     ※ 시저님 명식은 쓰지 마라. 아무 날짜나 골라라
       (예: 1990-01-01 12:00) — 개인정보를 시험에 쓰지 않는다

  5) 손금 — 사진 없이 갈 길이 있나
     지금 CV 가 없다. 그런데 두 갈래가 있다:
       ⓐ CV 를 만든다        (오늘 못 한다. 데이터도 검증법도 없다)
       ⓑ 사용자가 자기 손금을 직접 고른다 (사진 없이 밴드를 사람이 입력)
     ⓑ 로 갈 때 `PalmFeatures` 를 사람이 채울 수 있는가.
     밴드 값들이 일반인이 고를 수 있는 말인가, 측정기가 내야 하는 값인가.
     **판단만 적어라. 만들지 마라.**

■ 보고 형식
  1~5 번호 그대로. 경로와 명령·출력을 함께.
  확인 못 한 것은 "확인 못 함". 추정을 확인처럼 쓰지 마라.

■ 하지 말 것
  · 배포하지 마라
  · UI 를 만들지 마라
  · CV 를 만들지 마라
  · 십성 표를 지금 고치지 마라 (2번은 「어느 쪽인가」만 답한다)
  · 시저님 개인 명식을 시험에 쓰지 마라

■ 막히면
  "제 권한 밖입니다"라고 써라.
```

## 조사 결과로 갈리는 길

| 4번 결과 | 오늘 할 수 있는 것 |
|---|---|
| 사주가 돈다 · UI 있음 | **사주만 먼저 배포한다** |
| 사주가 돈다 · UI 없음 | UI 를 만든다 (반나절). 그다음 배포 |
| 사주가 안 돈다 | 왜 안 되는지부터. **배포는 오늘이 아니다** |

| 5번 결과 | 손금 |
|---|---|
| ⓑ 가 된다 | **사진 없는 판**으로 먼저 낸다. CV 는 나중에 얹는다 |
| ⓑ 도 안 된다 | 손금은 CV 가 설 때까지 **미룬다** |

**급하게 만든 CV 는 최악이다.**
그럴듯한 숫자를 내면 우리가 만든 품질 게이트를 **통과해 버린다.**
막으려고 만든 문이 가짜 값을 통과시키면, 문이 없느니만 못하다.
