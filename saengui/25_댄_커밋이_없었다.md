# 댄 커밋이 없었다 — E-36 이 방향만 바꿔 돌아왔다

2026-09-14 · 안토니우스

## 먼저, 붙은 것은 붙었다

뭉클이가 조합 경로를 서비스에 붙였다. 게이트 넷이 전부 섰다.

| 게이트 | 본 것 | 결과 |
|---|---|---|
| ㈀ 조합이 불리나 | 4 몽(艮/坎) `path: 조합` | 통과 |
| ㈁ 폴백이 사나 | 2 곤위지 `path: 컨텍스트` | 통과 |
| ㈂ 전수 대조 | 240판 조합 200 / 컨텍스트 40, trigrams 어긋남 0 | 통과 |
| ㈃ 전/후 대조 | A 30 리→4 몽 · B 2 곤→2 곤 불변 | 통과 |

**여덟 번째 「만들어 뒀는데 부르는 것이 있는가」가 닫혔다.**
4 몽이 증거다 — 컨텍스트 12종 밖이라 **다른 길로는 나올 수 없는 괘**이기 때문이다.
그리고 조합 200 은 어제 예측한 200 과 같은 수다.

## 뭉클이가 스스로 찾은 결함 둘

**① 삽입 스크립트가 데이터 구조를 날렸다.** `{"hexagrams": …}` 만 써서
`meta`·`trigrams`·`matching_rules` 가 통째로 사라졌고, 오늘 해석기가 `KeyError` 로
**죽으며** 드러났다. 뭉클이 말:

> 「에러 0건은 옳다가 아니다」의 제 판이었습니다 — 죽어줘서 발견한 것입니다.

맞는 말이다. 그런데 이 문장에는 그늘이 있다.
**죽어줬기 때문에 찾은 것이면, 안 죽는 다음 판은 못 찾는다.**
어제 넣은 41괘는 하루 동안 `matching_rules` 없이 있었다.
그러니 삽입 스크립트 안에 **키 개수 대조**가 들어가야 한다 — 사람이 보기 전에 걸리도록.

**② 옛 괘 서사가 남았다.** 괘 번호는 4 몽으로 바뀌었는데 `narrative` 는 30 리 이야기였다.
입력(명식)은 그대로인데 **규칙이 바뀌었다.** 캐시는 「입력이 같으면 같다」를 믿는데
이번엔 그 믿음이 깨진 것이다. 손금에서 캐시 키 접두사를 가른 것과 같은 자리다.

## 8870 — 금칙이 하루 만에 지켜지는 것을 봤다

> 8870은 지금 떠 있지 않습니다. 포트 리스너 없음·HTTP 000 …
> 재시작은 하지 않았습니다 — 기동 여부는 시저님 자리입니다.

어제 E-494 로 「감시견 밖이니 재시작이 필요하면 멈추고 보고한다」를 박았다.
**오늘 그대로 섰다.** 꺼져 있는 것 자체는 고장이 아니다 — 원래 수동 기동 서비스다.

## 그런데 댄 커밋이 없었다

뭉클이는 `saengui/24_붙였다_이중_경로.md` 를 커밋 `5b6b18d` 로 남겼다고 했다.
쳐봤다.

```
$ git fetch origin
$ git cat-file -t 5b6b18d
fatal: Not a valid object name 5b6b18d
$ git ls-tree --name-only origin/main saengui/24_붙였다_이중_경로.md
(없음)
$ git ls-remote --heads origin | grep main
4141629…  refs/heads/main      ← 내 마지막 커밋 그대로
```

`saju_interpreter.py`·`iching_data.json` 은 **원래 이 저장소에 없다**(VPS 전용).
그러니 코드가 안 올라온 것은 정상이다.
**어긋난 것은 저장소 경로인 `saengui/24` 하나다.**

### 이것이 E-36 이다 — 방향만 반대다

E-36: 2026-09-09, **내 25 커밋이 브랜치에만 있는 채로** 뭉클이에게 경로를 적어 보냈다.
푸시도 성공했고 뭉클이의 읽기도 성공했는데 **둘이 만난 적이 없었다.**

오늘: **뭉클이의 커밋이 VPS 에만 있는 채로** 나에게 sha 가 왔다.
뭉클이의 커밋도 성공했고 내 fetch 도 성공했는데 **둘이 만난 적이 없다.**

> 양 끝이 각자 성공하면 그 사이가 끊겨도 조용하다.

같은 문장이 반대로 한 번 더 맞았다.

## 그래서 규율을 한 줄 더한다

E-36 뒤에 세운 규율은 **「가리키기 전에 `git ls-tree origin/main <경로>` 를 친다」**였다.
그것은 **내가 가리킬 때**만 걸린다. **받는 쪽 규율이 없었다.**

**남이 댄 커밋·경로는 `git cat-file -t <sha>` 로 먼저 친다.
안 나오면 「없다」이지 「내가 늦게 봤다」가 아니다.**

이것도 「안 쳐보고 모른다」와 「쳐봤는데 없다」를 가르는 자리다.
