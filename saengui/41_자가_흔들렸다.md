# 자가 흔들렸다 — σ_안이 6배 커지자 판정이 뒤집혔다

**2026-09-23 · 뭉클이 블록 #20 집행 보고 분석 · 안토니우스 · 원장 E-825~E-833**

---

## 1. ★★★★★ 같은 사람을 다시 재니 σ 가 6배가 됐다

```
어제 3회 (1955 남)   A = 0.41  / 0.47  / 0.47     σ_안 = 0.035
오늘 3회 (같은 사람)  A = 0.294 / 0.059 / 0.471    σ_안 = 0.207   ← 6.0배
```

**같은 사람, 같은 설정, 다른 날이다.**

### 그래서 E-817 의 「3.7배」가 무너진다

| | σ_안 | σ_밖 | 비 |
|---|---|---|---|
| 어제만 (3회) | 0.035 | 0.102 | **2.9배** (σ_밖이 큼) |
| **6회 합산** | **0.164** | 0.102 | **0.62배 — 뒤집혔다** |
| 빈축 4 를 뺀 5회 | 0.077 | 0.102 | 1.3배 |

> ★★★★★ **어느 셈으로도 3.7배는 없다.**
> **6회를 다 세면 같은 사람 안의 흔들림이 사람 사이의 흔들림보다 크다.**

**E-817 을 회수한다.**

## 2. ★ 어제 내가 적은 경고가 그대로 적중했다

> *「그 3회의 빈축 수가 같았나? **같았다면 σ_안이 작은 것은 당연하다. 아무것도 안 잰 것이다**」* (E-819)

**어제 3회는 빈축 수를 기록조차 안 했다.** 오늘 재니 3·4·3 으로 갈렸고 A 가 흩어졌다.

★ **어제의 작은 σ_안은 「안정」이 아니라 「우연히 고른 3회」였다.**

---

## 3. 🔴 분산을 분해하면 사람 성분이 남지 않는다

각 사람을 **1회씩만** 쟀으므로, σ_밖 안에는 회차 변동이 이미 섞여 있다.

```
σ_밖² = σ_사람² + σ_회차²

σ_회차 = 0.164 (6회)   →  σ_사람² = −0.016   ★ 음수
σ_회차 = 0.077 (빈축3이하) →  σ_사람² = +0.0045 → σ_사람 ≈ 0.067
```

> ★★★★★ **회차 변동만으로 관측된 사람 간 흩어짐이 설명되고도 남는다.**
> **「사람을 본다」의 근거가 지금은 없다.**

★ 다만 **n=3·6 으로 σ 를 재면 σ 자체가 크게 흔들린다.** 오늘 6배가 그 증거다.
**「사람을 안 본다」로 뒤집어 단정하지도 않는다. 지금 말할 수 있는 것은 「모른다」다.**

## 4. 🔴 「빈축이 절반을 설명한다」는 과대 추정일 수 있다

뭉클이 값: **축당 인용률 σ_밖 0.0495** — 원 A 의 σ_밖 0.1017 의 절반.

★ **그런데 `A/(5−빈축)` 은 값 자체가 작아진다. 단위가 달라졌다.**
**σ 를 직접 비교하면 안 되고, 상대 흩어짐(CV = σ/평균)으로 봐야 한다.**

```
빈축 평균 3.0 가정:   CV_원 0.352  vs  CV_축당 0.343   ← 거의 같다
```

그리고 상관: **r = −0.349 → r² = 0.122.**
**빈축은 A 흩어짐의 약 12% 를 설명한다. 절반이 아니다.**

★ **뭉클이가 낸 값 자체는 맞다. 「절반」이라는 읽기가 과대였다.**
**숫자가 절반으로 줄어든 것과 원인의 절반인 것은 다르다.**

## 5. ★★★★★ 그런데 더 큰 것 — 우리 지표는 A 가 아니다

E-793 에서 합격선을 이렇게 바꿨다.

> **지표는 절대값 A 가 아니라 차이 `A − B` 다.**

**그런데 오늘까지 σ_안을 잰 것은 전부 A 다.**

```
A 가 흔들려도  A 와 B 가 같이 움직이면  delta 는 안 흔들릴 수 있다
```

★ 실제로 **11판 delta 가 전부 양수**였고(+0.10~+0.41) **바꿔치기가 한 판도 통과하지 않았다.**
**delta 는 A 보다 안정적일 가능성이 있다.**

> ★★★★★ **재야 할 것은 σ_안(A) 이 아니라 σ_안(delta) 다.**
> **지표를 바꿔 놓고 옛 지표의 흔들림을 재고 있었다.**

**이것이 오늘 제일 큰 것이다.**

## 6. 뭉클이 제안 셋 — 순서를 정한다

> ① 재시도 규칙 넣고 11판 재측정 ② 빈축 3인 7판끼리만 비교 ③ 같은 사람 10회

**③ 이 먼저다. 그리고 ③ 에 delta 를 함께 싣는다.**

| | 왜 |
|---|---|
| **③ 먼저** | **σ_안을 모르면 σ_밖을 해석할 수 없다. 자를 먼저 세운다.** 오늘 6배가 그 이유다. 그리고 한 사람 10회라 싸다 |
| ② 다음 | 빈축을 고정한 사람 간 비교. **7판이면 σ_밖을 다시 낼 수 있다** |
| ① 마지막 | **재시도를 넣으면 기준선이 바뀐다**(E-820). 자가 서고 나서 |

★ **③ 에서 A 10개와 delta 10개를 둘 다 낸다.** §5 가 그 이유다.

## 8. 규칙으로 옮긴다

> **㈀ σ 를 3회로 재면 σ 자체가 흔들린다.**
> **같은 대상을 다시 재서 6배가 나왔다. 흩어짐을 재려면 흩어짐의 자부터 세운다.**

> **㈁ 정규화한 값의 σ 를 원래 σ 와 직접 비교하지 않는다.**
> **단위가 달라졌으면 CV 로 본다. 숫자가 절반이 된 것과 원인의 절반인 것은 다르다.**

> **㈂ 지표를 바꿨으면 흔들림도 새 지표로 잰다.**
> **합격선을 `A−B` 로 바꿔 놓고 σ 는 A 로 재고 있었다.**
