> **원장 E-417 ~ E-424.**

## 0. 먼저 잰 것 — **코드는 이미 멀쩡했다**

ROADMAP 에 적은 대로 **짜기 전에 돌려 봤다.**

```
palm_features.py       28/28 통과   ★ 계약 · 판정 · 프롬프트 · 출력검사가 다 있다
report_composer.py     39/39 통과
weights · relation     48/48 통과
```

> ## ★★★ **「완성」이 아니라 「멈춰 있던 것」이었다.**

## 1. ★★★★★ 그런데 **테스트 다섯이 같은 병을 앓고 있었다**

```
pytest test_palm_features.py
   →  INTERNALERROR … SystemExit: 0
   →  "no tests ran"        ★ 그런데 종료코드 0
```

★ 원인: 파일 **맨 끝 최상위**에 `sys.exit(0 if all(results) else 1)` 이 있다.
pytest 가 import 하는 순간 터져서 **테스트를 하나도 못 모은다.**

> ## ★★★★★ **「0개 통과」와 「28개 통과」가 같은 신호를 낸다.**
> **E-253(깨끗이 죽으면 아무도 울지 않는다)의 정확한 재현이다.**

★★ CI 는 지금 테스트를 안 돌린다(워크플로 둘 다 크롤러용). **그래서 아무도 못 봤다.**
★★★ **언젠가 CI 를 붙이면 조용히 0개가 돈다.** 그 전에 잡았다.

### 고침 — **한 줄 차이다**

```python
if __name__ == "__main__":          # ★ 이 두 줄이 없었다
    sys.exit(0 if all(results) else 1)
```

★ 다섯 파일 전부 고쳤다. **직접 실행은 그대로 되고**(종료코드 0), **pytest 가 안 죽는다.**

`palm_features.py` 첫 줄이 답이었다 —

★★★ **CV 는 하루에 못 만든다.** 자기보고는 **설계가 이미 끝나 있었다**(`saengui/01`, 2026-09-09).

## 3. `self_reported_palm.py` — **지킨 것 넷**

| | |
|---|---|
| ① **그릇을 나눴다** | `PalmFeatures` 를 재사용하지 않는다. 섞으면 **어느 것이 측정이고 어느 것이 자기보고인지 나중에 구분이 안 된다** |
| ② **못 내는 값은 필드가 없다** | `confidence` · `breaks` · `branches` · `Quality` — **0 이나 기본값으로 채우지 않고 아예 없다** |
| ③ ★★★ **캐시 키 접두사를 갈랐다** | 같은 밴드면 측정판과 **같은 키가 나온다** → 캐시가 섞여 **자기보고가 측정 자리로 나온다.** `palm-self:` 로 막았다 |
| ④ **출처를 소리내어 밝힌다** | 프롬프트에 *"본인이 직접 고른 것이며, 측정된 값이 아닙니다"* 가 **반드시** 들어간다 |

### ★★ 그리고 이 판만의 검사 하나

```
끊김 · 갈래를 언급하면 잡는다  ←  ★ 이 판에는 그 값이 「아예 없다」
```

★ 측정판에는 있는 재료라 **LLM 이 흔히 지어낸다.** 없는 재료를 말하는 것은 근거없음이다.

### ★★★ 접근성 — **대체품이 아니라 또 하나의 문**

문답(`QUESTIONS`)을 **소리로 읽어도 되는 문장**으로 썼다.
*"아래 그림에서 고르세요"* 가 아니라 *"손목 가까이까지 길게 내려오나요?"*

> 시저님(더빙 설계 때): *"시각장애인도 돈을 벌고 싶고 경제 상식을 알아야 한다.
> **복지의 틀 안에만 가두면 안 된다.**"*

★★ **ⓑ 는 CV 가 서고 나서도 남는다.**

### 무게는 안 낮췄다

★ 5% 를 3% 로 깎아봐야 읽는 사람은 모른다. *"본인이 고른 것"* 한 줄은 **바로 안다.**
**숫자를 조용히 깎는 것보다 출처를 크게 밝히는 편이 정직하다.**

## 4. ★★★★★ 쓰다가 찾은 것 — **예언은 「단어」가 아니라 「어미」로 온다**

테스트를 쓰다 이 문장이 **안 잡히는 것**을 봤다 —

```
"올해 안에 결혼하시겠습니다."     ←  ★ BANNED_TERMS 를 하나도 안 건드린다
```

★ 목록에 **「결혼할 나이」**는 있는데 **「결혼하시겠습니다」**가 없었다.
★★ **단어를 하나씩 늘려도 같은 구멍이 계속 생긴다 — 말하는 「방식」이 문제이기 때문이다.**

### 고침 — **시점 표지 + 미래 단정 어미가 같이 오면 잡는다**

```
_FUTURE_MARKS    올해 · 내년 · 머지않아 · 곧 · 앞으로 · 장차 · 안에 · 무렵 …
_FUTURE_ENDINGS  하시겠습니다 · 되시겠습니다 · 할 것입니다 · 이루어집니다 …
```

★★★ **어느 한쪽만으로는 안 잡는다.** *"올해도 그러셨겠지요"* 를 잡으면 안 되고,
*"이 자리는 오래 가는 자리로 보이겠습니다"* 도 예언이 아니다.

★★★★ 이것은 `04_읽기의_철학.md` §5 그대로다 —
***"예감은 된다. 예언은 안 된다. `BANNED_TERMS` 는 도덕 규칙이 아니라 제품의 핵심 설계다."***
