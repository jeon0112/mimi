## 2. ★★★★★ 그런데 ㈀-4 가 나머지를 전부 덮는다

```
자기 한눈에 + 자기 본문   35%
남의 한눈에 + 자기 본문   41%   ← 오히려 올라간다
```

**남의 재료를 얹었는데 인용률이 올라갔다.**

이것이 무슨 뜻인지 정확히 적는다.

> **본문이 자기 재료를 쓴다면, 남의 재료로 바꾸면 반드시 내려가야 한다.**
> **안 내려가고 올라갔다 = 본문과 이 사람의 재료 사이에 연결이 아예 없다.**

★★★★★ **그러므로 24.7% 라는 수는 「이 사람 재료를 24.7% 쓴다」는 뜻이 아니다.**
**그 24.7% 중 얼마가 이 사람 것인지 아무도 모른다. 0에 가까울 수도 있다.**

### 🔴 그래서 24.7% 를 「13.9% 에서 나아졌다」로 읽으면 안 된다

**두 수는 분모도 잣대도 다르고, 무엇보다 24.7% 는 바꿔치기를 통과한다.**
**바꿔치기를 통과하는 수는 크기를 비교할 자격이 없다.**

E-707 에 적은 *「안 실렸다가 아니라 **실린 척한다**」* 가 여기서 값으로 확정됐다.

### ★ 그리고 이 실패는 좋은 실패다

**틀려야 할 때 틀렸다.** 음성 대조가 제대로 작동한 것이다(E-235).
만약 바꿔치기가 조용히 「35% → 34%」 였다면 우리는 *「조금 내려갔으니 재료를 쓰긴 쓴다」* 고 읽었을 것이다.
**41% 라는 역방향이 그 오독을 불가능하게 만들었다.**

## 3. ★★★★★ 그러므로 합격선을 바꾼다 — 절대값이 아니라 차이다

지금까지 우리는 인용률을 **하나의 수**로 봤다. 틀렸다.

```
✗  "인용률 40% 를 넘기면 통과"
      → 남의 재료로도 41% 가 나온다. 아무것도 안 잰다

✓  자기 재료로 쓴 글      A%
   남의 재료를 얹은 글    B%
   합격선은  A − B 가 유의하게 양수인가
```

★★★★★ **지금 A − B = −6%p 다. 부호가 반대다.**
**고쳐야 할 것은 A 를 올리는 것이 아니라 부호를 뒤집는 것이다.**

| | 지금 | 목표 |
|---|---|---|
| A (자기 재료) | 35% | — |
| B (남의 재료) | 41% | — |
| **A − B** | **−6%p** | **크게 양수** |

**A 가 30% 라도 B 가 8% 면 그 글은 재료를 쓴 것이다.**
**A 가 60% 라도 B 가 58% 면 그 글은 아무것도 안 쓴 것이다.**

> **이것이 오늘 이 보고가 남긴 제일 큰 것이다.**

## 4. 13%p 차이 — 「한눈에」가 혼자 번다

```
본문만      24.7%
전체 포함   37.6%
차이        12.9%p
```

어제 경고한 것(E-784)이 값으로 확인됐다.

> *「한눈에」에 값을 나열하는 것과 본문 문장이 그 값을 쓰는 것은 다르다.
> 값을 머리에 얹어 놓으면 인용률 측정기는 통과하고 글은 안 변한다.*

★ **「한눈에」는 값을 나열하는 자리이므로 높은 것이 당연하다. 그런데 그것은 글이 아니다.**
**앞으로 인용률은 「본문만」을 정본으로 삼는다.** 전체 포함은 참고로만 적는다.

## 7. 다음 — 순서가 바뀌었다

`compose()` 를 잇는 것이 본 수리인 것은 맞다. **그런데 이으면 끝이 아니다.**

```
1. compose() 를 잇는다            ← 재료가 프롬프트에 들어간다
2. ★ 바꿔치기를 다시 잰다          ← A − B 의 부호를 본다
3. 부호가 양수가 될 때까지 고친다   ← 이것이 진짜 일이다
```

★★★★★ **2번 없이 1번만 하면, 인용률은 오르고 바꿔치기는 여전히 통과할 수 있다.**
**그러면 우리는 「40% 달성」이라고 적고 아무것도 못 고친 채 넘어간다.**

**오늘 41% 가 그것을 미리 가르쳐 줬다.**

> **㈂ 요약 칸이 번 점수를 본문 점수에 섞지 않는다.**
