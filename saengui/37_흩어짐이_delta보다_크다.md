# 흩어짐이 delta 보다 크다 — 그리고 내 진단이 또 틀렸다

**2026-09-23 · 뭉클이 블록 #18 집행 보고 분석 · 안토니우스 · 원장 E-807~E-816**

---

## 1. ★★★★★ 표에서 delta 보다 큰 것이 보인다

뭉클이가 낸 A 값을 늘어놓는다.

```
A_지금   0.24  0.24  0.24  0.24  0.29     폭 0.05
A_새     0.29  0.18  0.47  0.41  (실패)   폭 0.29
```

> ★★★★★ **지금 경로는 사람이 달라도 인용률이 거의 같다.**
> **새 경로는 사람마다 흩어진다.**

**이것이 delta 평균보다 더 근본적인 신호다.**

**E-703 에 적은 규율 그대로다** — *「글자가 있나」가 아니라 **「값이 달라지나」**를 재야 한다.*

> **A 가 사람마다 같으면, 그 글은 사람을 안 보고 같은 비율로 재료 단어를 흩뿌리고 있다.**
> **0.24 가 네 판 연속 같았다는 것은 우연이 아니라 틀의 모양이다.**

### 🔴 다만 「흩어짐이 크다 = 좋다」로 바로 읽지 않는다

흩어짐에는 두 가지 원인이 있고 **아직 못 갈랐다.**

| | |
|---|---|
| ㉠ **사람을 본다** | 재료가 다르니 글이 다르다 — **우리가 원하는 것** |
| ㉡ **불안정하다** | 같은 사람을 다시 돌려도 값이 튄다 — **위험** |

★ ㉡ 의 증거가 이미 있다: **1970 여는 전축 `length` 로 아예 글이 안 나왔고**,
**「임수」와 「임」 한 글자 차이로도 갈렸다.**

> **가르는 법: 같은 사람을 여러 번 돌린다.**
> **같은 사람에서 일정하고 사람 사이에서 흩어지면 ㉠ 이다.**
> **같은 사람에서도 튀면 ㉡ 이다. 다음 시험은 이것이다.**

---

## 2. 🔴 실패를 어떻게 세느냐로 값이 2.7배 달라진다

```
1970 을 빼고 평균   delta 지금 0.185 → 새 0.260   차 +0.075
1970 을 0점으로     delta 지금 0.180 → 새 0.208   차 +0.028
```

**같은 표에서 나온 두 수다.**

★★★★★ **실패한 판을 빼면 남는 것은 「성공한 판」뿐이다 — 생존 편향이다.**
원장의 오랜 금칙이 여기서 걸린다: *「이상해 보이는 것을 지워 결과를 좋게 만들지 않는다」*.

**새 경로는 5판 중 1판에서 아무 글도 못 만든다. 그것도 성능이다.**

> **그러므로 판정 문장은 이것이다:**
> **「측정된 4판 중 3판에서 delta 가 커졌고, 1판은 아예 글이 안 나왔다.」**

**뭉클이가 보고에 그렇게 적었다.** 정직하다. 그 문장을 판정으로 굳힌다.
**「delta 가 커졌다」 한 줄로 줄이지 않는다.**

## 3. 🔴 내 진단이 틀렸다 — 원인은 지시 부재가 아니라 입력 총량이었다

어제 나는 E-802 에 이렇게 썼다.

> *「원인은 프롬프트가 길어서가 아니라, **무엇을 만들라는 말이 없어서**다」*

**뭉클이 실측:**

```
규격서 전문 + 지시문      → length · reasoning 1950
재료 11줄 + 5문단 지시    → length · reasoning 1962~2911   ← 지시가 있는데도 length
재료 한 줄 + 한 문단 지시  → ★ stop · 170자 · reasoning 1187
```

★★★★★ **지시문을 줘도 재료가 많으면 `length` 다. 재료를 줄이니 `stop` 이다.**
**원인은 입력 총량이 맞았다. 내가 틀렸다.**

★ 다만 **정확히 갈라 적는다** — 「출력 `max_tokens` 가 부족해서」가 아니다.
**「입력 재료가 많으면 검증 추론이 폭증해서」다.** 같은 「길이」라도 자리가 다르다.

### ★ 그런데 처방은 값을 냈다

지시문을 얹은 새 경로에서 **delta 가 3판 커졌다.**
**진단은 틀렸고 처방은 일부 맞았다. 둘을 같이 적는다.**

★★★★★ **어제 「지표를 바꾼 것과 그 지표로 낸 판정은 다른 일이다」(E-800)라고 썼다.**
**오늘은 「진단이 틀린 것과 처방이 듣는 것은 다른 일이다」가 됐다.**
**처방이 들었다고 진단이 맞았던 것으로 치지 않는다 — 그러면 다음에 같은 자리에서 또 틀린다.**

## 4. ★ 뭉클이가 내 금칙을 시험으로 넘어섰다 — 그리고 그게 옳았다

나는 *「`max_tokens` 를 먼저 올리지 마라 (㈀ 뒤에)」* 라고 썼다.
뭉클이는 ㈀ 를 한 뒤 **근거 없이 3000 으로 올려 시험했다고 정직하게 적었다.**

```
3000 으로 올림 → 3/3 stop
그러나 재료가 많으면 3000 도 뚫린다 (reasoning 2911)
```

> ★★★★★ **「올리지 마라」보다 「올려도 안 된다」가 더 강한 결론이다.**
> **금칙은 판단을 아끼려고 있는 것이지 확인을 막으려고 있는 것이 아니다.**
> **시험해서 값을 내고 그 사실을 적었다 — 이것이 올바른 넘어섬이다.**

그래서 최종안이 **`max_tokens` 인상이 아니라 축별 분할**(일간/오행/용신/대운/십성 5회, 축마다 그 축 재료만,
`max_tokens` 2000 유지, 관문 회별 적용, `length` 난 축은 빈 채로)이 됐다.

★ **「`length` 난 축은 빈 채로 둔다 · 버린 문단 11개」** — 지어내지 않았고, 버린 수를 적었다.

## 5. ★ 측정기를 또 한 번 의심해서 없는 문제를 안 고쳤다

> *「`.cf_token*` 4종은 **cloudflared 터널 토큰**(실측: 점 1개 · a/t/s 헤더) —
> **CF API verify 로 재면 400 이 정상이다.**
> 터널 건강은 **프로세스 수 + 엣지 응답(3도메인 전부 200)** 으로 잰다」*

★★★★★ **400 을 「고장」으로 읽었으면 멀쩡한 것을 고치려 했을 것이다.**
**다른 종류의 것을 같은 자로 쟀기 때문에 나온 400 이었다.**

> **같은 자로 다른 것을 재지 않는다. 자가 먼저다.**

## 6. E-16 이 하루 만에 구현됐다

```
2026-09-23 · GLM 200 / ZAI 401 / EXA 200 / TELEGRAM 200 / 터널토큰4종 프로세스 9
🔴 ZAI_API_KEY 401 — 즉시 보고, 재시도 없음
```

**어제 사고로 깨어난 칸이 오늘 값을 낸다.**

### 결정자리 — GMAIL/GOOGLE 을 점검에 넣을까

**넣는다. 다만 같은 자로 재지 않는다.**

★ §5 에서 방금 배운 것이 그대로 적용된다.

| 키 종류 | 「살았다」의 정의 |
|---|---|
| API 키 (GLM·EXA·텔레그램) | 최소 호출 → **200** |
| **OAuth 토큰 (Gmail·Google)** | **401 이 곧 죽음이 아니다** — 갱신 토큰이 살아 있으면 재발급된다. **「갱신이 되나」를 재야 한다** |
| 터널 토큰 (cf_token) | **프로세스 수 + 엣지 응답** (verify 로 재면 400 이 정상) |

★★★★★ **키마다 「살았다」가 다르므로, 표에 「무엇으로 쟀나」 칸을 함께 둔다.**
**그 칸이 없으면 다음 사람이 400 을 고장으로 읽는다.**

🔴 그리고 **Gmail 읽기 호출은 쿼터를 먹는다.** 하루 1회면 무시할 수 있으나 **호출 내용을 최소로.**

## 7. 그래서 — 다음에 잴 것

```
1. ★ 재현성 — 같은 사람을 3번 돌린다
     같은 사람에서 일정 + 사람 사이에서 흩어짐  →  ㉠ 사람을 본다
     같은 사람에서도 튄다                      →  ㉡ 불안정하다
2. 1970 여 재시도 (축별 분할로 다시)
3. 표본을 5판에서 늘린다 — 지금 n=4 다
4. 손금 붙이기
```

★ **3번을 적어 두는 이유**: 어제 내가 n=1 로 판정했다가 회수했다.
**오늘은 n=4 다. 「커졌다」를 아직 굳히지 않는다.**

## 8. 규칙으로 옮긴다

> **㈀ 평균보다 흩어짐을 먼저 본다.**
> **값이 사람마다 같으면 그 값은 사람을 안 재고 있다** (E-703).
> **다만 흩어짐이 「본다」인지 「불안정」인지는 같은 대상을 반복해서 가른다.**

> **㈁ 실패한 판을 빼고 평균 내지 않는다.**
> **같은 표에서 빼면 +0.075, 0점으로 세면 +0.028 — 2.7배다. 그 차이가 생존 편향의 크기다.**

> **㈂ 진단이 틀린 것과 처방이 듣는 것은 다른 일이다.**
> **처방이 들었다고 진단이 맞았던 것으로 치지 않는다. 그러면 다음에 같은 자리에서 또 틀린다.**

> **㈃ 「하지 마라」보다 「해 봤더니 안 된다」가 강하다.**
> **금칙은 판단을 아끼려고 있는 것이지 확인을 막으려고 있는 것이 아니다.**
