# 자는 섰는데 물건이 흔들린다 — 10명 중 3명이 빈 글을 받는다

**2026-09-23 · 뭉클이 블록 #21 집행 보고 분석 · 안토니우스 · 원장 E-834~E-841**

---

## 1. 결론은 맞다. 그런데 뜻이 약하다

```
σ_안(A) 0.203 · σ_안(delta) 0.188   →  7.8% 감소뿐
```

**delta 를 역산해 B 를 꺼내 보면 이유가 보인다.**

```
B = 0.059 0.029 0.059 0.059 0.029 0.045 0.000 0.059 0.044 0.000
σ(B) = 0.023   평균 0.038     ← 거의 고정이다
```

★ **B 가 안 움직이니 `delta = A − 상수` 에 가깝다. σ(delta) ≈ σ(A) 가 되는 것이 당연하다.**

**내가 기대한 「A 와 B 가 같이 움직여 delta 가 안정된다」는 일어나지 않았다.**
**delta 로 바꿔도 흔들림은 그대로다.**

---

## 2. ★★★★★ 그리고 진짜 값은 σ 가 아니라 CV 다

```
delta  평균 0.209 · σ 0.188  →  CV = 0.90
A      평균 0.247 · σ 0.203  →  CV = 0.82
```

> ★★★★★ **지표가 자기 평균만큼 흔들린다.**
> **이 수치로는 두 글을 비교할 수 없다. 좋아졌는지 나빠졌는지 잴 수 없다.**

---

## 3. ★★★★★ 그리고 이것이 제품의 문제다

```
10회 중 3회  delta = 0.000     (회차 7 · 8 · 10)
```

**같은 사람, 같은 입력인데 10번 중 3번은 재료를 하나도 안 쓴 글이 나온다.**

| 회차 | 무슨 일 |
|---|---|
| 7 | **A = 0.000, 빈축 3** — 채워진 2축조차 재료를 안 썼다 |
| 8 | **A = 0.059, B = 0.059** — **자기 재료와 남의 재료를 똑같이 썼다** |
| 10 | A = 0.000, 빈축 4 |

> ★★★★★ **손님 10명 중 3명이 「자기 이야기가 아닌 글」을 받는다는 뜻이다.**
> **이것은 측정의 문제가 아니라 제품의 문제다.**

---

## 4. 🔴 누적 σ 가 10회로도 안 멈췄다 — 그런데 더 재는 것이 답이 아니다

```
 3회  σ(A) 0.123
 5회  σ(A) 0.174
10회  σ(A) 0.203     ← 계속 자란다. 미수렴
```

뭉클이가 *「다음부터 같은 사람 반복은 10회가 표준이다」* 라고 적었다.
**10회로도 안 멈췄으니 표준은 아직 못 정한다.**

★★★★★ **그러나 20회·30회로 가지 않는다.**
**더 재면 「얼마나 흔들리는지」를 더 정확히 알 뿐이다. 흔들린다는 사실은 이미 확정이다.**

> **E-383: 틀 → 자 → 도구.**
> **자가 섰으면 다음은 자를 더 가는 것이 아니라 물건을 고치는 것이다.**
> **오늘부터 방향을 바꾼다.**

---

## 5. 흔들림의 원인이 둘이다 — 고칠 곳도 둘이다

| | 증거 | 고칠 것 |
|---|---|---|
| ㉮ **빈축** | r(A, 빈축) = **−0.617** (11판의 −0.349보다 강해졌다). 빈축 4 → A 0.00~0.18 | **재시도 규칙** — 이제 넣는다. 기준선은 확보됐다 |
| ㉯ **채워진 축도 재료를 안 씀** | **7회: 빈축 3인데 A = 0.000.** 빈축 3 안에서도 A 가 0.00~0.47 로 갈린다 | **지시문이 아직 약하다** |

★ **㉯ 는 재시도로 안 고쳐진다.** 축이 채워져도 글이 재료를 안 쓰면 그만이다.

---

## 6. ★★★★★ 그래서 관문을 하나 더 세운다

흔들림을 없애지 못해도 **나쁜 쪽을 내보내지 않을 수는 있다.**

```
오늘 아침 세운 관문   잘렸나        →  잘린 글을 안 내보낸다
오늘 세울 관문        재료를 썼나   →  빈 글을 안 내보낸다
```

**설계 — 운영은 A 로 막고, 검증은 delta 로 한다**

| | |
|---|---|
| **운영 관문** | 생성 뒤 **A 를 잰다. 임계 미만이면 재생성** (최대 N회) |
| 왜 A 인가 | **delta 는 남의 재료로 한 번 더 돌려야 해서 비용이 2배 넘는다.** 매 요청에 못 쓴다 |
| N 회 다 실패하면 | **지어내지 않는다.** 「지금은 해석을 낼 수 없다」로 두고 기록을 남긴다 |
| **기록** | **재생성 횟수를 판마다 남긴다** — 그것이 다음 개선의 재료다 |
| **검증** | delta 는 **표본 검사**로. 주 1회 n판 |

★ **임계값을 지금 정하지 않는다.** 10회 값(A = 0.000~0.588)으로는 근거가 얇다.
**㈁(빈축 3인 7판) 이 끝나고 분포를 보고 정한다.**

🔴 **그리고 관문을 세우면 평균 A 가 오른다 — 그것은 「글이 좋아진 것」이 아니라 「나쁜 판을 버린 것」이다.**
**버린 수를 반드시 같이 적는다**(E-820 과 같은 자리).

---

## 7. 뭉클이가 잘한 것

- ★★★★★ **10회를 끝까지 돌렸다.** 값이 나빠지는 것을 보면서도 멈추지 않았다
- ★★★★ **delta = 0 인 3회를 그대로 뒀다** — *「부호 규율상 「안 쓴 글」로 그대로 둔다」*. **버렸으면 CV 가 예뻐졌을 것이다**
- ★★★★ **빈축 3 안에서도 A 가 갈린다**를 짚었다 — ㉯ 의 근거를 스스로 냈다
- ★★★ **누적 σ 를 3·5·10 으로 내서 미수렴을 보였다** — 내가 시킨 대로였고 그게 방향 전환의 근거가 됐다
- ★★★ 「모른다」 판정을 유지했다

## 8. 규칙으로 옮긴다

> **㈀ σ 를 볼 때 평균을 함께 본다. 지표가 자기 평균만큼 흔들리면 그 지표로는 비교할 수 없다.**
> **CV 가 0.9 면 「좋아졌다」를 말할 자격이 없다.**

> **㈁ 자가 섰으면 자를 더 갈지 말고 물건을 고친다** (E-383).
> **더 재면 「얼마나」를 더 정확히 알 뿐이고, 「흔들린다」는 이미 확정이다.**

> **㈂ 흔들림을 못 없애면 나쁜 쪽을 안 내보내는 관문을 세운다.**
> **그리고 관문이 올린 평균은 「좋아진 것」이 아니다 — 버린 수를 같이 적는다.**
