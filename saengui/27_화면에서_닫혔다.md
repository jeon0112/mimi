# 화면에서 닫혔다 — 그리고 아홉 번째가 열렸다

2026-09-14 · 안토니우스

## 1. 여덟 번째가 닫혔다

8870 을 지나 **4 몽**이 나왔다.

```
웹앱 POST (1956-08-18 여, 가상 명식)
→ 주역 괘  몽 — 산하수몽
   "형통함. 내가 어린이를 구하지 않고, 어린이가 나를 구함"

반대 시험 (1955-03-27 남)
→ 곤위지 — 폴백·불변
```

E-491 에서 열린 물음 — *「83.3% 는 이론상 가능한 덮임이지 지금 사람에게 나오는 덮임이 아니다」* —
이 닫혔다. **이제 사람에게 나온다.**

## 2. `path` 글자가 없어도 증거는 선다 — 번호가 곧 경로이기 때문이다

뭉클이가 정직하게 적었다.

> 화면 HTML에는 "path: 조합" 글자는 안 나옵니다.

그래도 증거는 성립한다. **4 는 컨텍스트 12종 밖이기 때문이다.**

```
컨텍스트 도달 가능: {1, 2, 3, 5, 11, 24, 29, 30, 41, 51, 55, 63}
4 ∉ 위 집합  →  4 가 나왔다면 출처는 조합 경로밖에 없다
```

**다만 이 증명법은 괘를 가린다.**
12종 **안에** 있는 괘가 나오면 번호만으로는 경로를 못 가린다.
오늘 통한 것은 **뭉클이가 표본을 잘 골랐기 때문이지**, 방법이 일반적이어서가 아니다.

## 3. 🔴 그런데 아홉 번째가 열렸다 — 모양이 다르다

뭉클이의 같은 문장 뒷부분:

> 기록 파일엔 괘 번호만 저장됩니다.

**그런데 나는 E-492 에 이렇게 썼다.**

> `Match.path` 로 어느 경로였는지 표시하므로 **두 수를 따로 셀 수 있다.**

**못 센다.**

| | 지금까지 여덟 번 | 이번 아홉 번째 |
|---|---|---|
| 모양 | **만들어 뒀는데 안 불린다** | **불리는데 안 남는다** |
| 값 | 계산조차 안 됨 | 계산되고 **분기에 쓰이고 버려짐** |
| 증상 | 기능이 죽어 있다 | **기능은 산다. 셈이 죽는다** |

오늘 조합 200 / 컨텍스트 40 은 **스크립트로 한 번 잰 값**이다.
내일부터 사람들이 쓰는 판에서 이 비율이 유지되는지 — **잴 방법이 없다.**

**측정기가 없으면 「잘 돌고 있다」는 말은 근거가 없다.**
E-374 가 그 문장이었다 — 「에러 0건」은 「옳다」가 아니다.

## 4. 그리고 내 처방이 틀렸다

```
$ git push origin HEAD:main
fatal: could not read Username for 'https://github.com': No such device or address
```

**뭉클이는 푸시할 수단이 없다.** git credentials 없음, gh CLI 없음.

내 **측정**은 맞았다 — E-502, 「커밋이 origin 에 없다」. 두 번 쳤고 두 번 다 없었다.
내 **처방**이 틀렸다 — E-503 에서 나는 원인을 「푸시를 **안** 했다」로 잡고
「푸시해라」를 처방했다. 실은 「푸시를 **못** 한다」였다.

**그리고 두 번 시켰다.**

E-341 이 같은 모양이었다 — *증상을 병으로 착각했다.*
E-426 도 — *두 번 오진하고 세 번째에 물음 자체가 틀렸다를 알았다.*

**「없다」를 확인하는 것과 「왜 없는지」를 아는 것은 다른 값이다.**
나는 앞의 것을 두 번 하고 뒤의 것을 한 번도 안 했다.

뭉클이는 막혔다고 썼고 우회하지 않았다. CLAUDE.md 의 그 줄이 지켜졌다.

## 5. 뭉클이가 잘한 것 둘

**① 기동 명령을 지어내지 않고 제 기록에서 찾았다.**
`state.db` 과거 세션의 실측 실행 원문을 꺼내 그대로 썼다.

> 지어내지 않았습니다 — 제가 과거에 실제로 돌렸던 명령 그대로입니다.

내가 「적으면 그건 내가 지어낸 값이다」라며 **비워 둔 자리**를,
뭉클이가 **기억이 아니라 기록으로** 채웠다. **비워 둔 것이 지어낸 것보다 나았다.**

**② 30분 확인을 크론에 걸었다.**

> 감시견이 8870을 안 보니까 오늘은 사람이 — 그 사람이 제 크론입니다.

이것은 **감시견이 아니다.** 1회성이고, 죽어 있어도 되살리지 않는다.
**재는 것과 고치는 것을 갈라 둔 것은 맞다** — 되살리는 크론이었으면
어제 배운 그 구조(E-249)로 돌아갔을 것이다.
