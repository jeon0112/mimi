# 계기판 — 무엇을 안 읽는가, 그리고 무엇부터 고치는가

## 1. 표 — 이것이 답이다

**자 검사 100.0%** (같은 입력 두 번). 난수 없음. **자를 믿는다.**

| 재료 | 겹침 | 판정 | 무슨 일이 일어나나 |
|---|---|---|---|
| 일간 | **72.1%** | △ 절반 읽음 | 서사가 갈린다 — **유일하게 읽는 것** |
| 월주 | 90.7% | △ 조금 | 십성 라벨은 읽음 |
| 년주 | 92.9% | ❌ | 십성 라벨만. **조상 자리 의미 없음** |
| 신강신약 | 95.0% | ⚠ **모순** | 라벨만 뒤집히고 서술이 반대로 남는다 |
| 시주 | 95.3% | ❌ | 형충 라벨만. **자식·말년 자리 의미 없음** |
| 오행 수치 | 97.7% | ⚠ 숫자만 | `26%`→`23%`. **판단이 안 갈린다** |
| 현재 대운 | **100.0%** | ❌ | 문장 없음 (아래 §3) |
| 주역 괘 | — | 못 흔듦 | dict 에 없음 (해석 단계 산출) |
| 십성 구성 | — | 못 흔듦 | 해석 중 재계산 |
| 성별 | — | 못 흔듦 | dict 에서 탈락 |

> **여덟 글자 중 서사가 읽는 것은 사실상 하나다.**
> E-46 이 「일간이 같으면 통째로 같다」였는데, **왜 그런지가 이 표다.**

## 2. ★ 제 지시서가 틀렸다 — 유형이 셋이다

`05_흔들어보기.md` 에 이렇게 적었다.

| 전달되나 | 읽나 | 뜻 |
|---|---|---|
| ✅ | ❌ | 받아놓고 안 쓴다 |
| ❌ | ❌ | 아예 안 넘긴다 |

**둘이 아니었다. 셋이다.**

```python
# saju_interpreter.py 241~245  (interpret_daeun)
current_daeun = None
for d in daeon_list:                                  # ← saju['daeun']['current_daeun'] 을 무시하고
    if d["start_age"] <= current_age < d["end_age"]:  #    나이로 재계산한다
        current_daeun = d
        break
```

**값을 받고, 버리고, 다시 만든다.**

| 전달되나 | 읽나 | 뜻 | 흔들기가 |
|---|---|---|---|
| ✅ | ❌ | 받아놓고 안 쓴다 | 닿는다 |
| ❌ | ❌ | 아예 안 넘긴다 | 닿는다 |
| ✅ | **덮어씀** | **받고 버리고 다시 만든다** | ★ **안 닿는다** |

### 그래서 대운의 100% 는 「안 읽는다」의 증거가 아니다

**「제 흔들기가 못 닿았다」의 증거다.** 자가 못 잰 것을 못 읽는다고 읽을 뻔했다.

★ 뭉클이가 `grep` 으로 이걸 잡아냈다. **판정 뒤에 설명이 필요하다**고 했던 그 자리에서
  설명이 판정을 뒤집었다. 순서를 지킨 덕이다.

★ 그리고 결론 자체는 같았다 — 602행부 대운 서술이 **「대운 방향: 순행」과 오행 라벨뿐**이었다.
  **다른 길로 같은 답에 닿았다.** 두 길이 만나면 그 답은 단단하다.

> **덮어쓰는 값은 흔들어도 안 움직인다.**
> 재려면 **재계산의 입력**(나이·`daeon_list`)을 흔들어야 한다. 이건 다음에 잰다.

## 3. ★★ 순서를 겹침이 아니라 **해로움**으로 다시 센다

뭉클이가 매긴 순서는 겹침 큰 순이다. **그게 자연스럽지만, 틀렸다.**

```
겹침이 큰 것 = 밋밋한 글
모순이 있는 것 = 틀린 글
```

**밋밋한 글은 실망시키고, 틀린 글은 웃음거리가 된다.** 무게가 다르다.

### 실제 출력

```
"신강 — 자기 에너지가 부족한 명식"
   ↑ 강하다      ↑ 부족하다
```

**한 문장 안에서 스스로 반대말을 한다.** 사주를 모르는 사람도 이건 안다.

> 시저님이 걱정하신 그 자리다 — *"수많은 사주앱하고 비슷하면 웃음거리만 된다."*
> **비슷한 것보다 나쁘다. 이건 고장 난 것이다.**

### 다시 센 순서

| | 무엇 | 왜 이 자리인가 |
|---|---|---|
| **1** | **신강신약 모순** (95.0) | ★ **지금 틀린 글이 나간다.** 겹침과 무관하다 |
| **2** | **대운** (100.0) | ★ **시간이 없다** — 아래 §4 |
| **3** | 오행 숫자 베끼기 (97.7) | 숫자만 갈리고 판단이 안 갈린다 |
| **4** | 시주 · 년주 자리 의미 (95.3 · 92.9) | 라벨만 있고 **자리의 뜻**이 없다 |
| **5** | 괘 · 십성 · 성별 | **아직 재지도 못했다** |

★ 1번은 **고장**이고 2~4번은 **부족**이다. 고장을 먼저 고친다.

---

## 4. 대운이 2순위인 이유 — 시저님 말씀이 근거다

> *"인생을 진행하면서 만나게 되는 수많은 인연의 학습과 충돌이
>  그를 쇠하게도 성하게도 한다"*
> *"운명은 있으나 환경·인연·시간으로 갈라진다"*

**대운이 그 「시간」이다.**

명식은 태어날 때 정해진 여덟 글자다. **대운은 그것이 십 년마다 다른 바람을 맞는 자리다.**
대운을 안 읽으면 —

```
스무 살에게 하는 말과 쉰 살에게 하는 말이 같아진다
```

**그건 사주가 아니다.** 그냥 성격 설명이다.

★ 그리고 이게 **다른 사주앱과 갈리는 자리**이기도 하다.
  성격 묘사는 어디나 한다. **시간에 따라 말이 달라지는 것**은 흔치 않다.

---

## 5. ★ 아직 안 잰 것 — 이게 진짜 머릿수다

뭉클이가 스스로 밝힌 단서를 그냥 넘기면 안 된다.

> *"이번엔 full_narrative 전체를 잼 — 고정 문장 분리를 안 해
>  수치 체계가 2차와 다르다"*

**밝힌 것은 옳다.** 그런데 이 말이 뜻하는 바가 크다.

```
리포트 = 고정 뼈대 + 명식 따라 바뀌는 살
              ↑
       이게 몇 할인지를 아직 모른다
```

고정 뼈대가 많으면 **모든 겹침이 100% 쪽으로 부풀려진다.**
「97.7%」가 *"변하는 부분의 3%만 변했다"* 인지 *"변할 수 있는 부분은 다 변했는데 뼈대가 눌렀다"* 인지 —
**지금 숫자로는 구분이 안 된다.**

### 그래서 다음에 잴 것

> ## **열 번 흔드는 동안 한 번도 안 바뀐 문장이 몇 할인가.**

이 한 숫자가 **「템플릿 채우기」의 정직한 크기**다.
그리고 이건 새 도구가 필요 없다 — **이미 만든 열 벌의 출력**을 겹치면 나온다.

★ 이 숫자가 나오면 표의 모든 %를 **다시 읽어야 한다.**
  지금 순서(§3)는 상대 순위라 살아남지만, **절대 수치는 아직 못 믿는다.**

---

## 6. 배포는 어떻게 되나

시저님 오늘 일정에 「사주·손금 배포」가 있었다. **1번을 고치기 전에는 배포하지 않는다.**

| | |
|---|---|
| **배포 전 필수** | **1번 모순** — 틀린 글이 나가면 안 된다 |
| 배포 전 권장 | 5번 측정 (고정 문장 비율) — 얼마나 밋밋한지는 알고 내보내야 한다 |
| 배포 후 개선 | 2 · 3 · 4번 |

★ **「비슷하다」는 개선의 문제고 「모순된다」는 배포의 문제다.**
  하나만 고르라면 1번이다. 그것 하나면 오늘 안에 된다.

## 8. 그 뒤 (지금 하지 않음)

| | 조건 |
|---|---|
| 대운 서사 쓰기 | ①② 끝난 뒤. **재계산의 입력을 흔들어** 먼저 다시 재고 |
| 오행 판단 분기 | 점수 구간별로 결론이 갈리게 |
| 시주·년주 자리 의미 | 라벨 말고 **자리의 뜻**을 |
| 괘·십성·성별 재기 | 해석 산출물 쪽에서 흔드는 법을 따로 설계 |
| 배포 | ① 이 끝나고, ② 를 보고 판단 |

★ **계기판은 한 번 쓰고 버리는 것이 아니다.**
  고칠 때마다 같은 표를 다시 만든다. 나아졌는지는 **주장이 아니라 숫자로** 안다.
