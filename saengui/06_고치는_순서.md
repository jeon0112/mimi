## 0. ★ 먼저 — 1판의 1순위는 고장이 아니었다

1판은 이렇게 시작했다.

```
"신강 — 자기 에너지가 부족한 명식"
   ↑ 강하다      ↑ 부족하다
```

**이건 엔진의 모순이 아니었다. 시험 입력이 틀린 것이었다.**

엔진이 쓰는 값은 `신강` / `신약` 인데 흔들기가 넣은 값은 `강` 이었다.
그러자 —

| | 일어난 일 |
|---|---|
| 제목 | `f"신{strength.replace('신','')}"` → `"신"` + `"강"` = **신강** (라벨을 만들어냄) |
| 서술 | `if strength == "신강"` → **거짓** → `else` → 신약 서술 |

정확한 값으로 다시 재니 **두 판의 결론이 반대로 갈린다.**

```
[신약 판]                          [신강 판]
신약 — 자기 에너지가 부족한 명식    신강 — 자기 에너지가 넘치는 명식
받아들이고 채워야 균형이 잡힘       밖으로 쏟아내야 균형이 잡힘
무리하면 고갈된다
```

**겹침 88.4%** (95.0 은 폐기). **신강신약은 읽는다.**

### 그런데 잠재 병은 실재했다 (E-58)

제목 조립이 **임의 문자열을 「신강」으로 위조**한다. `강`·`약`·`엿가락` 무엇이 와도
제목에는 신강/신약이 찍혔다. **제목과 서술이 서로 다른 판정에서 나왔다.**
뭉클이가 한 곳에서 함께 정하도록 고쳤다. 위조 입력 3/3 → 0.

### ★★ 그리고 이것이 오늘의 진짜 교훈이다 (E-57)

> **흔들기가 헛돌았는데, 결과는 오히려 극적이었다.**

엔진은 모르는 값을 받고 **조용히 `else` 로 떨어졌다.** 안 흔든 판이 만들어졌는데
제목만 라벨을 바꿔서 **「모순」이라는 가장 눈에 띄는 모양**으로 나왔다.

**0번 자 검사(같은 입력 두 번 = 100%)가 이걸 못 잡는다.**
재현성은 봤지만 **입력이 엔진이 아는 값인지는 안 봤기 때문이다.**

> 자가 흔들리지 않는다는 것과, 자가 **맞는 자리를 잰다**는 것은 다르다.

**새 규칙 — 흔들 값은 지어내지 않는다. 엔진이 실제로 내놓는 값의 목록에서 고른다.**
이 한 줄을 `05_흔들어보기.md` 0번에 넣는다.

★ 뭉클이가 **스스로 자기 시험을 의심하고 정정했다.** 이건 보고가 아니라 규율이다.

## 2. 유형이 셋이다 (1판에서 그대로 유효)

`05_흔들어보기.md` 는 둘로 적었다. **셋이다.**

```python
# saju_interpreter.py 241~245  (interpret_daeun)
current_daeun = None
for d in daeon_list:                                  # ← saju['daeun']['current_daeun'] 을 무시하고
    if d["start_age"] <= current_age < d["end_age"]:  #    나이로 재계산한다
        current_daeun = d
        break
```

| 전달되나 | 읽나 | 뜻 | 흔들기가 |
|---|---|---|---|
| ✅ | ❌ | 받아놓고 안 쓴다 | 닿는다 |
| ❌ | ❌ | 아예 안 넘긴다 | 닿는다 |
| ✅ | **덮어씀** | **받고 버리고 다시 만든다** | ★ **안 닿는다** |

★ 오늘 **네 번째가 하나 더 붙었다** — §0 의 「엔진이 모르는 값을 줬다」.
  이건 재료 쪽이 아니라 **자 쪽의 고장**이다. 그래서 표에 넣지 않고 0번 규칙으로 넣는다.

> **덮어쓰는 값은 흔들어도 안 움직인다.**
> 재려면 **재계산의 입력**(나이 · `daeon_list`)을 흔들어야 한다.

## 3. ★★ 오늘의 큰 수 — 고정 문장 **53.7%**

기준 판 **41문장 중 22개**가 7번 흔들어도 **한 번도 안 바뀌었다.**

안 바뀐 것 중 가장 긴 셋 (원문 그대로) —

```
1. 용신이 전혀 없다가 처음 들어오는 대운 = 만개기
2. 땅은 만물을 기르되 자기 것을 주장하지 않습니다
3. 지금은 이끄는 것보다 받아들이는 때입니다
```

**이것이 모든 사람이 똑같이 받는 문장이다.**

> 시저님 기준: *"수많은 사주앱하고 비슷하면 웃음거리만 된다."*
> **절반 이상이 공용 문장이면, 그게 사주앱이다.** 이 숫자가 그 기준의 실측치다.

### ★ 그런데 53.7% 도 아직 못 믿는다 — 상한이다

7판 중 **한 판(신강신약)이 §0 으로 헛돌았다.** 헛돈 판은 기준 판과 거의 같은 글이었을 것이고,
**안 흔들린 판이 섞이면 고정 비율은 실제보다 높게 나온다.**

```
53.7%  ←  이 수는 위쪽 끝이다. 진짜 값은 이보다 낮다.
```

**그래서 다시 잰다.** 정확한 값으로 7판을 다시 만들어 같은 자로 센다.
★ 이건 트집이 아니다 — **못 믿는 수로 배포를 결정하지 않는다.**

### 1번과 3번은 같은 뿌리다

`1. 용신이 전혀 없다가 처음 들어오는 대운 = 만개기` — **대운 안내문이다.**
대운이 100%(덮어씀)라서 **대운 자리의 글이 통째로 고정문으로 밀려나 있다.**

뭉클이가 이 구조를 스스로 짚었다. **대운을 고치면 53.7% 가 저절로 내려간다.**

## 4. 다시 센 순서 — 3판

1판의 1순위(모순)가 없어졌으므로 다시 센다.

| | 무엇 | 왜 이 자리인가 |
|---|---|---|
| **1** | **대운 덮어쓰기** (100.0) | ★ **버그다.** 전달된 값을 코드가 버린다. 그리고 §3 의 고정문을 끌고 있다 |
| **2** | **고정 문장 재측정** (53.7 상한) | ★ 1번을 고치면 이 수가 움직인다. **고친 뒤에 재는 것이 옳다** |
| **3** | 오행 숫자 베끼기 (97.7) | 숫자만 갈리고 판단이 안 갈린다 |
| **4** | 시주 · 년주 자리 의미 (95.3 · 92.9) | 라벨만 있고 **자리의 뜻**이 없다 |
| **5** | 괘 · 십성 · 성별 | **아직 재지도 못했다** |

★ **1번이 왜 2번보다 먼저인가** — 순서가 뒤바뀌면 일을 두 번 한다.
  고정문을 손으로 걷어내고 나서 대운을 고치면, 대운이 만든 고정문을 **두 번 세게 된다.**
  **원인을 먼저 고치고 결과를 잰다.**

### 대운이 1순위인 이유 — 시저님 말씀이 근거다

> *"인생을 진행하면서 만나게 되는 수많은 인연의 학습과 충돌이 그를 쇠하게도 성하게도 한다"*
> *"운명은 있으나 환경·인연·시간으로 갈라진다"*

**대운이 그 「시간」이다.** 대운을 안 읽으면 —

```
스무 살에게 하는 말과 쉰 살에게 하는 말이 같아진다
```

**그건 사주가 아니다.** 그냥 성격 설명이다.
그리고 이게 **다른 사주앱과 갈리는 자리**다 — 성격 묘사는 어디나 한다.

제가 드릴 수 있는 것은 숫자이고, 지금 그 숫자는 **못 믿는 상태**입니다(상한).

> **1번(대운)을 고치고, 2번(고정 비율)을 정확한 값으로 다시 재고,

## 3. ② 대운 — 판단이 갈렸다. 그리고 **괘가 따라 움직였다** (E-69)

```
- 현재 대운: 을사 (31~41세)
- 기르는 시간. 주도하지 말고 따르세요. 받아들이는 것이 힘입니다

+ 돌아왔다고 안주하면 다시 내려감
```

**숫자만 갈린 것이 아닙니다.** 오행 97.7%의 함정이 아닙니다. ✅

### ★ 괘가 곤위지 → 복(지뢰복)으로 함께 움직였다

뭉클이는 *"오탐이 아니라 `match_hexagram` 이 대운 해석을 받는 정상 연쇄"* 라고 밝혔습니다.
**맞습니다.** 그리고 밝힌 것이 옳습니다 — 이건 제가 `05` 에 적어둔 **함정 그 자체**입니다.

> *"입력을 흔들면 여러 개가 같이 움직인다"*

| 제품으로서 | 측정으로서 |
|---|---|
| ✅ **옳다.** 대운이 괘로 흘러야 맞다 | ⚠ **77.0% 는 대운 단독의 몫이 아니다** |

**대운 단독 몫은 23%p 보다 작습니다.** 얼마나 작은지는 모릅니다.
★ 이건 흠이 아니라 **읽는 법**입니다. 숫자에 무엇이 섞여 있는지 알고 읽으면 됩니다.

### ★ 그리고 시저님이 봐주셔야 할 자리가 하나 (제 권한 밖입니다)

**두 번 다 뜻이 들어맞습니다.** 우연히 바뀐 것이 아니라 **맞게 바뀐 것으로 보입니다.**

★ 다만 **이 판정은 제가 할 자리가 아닙니다.** 사주·주역의 옳고 그름은 시저님이 보십니다.

## 4. ③ 고정 21.1% — **방향은 믿고 절대값은 못 믿는다** (E-70)

```
②전 : 10/19 = 52.6%
②후 :  4/19 = 21.1%     ← 같은 자로 쟀다
```

**같은 자로 쟀으니 이 하락은 진짜입니다.** 대운 하나를 고쳐 고정문이 **절반 이하**로 떨어졌습니다.
★ 제가 §3에서 *"대운을 고치면 53.7% 가 저절로 내려간다"* 고 쓴 것이 맞았습니다.

### 그런데 분모가 41에서 19로 바뀌었다

뭉클이가 먼저 밝혔습니다 — *"중복·짧은 줄을 정리해 센 결과"* · *"3차 53.7% 와 직접 비교하지 않는다"*.
**밝힌 것은 옳고 비교하지 않은 것도 옳습니다.** 그래도 남는 것이 둘입니다.

| | 왜 걸리는가 |
|---|---|
| **한 문장이 3.7%p** | 19개는 적다. 문장 하나를 다르게 세면 숫자가 크게 흔들린다 |
| **「짧은 줄」을 뺐다** | ★ **고정문은 보통 짧다**(제목·라벨). 짧은 줄을 빼면 고정 비율이 **낮게** 나온다 |

★ 실제로 남은 고정문 중 하나가 **`(10자) 만개기: 임인 대운`** 입니다. **10자는 짧습니다.**
  그럼 「짧다」의 기준이 무엇인지가 정해져 있지 않다는 뜻입니다.

> **자를 바꾸면서 재면, 결과가 자 때문인지 고친 것 때문인지 모른다.**
> ②전/②후가 같은 자였던 덕에 **방향은 건졌습니다.** 절대값은 다음에 못 박고 잽니다.

★ 그리고 41 → 19 면 **절반 이상이 사라졌습니다.** 「중복·짧은 줄」이 22개라는 뜻인데,
  그게 사실이면 **그 자체가 발견**입니다 — 리포트의 절반이 중복이라는 말이니까.

**대운 「값」은 읽는데 대운 「설명문」은 고정입니다.** 그리고 여기 둘이 걸립니다.

### ① 「만개기」가 모든 사람에게 나간다 — ★ 이건 밋밋한 게 아니라 **틀릴 수 있다**

*"용신이 전혀 없다가 처음 들어오는 대운"* 은 **조건문**입니다. 조건이면 참일 때만 나와야 합니다.
일곱 판 전부에 나왔다면 —

```
조건 판정이 없거나,  조건이 항상 참이거나
```

**둘 다 고장입니다.** 모든 사람에게 *"60년간 닫혀 있던 문이 열린다"* 고 말하면
그건 비슷한 글이 아니라 **틀린 글**입니다. E-56 이 시험 버그로 사라졌는데, **여기 진짜가 있을 수 있습니다.**

★ **배포 전에 이것 하나는 확인해야 합니다.** 고장 후보이기 때문입니다.

### ② 「순행」이 고정 — **성별을 못 흔든 것이 여기서 결과로 보인다**

대운의 순행/역행은 **년간 음양 × 성별**로 갈립니다. 사람마다 다릅니다.
그런데 고정이라면 — **성별이 dict 에서 탈락한 것**(§1 표의 「못 흔듦」)이 원인일 수 있습니다.

> ★ **「못 잰 것」이 「고정문」으로 나타났다.** 표의 빈칸과 결과가 만났습니다.
> 못 잰 것은 없는 것이 아니라 **아직 안 보이는 것**이었습니다.

# 4판 — 2026-09-11 저녁. **만개기는 고장이 둘이다**

> 뭉클이 보고. `LEDGER.md` **E-72 ~ E-75**

## 1. ★★ 「만개기」 — 조건이 있는데 **두 군데가 따로 틀렸다** (E-73)

### 고장 ㉠ — 「전혀 없다가」가 코드에 없다

```python
for d in daeon_list:
    d_elements = [d["stem_element"], d["branch_element"]]
    if yongsin_element in d_elements and yongsin_element not in yongsin_elements_seen:
        is_blooming = True; blooming_daeun = d; break
    yongsin_elements_seen.extend(d_elements)
```

이 루프가 찾는 것은 **「용신 오행의 첫 등장」**입니다. 문장이 약속한 것은 **「전혀 없다가 처음 들어오는」**입니다.

**둘은 다릅니다.**

```
문장 :  앞의 대운들에 용신이 하나도 없었다  →  그래서 특별하다
코드 :  용신이 처음 나오는 자리             →  첫 대운이어도 참
```

**첫 대운에서 바로 나오면 `yongsin_elements_seen` 은 아직 비어 있으니 무조건 참입니다.**
그리고 8대운 × 2칸 = 16칸에 오행은 다섯뿐이라 **용신이 한 번도 안 나오기가 더 어렵습니다.**

> **조건이 없는 것이 아니라 조건이 퇴화해 상수가 됐습니다.**

★ 실측이 그것을 보여줍니다 — **`blooming=임인 (1~11세)`**.

```
갓난아기 때가 만개기다.
"60년간 닫혀 있던 문이 열린다" 를 한 살에게 말한다.
```

**밋밋한 것이 아니라 말이 안 됩니다.**

### 고장 ㉡ — ★ 두 판정이 어긋난다

```
is_blooming_period = False          ← 「지금이 만개기인가」 = 아니다
match_hexagram 331~332 :  blooming 인 대운이 목록에 하나라도 있으면 → daeon_context = "만개기"
```

  이건 부작용이 아니라 **진단이 한 겹 내려간 것**입니다.

★★ **그러므로 시저님 답이 있기 전에는 만개기 기능 전체가 미완입니다.**
  지금은 **말을 덜 틀리게** 만들어 놓은 상태이지, 맞게 만든 것이 아닙니다.

## 3. 같은 자의 비교 쌍 — 완성됐습니다 (E-78)

```
②전 (옛 코드 · 대운 무시)  :  14/23 = 60.9%
②후 (현행 · ㉡ 반영)        :   6/23 = 26.1%
```

**같은 자입니다. 이 비교는 성립합니다.** 대운 배선을 고쳐 고정문이 **절반 이상 풀렸습니다.**

### ★ 다만 설명 한 줄은 성립하지 않습니다

뭉클이가 *"21.1% 와 26.1% 의 차이는 ㉡ 수정으로 괘가 풍으로 바뀐 몫"* 이라고 적었습니다.

**이건 말할 수 없습니다.**

```
21.1%  =  옛 자(len>=8 필터, 19문장)  +  ㉡ 고치기 전
26.1%  =  새 자(구조 단위, 23문장)    +  ㉡ 고친 뒤
              ↑ 자가 바뀌었다            ↑ 코드도 바뀌었다
```

**둘이 같이 움직였으니 차이를 어느 쪽 탓으로도 돌릴 수 없습니다.** 오늘 내내 경계한 그 모양입니다.

★ 큰 흠은 아닙니다 — **새 자에서 나온 세 수(60.9 · 26.1 · 13.3)는 전부 유효합니다.**
  **설명 한 줄만 지우면 됩니다.** 숫자는 멀쩡하고 이야기가 하나 덧붙었을 뿐입니다.

> 지어낸 것은 숫자가 아니라 **숫자 사이의 선**입니다.

# 6판 — 2026-09-11. **만개기는 대나무 꽃이다** (시저님 결정)

> `LEDGER.md` **E-80 · E-81**
> 시저님 말씀이 근거입니다. 제가 어떻게 읽었는지 아래에 그대로 펼쳐 확인받습니다.

## 1. 시저님 말씀 — 원문

> *"만개기는 이렇게 형용하면 어떨까? 마치 대운이 대나무의 마디를 형성하며 자라다
>  어느 것은 꺾이고 어느 것은 새로운 상황에 직면해 대나무가 꽃을 피우듯 하는 것이니,
>  꽃은 사람마다 다 달라서 한 번 맺을 수도 두 번 맺을 수도 세 번 맺을 수도 하는 것이
>  우리가 알 수 없는 일이 아닌가?"*

---

## 2. 제가 읽은 것 넷 — **이 중 셋은 코드가 바로 따라갑니다**

### ㈀ **만개기는 하나가 아니다** → `break` 를 뺀다

```python
if yongsin_element in d_elements and yongsin_element not in yongsin_elements_seen:
    is_blooming = True; blooming_daeun = d; break     # ← ★ 이 break
```

> *"한 번 맺을 수도 두 번 맺을 수도 세 번 맺을 수도"*

**`break` 가 꽃을 하나로 잘랐습니다.**
그리고 이 `break` 때문에 만개기가 **8대운 중 하나**가 되어, ㉡ 을 고치자 **거의 아무도 만개기가 아니게** 됐습니다(E-77).

★ **지금까지의 두 고장이 다 이 한 줄에서 나왔습니다.**

```
break 있음 + 목록 판정  →  전원 만개기   (너무 많다)
break 있음 + 현재 판정  →  거의 아무도    (너무 적다)
break 없음 + 현재 판정  →  ★ 사람마다 다르다
```

> **꽃이 여럿이면 사람마다 개수가 다르고 자리가 다릅니다.**
> **같은 문장이 안 나옵니다.** ★ **시저님의 사주관이 곧 밋밋함의 해법입니다.**

### ㈁ **단정하지 않는다** → 어법을 바꾼다

> *"우리가 알 수 없는 일이 아닌가"*

```
지금 :  "60년간 닫혀 있던 문이 열리는 것"        ← 확언한다
        "만개기: 임인 대운"                      ← 못 박는다
```

**언제 몇 번 필지 모른다면 못 박을 수 없습니다.**

★ 다만 **「그러니 아무 말도 하지 말자」로 읽지 않았습니다.** 그건 과한 해석입니다.
  사주는 말하는 일입니다. **말하되 단정하지 않습니다.**

```
「이 마디에 꽃이 맺힐 수 있다」   ≠   「이때 문이 열린다」
```

★★ 그리고 이건 우리가 이미 쓰는 말과 같습니다 —
  **「없는 값은 지어내지 않는다. 비면 비운 채로 둬라.」**
  시저님이 그것을 사주의 말로 하셨습니다.

### ㈂ **꺾임도 마디에 있다** → ★ 아직 못 합니다

> *"어느 것은 꺾이고"*

지금 코드의 만개기는 **좋은 일로만** 쓰입니다. 문이 열린다고만 합니다.
시저님의 대나무는 **마디마다 갈림이 있고 꺾임도 있습니다.**

★ **그런데 「꺾임」의 판정 기준을 안 주셨습니다.** 그러니 지금 만들지 않습니다.
  **지어내면 오늘 고친 것을 도로 무르는 일입니다.** 물음으로 남깁니다(§4).

### ㈃ **「전혀 없다가 처음」이라는 문장은 첫 꽃에만 맞다**

여러 번 필 수 있다면, 두 번째·세 번째 꽃은 **「전혀 없다가」가 아닙니다.**
**문장 자체가 첫 꽃 하나만 설명하는 글이었습니다.**

## 3. 그래서 코드가 할 일 — 셋. 그러나 **순서가 있습니다**

| | 무엇 | 왜 이 자리인가 |
|---|---|---|
| **1** | ★ **판정을 한 곳으로 모은다** (5판 ②의 지도) | ★★ **먼저 모으지 않고 「여럿」으로 바꾸면 세 곳이 각자 다르게 셈한다** |
| **2** | `break` 제거 — 꽃 **목록**을 낸다 | ㈀ |
| **3** | 어법에서 확언을 뺀다 | ㈁ |

★★ **1번이 먼저인 이유가 오늘 세 번 나온 그 병입니다.**
  E-58(제목 vs 서술) · E-73㉡(상태 vs 괘) · E-79(제목 vs 괘) —
  **판정을 여러 곳이 각자 내리고 있습니다.**

```
한 곳으로 모으기 전에 "꽃이 여럿"으로 바꾸면
  → 세 곳이 각자 다른 개수를 센다

```

# 7판 — 2026-09-11. **꽃은 사람이 몰고 온다** (시저님 ④⑤ 답)

> `LEDGER.md` **E-82 · E-83 · E-84**

## 1. ④ 꽃의 조건 — **문장의 주어가 바뀝니다**

> *"꽃은 여러 가지 충·형·십성으로 핀다는 말이 일리가 있구나.
>  인생의 꽃은 **귀인을 만나서** 피는 것이 대부분인데
>  이 **귀인이 이런 것을 몰고 다니지 않은가**?"*

### ★★ 핵심은 뒷문장입니다

**충·형·십성은 지표가 아닙니다. 「사람이 오는 표시」입니다.**

```
충·형    →  부딪히는 일이 온다   →  ★ 사람이 온다
십성     →  ★ 애초에 관계의 이름이다 (정관=윗사람·규범, 정재=재물·배우자, 인성=스승)
```

**귀인이 그것들을 몰고 다닙니다.** 지표가 먼저가 아니라 **사람이 먼저**입니다.

### 그래서 리포트의 말이 달라집니다

```
지금    :  "만개기 — 60년간 닫혀 있던 문이 열린다"     ← 사건이 저절로 온다
시저님  :  "이 마디에 사람이 온다"                      ← ★ 사람을 통해 온다
```

**주어가 다릅니다.** 그리고 읽는 사람이 **할 수 있는 일**이 달라집니다 —
「문이 열리기를 기다린다」와 「사람을 알아본다」는 다른 삶입니다.

### ★ 이것은 시저님이 처음부터 하신 말씀입니다

> *"인생을 진행하면서 만나게 되는 **수많은 인연의 학습과 충돌**이 그를 쇠하게도 성하게도 한다"*

**인연 = 귀인. 충돌 = 충·형.** 같은 말이 두 번 나왔습니다.
★ 저는 그 문장을 「대운이 2순위인 이유」의 근거로만 썼는데, **여기가 진짜 자리였습니다.**

### ★★ 그리고 재료 하나가 되살아납니다

1판 표에서 **십성은 「못 흔듦 — 해석 중 재계산」**이었습니다. 못 재는 재료로 밀어뒀습니다.

> **그 못 재던 것이 이제 꽃의 핵심 재료입니다.**
> 표의 빈칸이 또 한 번 결과로 나타났습니다(E-71 성별에 이어 둘째).

## 2. ⑤ 꺾임 — ★★★ **사주 밖입니다**

> *"꺾임 역시 외부의 상황이다. **내 사주 운명을 넘어** 외부의 세력(전쟁·재난 등)에 의해
>  벌어질 수 있지 않겠나?"*

**이건 「만들지 마라」가 아니라 「만들 수 없는 것」입니다.**

```
사주가 말할 수 있는 것 :  마디 · 꽃이 맺힐 수 있는 자리 · 오는 사람
사주가 말할 수 없는 것 :  ★ 전쟁 · 재난 — 외부의 세력
```

**전쟁은 개인의 명식에 안 들어 있습니다.** 계산할 자리가 없습니다.

### 그럼 리포트에서 빼나 — 아닙니다. **한계를 말합니다**

> **"사주는 당신의 마디를 말합니다. 전쟁과 재난은 마디 밖의 일입니다."**

★★ **이건 품질이 아니라 정직의 문제입니다.**
  사주앱들이 *"올해 큰 재난을 조심하라"* 고 하는 것 —
  그건 **계산할 수 없는 것을 계산한 척하는 것**입니다.

> **「없는 값은 지어내지 않는다. 비면 비운 채로 둬라.」**
> 우리가 크롤러에 쓴 말이 사주에서 그대로 나왔습니다.

★ 그리고 **자기 한계를 말하는 것이 오히려 신뢰의 근거**가 됩니다.
  못 하는 것을 못 한다고 말하는 글은, 한다고 말한 것도 믿게 합니다.

★ 반면 **「귀인」은 시저님이 스스로 꺼내신 말**입니다. **그것이 온전한 근거입니다.**

★★ **`break` 를 빼도 결과가 같다는 것이 증거입니다.** 뭉클이가 실측으로 제 말을 반증했습니다.

### ★ 그런데 제가 왜 틀렸나 — 되짚어 둡니다

시저님이 *"한 번 두 번 세 번 맺을 수도"* 라 하셨고, 제 눈에 `break` 가 보였습니다.
**말과 코드가 딱 맞아떨어져 보였습니다.** 그래서 거기서 멈췄습니다.

> ★ **맞아떨어지는 답이 나오면 거기서 멈추게 됩니다.**
> `break` 를 빼면 몇 개가 되는지 **재보라고 했어야 하는데, 뿌리라고 단정했습니다.**
> 다행히 지시서에 *"열 판을 돌려 꽃 개수 분포를 보여줘라"* 를 넣어뒀고, **그 재기가 저를 고쳤습니다.**

## 3. ★★ 그래서 천을귀인을 쓸 근거가 세졌습니다 (E-102)

| | 꽃이 몇 개 나오나 |
|---|---|
| **「첫 등장」 셈법** | ★ **정의상 최대 1개** — 시저님 말씀을 원리적으로 못 낸다 |
| **천을귀인** | 매 대운을 **독립으로 대조** → 0~3개 (예상 평균 1.3) |

```
「첫 등장」  :  한 번 나오면 그 뒤로는 「처음」이 아니다     →  1을 강제한다
천을귀인    :  이 대운의 지지가 귀인 자리인가 — 매번 따로   →  ★ 여러 번 가능하다
```

> **시저님의 「두 번 세 번」은 「첫 등장」으로는 만들 수 없습니다.**
> **대조여야 합니다.** 천을귀인이 바로 그 모양입니다.

★ E-94 에서 적어둔 예상(16.7% · 평균 1.3)이 **이제 대조 상대를 얻었습니다** — 1.0 vs 1.3 이 아니라
  **「최대 1」 vs 「0~3」** 이라는 구조의 차이입니다.

## 4. ★ ③ 문장 후보 — 하나에 **지어낸 숫자**가 있습니다 (E-103)

```
후보 1 :  이 대운이 만개기입니다. 60년에 한 번 열리는 자리입니다
                                  ↑ ★ 이 수의 근거가 없다
```

**「만개기입니다」는 단정해도 됩니다** — 계산된 것이니까(E-86 ①층).
**「60년에 한 번」은 계산 밖입니다.** 60갑자에서 온 수사(修辭)이고,
**이 조건이 60년 주기로 온다는 근거가 아무 데도 없습니다.** 8대운이면 80년이고 그 안에 한 번입니다.

> ★ **「계산된 것은 단정한다」는 계산된 것에만 해당합니다.**
> 단정할 자격이 없는 말을 단정하면, 그건 제가 E-86 에서 고친 것의 **반대편 낭떠러지**입니다.

**뺍니다.** 후보 1 은 *"이 대운이 만개기입니다"* 까지입니다.

★ 그리고 후보 2 의 *"그 문으로 누가 들어올지는…"* 이 후보 1 의 「문」을 받는데,
  후보 1 에서 「문」이 빠지면 연결이 끊깁니다. **후보 2 도 함께 다듬어야 합니다.**

## 5. ★★★ 고정 19.0% — **내려간 방향이 잘못됐습니다** (E-104)

```
고정 4/21 = 19.0%      ← 분모가 23 → 21 로 줄었다
「없다」 문장 (판정) : 0개
```

★ **분모가 준 이유가 중요합니다** — **기준판이 만개기가 아니라서 만개기 단락이 아예 없어졌습니다.**

```
전 :  만개기가 아닌데  "만개기입니다" 라고 말했다   ← 틀린 글
후 :  만개기가 아니니  ★ 아무 말도 안 한다          ← 빈 자리
목표:  만개기가 아니니  "자리가 잡히지 않습니다"     ← ★ 판정
```

> ## **지금은 「말을 안 한다」이지 「없다고 말한다」가 아닙니다.**

**E-86 에서 제가 경고한 그 방향입니다** — *"덜어내기만 하면 빈 글이 된다."*
★★ **첫 측정에서 바로 나왔습니다.** 고정 비율이 내려간 것이 **좋은 일이 아닐 수 있습니다.**

★ 뭉클이의 **후보 3** 이 바로 이 빈자리를 채울 문장입니다 —

```
이 대운에는 만개기 자리가 잡히지 않습니다
  (일간 ○ 기준 — 현재 대운에 생하는 오행 첫 진입 없음)
```

**이것이 「판정의 부정」을 0 에서 1 로 올리는 첫 문장입니다.**
