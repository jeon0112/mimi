## 0. ★ 먼저 — 1판의 1순위는 고장이 아니었다

1판은 이렇게 시작했다.

```
"신강 — 자기 에너지가 부족한 명식"
   ↑ 강하다      ↑ 부족하다
```

**이건 엔진의 모순이 아니었다. 시험 입력이 틀린 것이었다.**

엔진이 쓰는 값은 `신강` / `신약` 인데 흔들기가 넣은 값은 `강` 이었다.
그러자 —

| | 일어난 일 |
|---|---|
| 제목 | `f"신{strength.replace('신','')}"` → `"신"` + `"강"` = **신강** (라벨을 만들어냄) |
| 서술 | `if strength == "신강"` → **거짓** → `else` → 신약 서술 |

정확한 값으로 다시 재니 **두 판의 결론이 반대로 갈린다.**

```
[신약 판]                          [신강 판]
신약 — 자기 에너지가 부족한 명식    신강 — 자기 에너지가 넘치는 명식
받아들이고 채워야 균형이 잡힘       밖으로 쏟아내야 균형이 잡힘
무리하면 고갈된다
```

**겹침 88.4%** (95.0 은 폐기). **신강신약은 읽는다.**

### 그런데 잠재 병은 실재했다 (E-58)

제목 조립이 **임의 문자열을 「신강」으로 위조**한다. `강`·`약`·`엿가락` 무엇이 와도
제목에는 신강/신약이 찍혔다. **제목과 서술이 서로 다른 판정에서 나왔다.**
뭉클이가 한 곳에서 함께 정하도록 고쳤다. 위조 입력 3/3 → 0.

### ★★ 그리고 이것이 오늘의 진짜 교훈이다 (E-57)

> **흔들기가 헛돌았는데, 결과는 오히려 극적이었다.**

엔진은 모르는 값을 받고 **조용히 `else` 로 떨어졌다.** 안 흔든 판이 만들어졌는데
제목만 라벨을 바꿔서 **「모순」이라는 가장 눈에 띄는 모양**으로 나왔다.

**0번 자 검사(같은 입력 두 번 = 100%)가 이걸 못 잡는다.**
재현성은 봤지만 **입력이 엔진이 아는 값인지는 안 봤기 때문이다.**

> 자가 흔들리지 않는다는 것과, 자가 **맞는 자리를 잰다**는 것은 다르다.

**새 규칙 — 흔들 값은 지어내지 않는다. 엔진이 실제로 내놓는 값의 목록에서 고른다.**
이 한 줄을 `05_흔들어보기.md` 0번에 넣는다.

★ 뭉클이가 **스스로 자기 시험을 의심하고 정정했다.** 이건 보고가 아니라 규율이다.

## 2. 유형이 셋이다 (1판에서 그대로 유효)

`05_흔들어보기.md` 는 둘로 적었다. **셋이다.**

```python
# saju_interpreter.py 241~245  (interpret_daeun)
current_daeun = None
for d in daeon_list:                                  # ← saju['daeun']['current_daeun'] 을 무시하고
    if d["start_age"] <= current_age < d["end_age"]:  #    나이로 재계산한다
        current_daeun = d
        break
```

| 전달되나 | 읽나 | 뜻 | 흔들기가 |
|---|---|---|---|
| ✅ | ❌ | 받아놓고 안 쓴다 | 닿는다 |
| ❌ | ❌ | 아예 안 넘긴다 | 닿는다 |
| ✅ | **덮어씀** | **받고 버리고 다시 만든다** | ★ **안 닿는다** |

★ 오늘 **네 번째가 하나 더 붙었다** — §0 의 「엔진이 모르는 값을 줬다」.
  이건 재료 쪽이 아니라 **자 쪽의 고장**이다. 그래서 표에 넣지 않고 0번 규칙으로 넣는다.

> **덮어쓰는 값은 흔들어도 안 움직인다.**
> 재려면 **재계산의 입력**(나이 · `daeon_list`)을 흔들어야 한다.

## 3. ★★ 오늘의 큰 수 — 고정 문장 **53.7%**

기준 판 **41문장 중 22개**가 7번 흔들어도 **한 번도 안 바뀌었다.**

안 바뀐 것 중 가장 긴 셋 (원문 그대로) —

```
1. 용신이 전혀 없다가 처음 들어오는 대운 = 만개기
2. 땅은 만물을 기르되 자기 것을 주장하지 않습니다
3. 지금은 이끄는 것보다 받아들이는 때입니다
```

**이것이 모든 사람이 똑같이 받는 문장이다.**

> 시저님 기준: *"수많은 사주앱하고 비슷하면 웃음거리만 된다."*
> **절반 이상이 공용 문장이면, 그게 사주앱이다.** 이 숫자가 그 기준의 실측치다.

### ★ 그런데 53.7% 도 아직 못 믿는다 — 상한이다

7판 중 **한 판(신강신약)이 §0 으로 헛돌았다.** 헛돈 판은 기준 판과 거의 같은 글이었을 것이고,
**안 흔들린 판이 섞이면 고정 비율은 실제보다 높게 나온다.**

```
53.7%  ←  이 수는 위쪽 끝이다. 진짜 값은 이보다 낮다.
```

**그래서 다시 잰다.** 정확한 값으로 7판을 다시 만들어 같은 자로 센다.
★ 이건 트집이 아니다 — **못 믿는 수로 배포를 결정하지 않는다.**

### 1번과 3번은 같은 뿌리다

`1. 용신이 전혀 없다가 처음 들어오는 대운 = 만개기` — **대운 안내문이다.**
대운이 100%(덮어씀)라서 **대운 자리의 글이 통째로 고정문으로 밀려나 있다.**

뭉클이가 이 구조를 스스로 짚었다. **대운을 고치면 53.7% 가 저절로 내려간다.**

## 4. 다시 센 순서 — 3판

1판의 1순위(모순)가 없어졌으므로 다시 센다.

| | 무엇 | 왜 이 자리인가 |
|---|---|---|
| **1** | **대운 덮어쓰기** (100.0) | ★ **버그다.** 전달된 값을 코드가 버린다. 그리고 §3 의 고정문을 끌고 있다 |
| **2** | **고정 문장 재측정** (53.7 상한) | ★ 1번을 고치면 이 수가 움직인다. **고친 뒤에 재는 것이 옳다** |
| **3** | 오행 숫자 베끼기 (97.7) | 숫자만 갈리고 판단이 안 갈린다 |
| **4** | 시주 · 년주 자리 의미 (95.3 · 92.9) | 라벨만 있고 **자리의 뜻**이 없다 |
| **5** | 괘 · 십성 · 성별 | **아직 재지도 못했다** |

★ **1번이 왜 2번보다 먼저인가** — 순서가 뒤바뀌면 일을 두 번 한다.
  고정문을 손으로 걷어내고 나서 대운을 고치면, 대운이 만든 고정문을 **두 번 세게 된다.**
  **원인을 먼저 고치고 결과를 잰다.**

### 대운이 1순위인 이유 — 시저님 말씀이 근거다

> *"인생을 진행하면서 만나게 되는 수많은 인연의 학습과 충돌이 그를 쇠하게도 성하게도 한다"*
> *"운명은 있으나 환경·인연·시간으로 갈라진다"*

**대운이 그 「시간」이다.** 대운을 안 읽으면 —

```
스무 살에게 하는 말과 쉰 살에게 하는 말이 같아진다
```

**그건 사주가 아니다.** 그냥 성격 설명이다.
그리고 이게 **다른 사주앱과 갈리는 자리**다 — 성격 묘사는 어디나 한다.

## 5. 배포는 어떻게 되나 — 차단 사유가 바뀌었다

| | 1판 | 2판 |
|---|---|---|
| 차단 사유 | **모순된 글이 나간다** (고장) | 없어졌다 — 모순은 시험 버그였다 |
| 남은 사유 | | **절반 이상이 공용 문장이다** (53.7%, 상한) |
| 성격 | 고장 | **부족** |

**고장은 제가 막습니다. 부족은 시저님이 결정하실 일입니다.**

제가 드릴 수 있는 것은 숫자이고, 지금 그 숫자는 **못 믿는 상태**입니다(상한).
그래서 제 권고는 하나입니다 —

> **1번(대운)을 고치고, 2번(고정 비율)을 정확한 값으로 다시 재고,
>  그 숫자를 보고 시저님이 배포를 정하신다.**

★ 「밋밋하다」로 영원히 안 내보낼 수는 없습니다. 하지만 **얼마나 밋밋한지는 알고 내보내야 합니다.**
