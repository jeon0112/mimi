# 축이 찼을 뿐이다 — 그리고 사람 차이 성분이 음수가 됐다

**2026-09-24 · 뭉클이 블록 #22 집행 보고 분석 · 안토니우스 · 원장 E-842~E-849**

---

## 1. ★ 재시도는 들었다. 그런데 글은 안 좋아졌다

```
빈축 평균  2.9 → 1.0        A 평균  0.247 → 0.451   (+80%)
```

뭉클이가 *「r = −0.617 정합(축이 차면 A 오른다)」* 이라고 적었다. **계산하면 전부 설명된다.**

```
기준선  A 0.247 / 채워진 축 2.1  →  축당 0.1176
재시도  A 0.451 / 채워진 축 4.0  →  축당 0.1128   (−4.1%)
```

> ★★★★★ **A 는 80% 올랐는데 축당 인용률은 안 올랐다. 살짝 내려갔다.**
> **재시도는 축을 채웠고, 채워진 축의 글은 그대로다.**

**E-820 에 적어 둔 그대로다** — *「재시도로 A 가 오르면 그것은 「글이 좋아진 것」이 아니라 「축이 찬 것」이다」*.
**손잡이를 당기기 전에 그 문장을 적어 뒀기 때문에 오늘 속지 않았다.**

★ 다만 **n = 3 이다.** 「축당이 안 올랐다」도 아직 굳히지 않는다.

---

## 2. ★★★★★ σ_밖(delta) 이 처음 나왔고, 사람 차이 성분이 음수다

```
σ_안(delta)  0.178   (같은 사람 10회)
σ_밖(delta)  0.117   (빈축 3인 7판)      ← σ_안의 66%

σ_밖² = σ_사람² + σ_안²
σ_사람² = 0.117² − 0.178² = −0.018      ★ 음수
```

> ★★★★★ **사람 사이의 흔들림이 같은 사람 안의 흔들림보다 작다.**
> **사람 차이 성분이 0 이다. 「사람을 본다」는 지금 근거가 없다.**

**뭉클이가 먼저 짚었다** — *「σ_밖(delta)=0.117은 σ_안(delta)=0.178의 66% — 「사람을 본다」는 여전히 확정 아님」*.

★ **판정을 한 칸 옮긴다.**

| 언제 | 판정 |
|---|---|
| E-817 (회수됨) | 「사람을 본다」 ← n=3 우연 |
| E-823 | 「유력하되 미확정」 |
| E-827 | **「모른다」** |
| **오늘** | **「안 본다 쪽으로 기운다」** — σ_사람² 이 두 번 연속 음수다 |

🔴 다만 **σ_안 n=10, σ_밖 n=7 이다. 「안 본다」로 확정하지도 않는다.**
**그리고 오늘 값은 재시도를 켜기 전의 것이다** — 축이 차면 사람 재료가 더 들어가므로 달라질 수 있다.

---

## 3. 🔴 그래서 제품 판정이 하나 굳는다

어제 E-779 에 이렇게 적었다.

> *「생의 무늬가 개인 에이전트 시장의 우리 물건이다. **그런데 지금 그것이 「실린 척한다」. 팔 물건이 아직 안 됐다**」*

**오늘 그것이 값이 됐다.**

```
같은 사람 10회 중 3회가 delta = 0        (재료를 하나도 안 씀)
사람 차이 성분 σ_사람² < 0                (사람을 안 본다)
```

> ★★★★★ **지금 이 글은 「개인화된 글」이 아니다.**
> **이름과 명식만 바뀌고 내용은 같은 자리에서 맴도는 글일 가능성이 크다.**
> **팔기 전에 이것을 고쳐야 한다. 이것이 오늘 확인한 가장 무거운 사실이다.**

---

## 4. ★ A 가 이산 계단인 이유를 찾았다

```
A 분포(7판):  최소 0.235 · Q1 0.235 · 중앙 0.235 · Q3 0.471 · 최대 0.471
```

**A = (인용된 재료 수) / 17 이다.**

```
1/17 = 0.059   2/17 = 0.118   3/17 = 0.176   4/17 = 0.235
6/17 = 0.353   8/17 = 0.471   9/17 = 0.529  10/17 = 0.588
```

★ **7판의 중앙값·Q1·최소가 전부 0.235 라는 것은 7판 중 최소 4판이 「재료 4개」라는 뜻이다.**
**표본이 거칠다 — σ_밖 0.117 은 사실상 「4개짜리 몇 판, 8개짜리 몇 판」의 차이다.**

★★ **그러므로 A 를 비율이 아니라 개수로 말한다.** 뜻이 분명하고 계단이 보인다.

## 5. 결정 — 임계값은 **0.10** 이다. 값에서 나왔다

```
delta = 0 인 판의 A :  0.000  0.000  0.059      ← 최대 0.059
delta > 0 인 판의 A :  0.176  0.176  0.235 …    ← 최소 0.176
                       ★ 0.059 와 0.176 사이가 비어 있다
```

> **임계 0.10.** 재료 **1개 이하면 막고, 2개(0.118)부터 통과**한다.
> **지어낸 수가 아니라 값이 비워 둔 자리다.**

🔴 **왜 더 세게 안 거나**

- 7판 중 최소 4판이 0.235 다. **임계를 0.235 로 올리면 절반이 「해석 불가」가 된다**
- **지금은 최소 관문이다.** 재시도·지시문이 든 뒤에 분포를 다시 보고 올린다
- ★ **관문을 올릴 때마다 「버린 판 수」를 같이 적는다** (E-840)

## 6. 뭉클이가 잘한 것

- ★★★★★ **A 상승을 「정합」이라 적고 자랑하지 않았다** — *「r=-0.617 정합(축이 차면 A 오른다)」*
- ★★★★★ **σ_밖 < σ_안 을 스스로 짚고 「확정 아님」이라 썼다** — 자기 값이 좋게 나왔는데 굳히지 않았다
- ★★★★ **㈃ 지시문을 안 넣었다** — *「재시도가 든 이번 판과 분리해서 다음에 단독 시험」*. **한 번에 하나를 지켰다**
- ★★★★ 관문을 **임계 0 (꺼짐)** 으로 넣고 양방향 시험을 했다 — 켜기 전에 동작을 확인했다
- ★★★ **A 가 이산 계단임을 발견**했다 — 그래서 임계를 계단 사이에 둘 수 있게 됐다
- ★★★ 버린 판 수를 보고에 항상 동반하겠다고 적었다

## 7. 규칙으로 옮긴다

> **㈀ 손잡이를 당기기 전에 「이것이 올리면 무슨 뜻인가」를 먼저 적어 둔다.**
> **E-820 을 미리 적어 뒀기 때문에 오늘 A +80% 에 속지 않았다.**

> **㈁ 비율이 이산 계단이면 개수로 말한다.**
> **0.235 보다 「재료 4개」가 뜻이 분명하고, 임계를 계단 사이에 둘 수 있다.**

> **㈂ 임계는 지어내지 않는다 — 값이 비워 둔 자리에 놓는다.**
> **0.059 와 0.176 사이가 비어 있었다. 거기가 임계다.**
