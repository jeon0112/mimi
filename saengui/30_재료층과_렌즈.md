# 재료층과 렌즈 — 「추가」가 아니라 「같은 재료를 다르게 읽는다」

> 2026-09-22 · 안토니우스
> 시저님 물음: *「재료 인용률부터 올리는 블록을 만들어줘. 생의 무늬의 구조 설계를 바꿔야 할 건지 봐줘.
> 가령, 주변부 관계 내지는 궁합·진로·성격 등등을 추가로 해야지 않을까?」*
> 근거: 원장 E-698 ~ E-703 · E-556 · E-557 · E-491

---

## 1. 답부터 — **구조를 바꿉니다. 지금이 제일 쌉니다**

**다만 「전부 다시 만들자」가 아닙니다.**
**재료층 하나를 분리하는 것이고, 그게 오늘 할 수 있는 크기입니다.**

---

## 2. 🔴 「추가」로 가면 재료 문제가 **세 배로 복제됩니다**

### 나쁜 구조

```
궁합 엔진  ──→  궁합 글
진로 엔진  ──→  진로 글
성격 엔진  ──→  성격 글
```

**각각 따로 만들면 각각 밋밋해집니다.**
**지금 재료 인용률이 13.9% 인데**(E-557)**, 엔진을 셋 만들면 13.9% 짜리가 셋이 됩니다.**

**그리고 서로 모순돼도 아무도 모릅니다.**

### ★★★★★ 좋은 구조 — **재료는 하나, 렌즈가 여럿**

```
                        명 식
                          │
              ┌───────────┴───────────┐
              │      재 료 층          │   ← 여기 한 곳만 고치면 전부 오른다
              │  일간 · 오행 분포      │
              │  십신 · 신강신약       │
              │  대운 간지 · 지지 관계  │
              └───────────┬───────────┘
          ┌───────┬───────┼───────┬───────┐
        성격     진로    관계    시간    종합
      (십신)   (용신)  (합충)  (대운)
```

**같은 재료를 다른 축으로 읽습니다.**

| 얻는 것 | |
|---|---|
| ① | **재료 인용률을 한 번 올리면 렌즈 넷이 같이 오른다** |
| ② | ★★★★★ **렌즈끼리 서로가 검산이 된다** |
| ③ | 새 렌즈를 더하는 비용이 작다 — 재료는 이미 있다 |

### ★★★★★ ② 가 핵심입니다

> **「성격에서는 편관이 세다고 했는데, 진로 글에는 편관이 한 번도 안 나온다」**
> **→ 둘 중 하나가 재료를 안 읽고 있다는 뜻입니다.**

**렌즈가 하나면 틀려도 모릅니다. 여럿이면 서로 어긋나는 것이 보입니다.**

**이것이 어제 퀀트에서 본 그 구조입니다**(E-689) —
**감시가 로그와 CSV 를 둘 다 봐서 강했던 것.** 보는 눈이 둘이면 속이기 어렵습니다.

---

## 3. 🔴 13.9% 가 낮은 이유는 **둘 중 하나**인데, 아직 모릅니다

| | 가설 | 고치는 곳 |
|---|---|---|
| **㈎** | **글 템플릿에 재료 자리가 없다** — 문장이 재료를 부르지 않는다 | 글 |
| **㈏** | **재료는 계산되는데 안 쓰인다** | **연결** |

**㈏ 라면 이것은 「만들어 뒀는데, 부르는 것이 있는가」의 또 한 자리입니다**(E-491).
**9/14 에 `path` 가 그랬습니다 — 계산은 되는데 안 남았습니다.**

> **어느 쪽인지 재기 전에는 모릅니다. 그리고 고치는 곳이 다릅니다.**

**그래서 블록의 1번이 「재라」입니다.**

---

## 4. 순서 — **4번까지가 구조 바꾸기, 5번이 기능 추가**

| | 일 | 크기 |
|---|---|---|
| **1** | **재료 목록을 값으로 뽑는다** — 엔진이 계산하는 것 전부 | 잰다 |
| **2** | **본문이 그중 몇 개를 쓰나 센다** — 13.9% 의 분자·분모 확인 | 잰다 |
| **3** | **재료층을 함수 하나로 분리한다** — `get_materials(saju) → dict` | **여기가 구조 변경** |
| **4** | **지금 글이 그 dict 를 쓰게 고친다** (렌즈 1 = 종합) | 고친다 |
| **5** | **렌즈를 하나씩 더한다** — 성격 → 관계 → 진로 → 시간 | 더한다 |

**★ 3번이 오늘 할 수 있는 크기이고, 그것만으로 5번이 싸집니다.**

**★★ 지금 바꾸는 것이 제일 쌉니다 — 화면이 하나뿐이기 때문입니다.**
**궁합을 먼저 만들고 나중에 구조를 바꾸면 두 번 만듭니다.**

---

## 5. 렌즈 넷 — 무엇을 보나

| 렌즈 | 중심 재료 | 무엇을 말하나 |
|---|---|---|
| **성격** | **십신** (비견·식신·정재·편관·정인…) | 어떤 힘이 세고 어떤 힘이 얇은가 |
| **진로** | **용신 · 오행 분포** | 무엇이 나를 살리나 / 어디로 가면 덜 힘든가 |
| **관계** | **지지 합·충 · 일간 대 일간** | 어디서 맞물리고 어디서 부딪치나 |
| **시간** | **대운 · 세운 간지** | 지금 어느 구간인가 |

**★ 넷 다 같은 재료를 씁니다. 다른 것은 「무엇을 앞에 놓느냐」뿐입니다.**

**★★ 그리고 넷이 같은 재료를 쓰므로, 한 렌즈가 어떤 재료를 안 쓰면
다른 렌즈와 대조해서 잡을 수 있습니다.**

---

## 6. 재료 인용률을 재는 법 — **분모를 먼저 정합니다**

**13.9% 라는 수는 분모가 무엇이냐에 따라 달라집니다**(E-551: 섞지 말아야 할 수).

```
분모 후보
  ㈀ 엔진이 계산하는 재료 전부          ← 「만들어 둔 것」
  ㈁ 그 명식에서 유효한 재료만          ← 「부를 수 있는 것」
  ㈂ 글이 부르려고 자리를 만든 재료      ← 「부르기로 한 것」
```

**셋을 섞으면 안 됩니다.** 그리고 **㈀−㈂ 의 차이가 곧 「만들어 뒀는데 안 부르는 것」**입니다.

---

## 7. 한 줄로

**기능을 더하는 것이 아니라, 재료를 한 곳에 모으고 그것을 여러 각도에서 읽는 것입니다.**

> **그러면 재료를 한 번 고칠 때 글 넷이 같이 좋아지고,
> 넷이 서로 어긋나는 것을 보고 틀린 곳을 찾을 수 있습니다.**
