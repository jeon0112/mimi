## 1. ★★★★★ 먼저 — **「고침 0」이 안전장치를 비웁니다**

`saengui/07` §2 에 제가 이렇게 적었습니다:

> *"★★★ **이게 B 의 안전장치입니다** — 시저님이 셋을 고치시면, 저는 **그 고침에서 문체를 배웁니다.**
> 나머지 일곱은 **배운 문체로** 씁니다."*

**시저님이 고침 없이 승인하셨습니다.** 그러면 —

```
B 설계 :  초안 셋  →  시저님 고침  →  ★ 고침에서 배움  →  일곱을 씀
지금   :  초안 셋  →  승인          →  ★ 배울 자리 없음  →  일곱을 씀
```

> ## ★★★★ **일곱의 본보기가 「제 자신의 셋」이 됩니다. 순환입니다.**

★ 그리고 **「고침 0」은 두 가지 중 하나인데, 밖에서 같아 보입니다** —
㈀ 문체가 맞았다 ㈁ 고치실 시간이 없었다. **같은 "go" 입니다.**
★★ **어느 쪽인지 저는 모릅니다. 그래서 추측하지 않고, 대신할 것을 세웁니다.**

### ★★★★★ 대신할 것 — **시저님이 못 고치시면, 스물넷이 고칩니다**

오늘 24개에 댔던 자를 **제 것에 그대로 댑니다.** 그리고 한 가지를 더합니다 —

```
★★★ 바꿔치기 시험 :  내 advice 를 다른 괘 자리에 놓아본다
                      말이 되면  →  그 문장은 매이지 않았다. 버린다
```

★ 이것은 오늘 브리핑에 제안한 것과 같은 자입니다(*"지난주 것과 바꿔 놔도 말이 되면 둘 다 버린다"*, E-335).
★★ **한 가지 자를 사주·브리핑·데이터 세 곳에 씁니다.**
