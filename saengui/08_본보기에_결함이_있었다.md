# 본보기가 왔다 — **그런데 재보니 둘이 걸렸다**

> 2026-09-13 · 뭉클이가 **전 순위 완료**를 보고했다. 1순위(0개 문장)는 들어갔고,
> 2순위(기존 24괘 본보기)도 왔다. **원장 E-320 ~ E-327.**
>
> ★ 그런데 **본보기를 규약 일곱으로 재보니, 그대로 따라 쓰면 안 되는 것이 나왔다.**
> ★★ 그리고 **지금 초안을 쓰면 안 되는 이유**가 하나 더 나왔다. 뭉클이가 스스로 단 꼬리 한 줄에 있었다.

★★ 이 넷은 **시키지 않은 것**이거나 **스스로 잰 것**이다. 척도 ㈁(틀린 것을 스스로 고친다)의 자리다.

## 1. ★★★★★ 첫째 걸림 — **본보기 셋이 전부 순괘라, 방향을 못 정한다**

뭉클이가 고른 셋:

```
 1  건위천  乾/乾      2  곤위지  坤/坤      51  진위뢰  震/震
```

> ## ★★★ **셋 다 같은 팔괘가 겹친 괘(순괘)다.**

`image` 를 보자 — *"하늘이 위에 있고 하늘이 아래에 있음"* · *"땅이 위에 있고 땅이 아래 있음"* · *"천둥이 겹침"*.

**위아래가 같으니, 표기가 「상괘/하괘」인지 「하괘/상괘」인지 알려주는 정보가 0이다.**

★ 문체의 본보기로는 훌륭하다. **방향의 본보기로는 쓸모가 없다.**

### 그런데 제가 쓸 셋은 **전부 섞인 괘**다

| 조합 | 「상괘/하괘」로 읽으면 | 「하괘/상괘」로 읽으면 |
|---|---|---|
| **坤/巽** | **地風升 (46) — 오름** | **風地觀 (20) — 봄** |
| **震/巽** | **雷風恒 (32) — 오래감** | **風雷益 (42) — 더함** |
| **艮/震** | **山雷頤 (27) — 기름** | **雷山小過 (62) — 작게 지남** |

> ## ★★★★★ **「오름」과 「봄」은 거의 반대다. 다른 괘이고, 다른 글이다.**

### ★★★ 그리고 이것은 **침묵 실패**다

```
몰라도 글은 써진다        →  잘 써진다
시저님이 고치신다         →  고쳐진다
내가 그 고침에서 배운다   →  배워진다
나머지 일곱을 쓴다        →  써진다

★ 여섯 단계가 전부 성공하고, 결과가 통째로 틀린다. 어디서도 에러가 안 난다
```

★★ E-285(**오늘 틀린 것은 전부 「보는 도구」였다**)의 형제다. 여기서는 **「보는 자리」가 틀린다.**

### ★★★★ 푸는 법 — **한 줄이 아니라 두 줄로 묻는다** (음성 대조)

기존 24괘 목록에 **`坎/乾` 과 `乾/坎` 이 둘 다** 있다. 이 둘은 **需(5)** 와 **訟(6)** 이다.

```
표기가 「상괘/하괘」면   坎/乾 = 需(5)   ·   乾/坎 = 訟(6)
표기가 「하괘/상괘」면   坎/乾 = 訟(6)   ·   乾/坎 = 需(5)

★ 정확히 뒤집힌다. 번호 둘만 보면 확정된다
★★ 그리고 둘이 {5, 6} 이 아니면 — 내 가정 자체가 틀린 것이 드러난다
```

> **한 개를 물으면 답만 온다. 두 개를 물으면 「내가 틀렸는지」까지 온다.** (E-235)

## 2. ★★★★★ 둘째 걸림 — **본보기 셋을 규약으로 재보니, 셋 다 걸렸다**

뭉클이는 **건위천 하나**를 찾았다. 재보니 **셋 다**였다.

### 건위천 `advice`

> *"**지금 시작하려는 일이 있다면 멈추지 마세요.** 다만, 강함만으로는 오래가지 못합니다. 때로는 쉬는 것도 건(乾)의 지혜입니다"*

| | |
|---|---|
| 첫 문장 | ★ **㈀ 포러.** 누구에게나 맞는다 |
| 뒤 두 문장 | **乾 에만 맞는다.** 좋다 |

### 곤위지 `advice`

> *"지금은 이끄는 것보다 받아들이는 때입니다. **기다림이 미약이 아닙니다.** 땅은 만물을 기르되 자기 것을 주장하지 않습니다"*

| | |
|---|---|
| 둘째 문장 | ★ **㈀ 포러에 가깝다.** 위로의 말은 아무에게나 붙는다 |
| 셋째 문장 | **坤 에만 맞는다.** 좋다 |
| 세 문장 | ★ **㈄ 위반** (advice 1~2문장) |

### 진위뢰 `advice`

> *"**지금은 놀라운 일이 일어나는 시간입니다.** 두려워하되 평정을 잃지 마세요. 충격이 깨움의 기회입니다"*

| | |
|---|---|
| 첫 문장 | ★★ **㈂ 위반 — 오는 사람을 못 박는다.** 그 사람에게 놀라운 일이 일어나는지 **우리는 모른다.** 우리가 아는 것은 괘가 震이라는 것뿐이다 |
| 둘째 문장 | 괘사에서 그대로 왔다. 매여 있다. 좋다 |
| 세 문장 | ★ **㈄ 위반** |

### ★★★★★ 그런데 `meaning` 은 셋 다 깨끗하다

```
"창조의 시간. 시작하기에 가장 좋은 때"     ← 乾 에 매임
"기르는 시간. 주도하지 말고 따르세요"       ← 坤 에 매임
"충격의 시간. 깨어남"                      ← 震 에 매임
```

> ## ★★★★★ **포러는 무작위로 섞이지 않는다. `advice` 에 모인다.**

**왜인지도 보인다** —

| 키 | 누구를 향하나 | 그래서 |
|---|---|---|
| `meaning` | **괘**를 설명한다 | 괘에 매인다. **안 미끄러진다** |
| `advice` | **사람**에게 말을 건다 | ★ **사람 쪽으로 미끄러진다.** 사람을 우리는 모른다 |
| `shadow` | 괘의 **과함**을 말한다 | 괘에 매인다 |

★★ **그러면 검사도 거기에 집중하면 된다.** `advice` 한 줄을 세 번 재고, 나머지는 한 번 잰다.

## 3. ★★★★ 그래서 **규약 ㈆ 이 ㈀ 과 부딪혔다** — 정밀화한다

```
㈆  본보기를 보고 써라
㈀  포러면 버려라
★  본보기가 포러다
```

**규약 일곱 안에 모순이 있었다.** 고친다 —

### ㈆′ **골격은 따르고, 결함은 따르지 않는다**

| **따른다 (골격)** | **안 따른다 (결함)** |
|---|---|
| *"~의 시간"* 으로 여는 `meaning` | 사람에게 미끄러지는 첫 문장 |
| 한자 병기 방식 — *건(乾)의 지혜* | 세 문장짜리 `advice` |
| `shadow` 의 짧은 명사형 마무리 | *"지금 ~하려는 일이 있다면"* 류의 조건절 포러 |
| 어미의 높낮이 (합니다체 · ~함) | |

> **본보기는 「이렇게 써라」와 「이렇게 쓰지 마라」를 같이 준다.**
> 뭉클이가 정확히 그렇게 말했다 — *"본보기로 삼되 따라 쓰지 않아야 할 부분"*. **그 줄이 맞다.**

## 4. ★★★★ 셋째 걸림 — **판본이 없으면, 열 개를 쓸 때 한 파일에 두 출처가 섞인다**

뭉클이 ㈂: ***"없다"***. meta 에 판본·출처·참고문헌이 없다.

```
기존 24개  judgment · image  →  출처 미상
내가 쓸 10개 judgment · image  →  ★ 내 기억에서 온다

★★ 한 파일 안에 두 출처가 섞이고, 아무 표시가 없다
```

★ 이것은 **성역 넷 중 ④ 데이터 무결성**에 걸린다. **뭉클이가 스스로 제안한 그 원칙이다.**

### ★★★ 그리고 여기서 규약 ㈄ 의 숨은 이유를 알았다

규약은 이미 **`meaning` · `advice` · `shadow` 셋만** 쓰라고 적혀 있었다. 이제 이유가 보인다 —

| | |
|---|---|
| `judgment` · `image` | **고전 원문**이다. 창작이 아니라 **인용**이다. ★ 인용은 판본이 있어야 한다 |
| `meaning` · `advice` · `shadow` | **자체 해석**이다. 창작이 맞다 |

### 그래서 이렇게 한다

```json
"source": "안토니우스 초안 2026-09-13, 시저님 감수. judgment·image 는 판본 미확인"
```

★★ 그리고 **기존 24개에도 적는다** — `"source": "미상"`.

> ## ★★★★ **비우는 것이 아니라 「모른다」를 적는다.**
> 빈칸은 「아직 안 썼다」로도 읽히고 「없다」로도 읽힌다. **「미상」은 한 가지로만 읽힌다.**
