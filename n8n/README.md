# n8n 전략 자문 위원회 (멀티에이전트)

`strategy_council.json` — 텔레그램 또는 웹 채팅으로 수시로 대화하는 **실시간 전략 상담 파트너**.
나라장터 입찰 워크플로우와는 별개로, 아이디어를 체계화·검수·법률검토·확장설계·재무분석해주는 두뇌 집단.
모든 답변은 구글 드라이브에 자동 기록되어 **전략 아카이브**가 쌓인다.

## 구조 — 합의형 위원회

```
텔레그램 입력 ┐
웹 채팅 입력 ┘→ 입력 정규화(채널·메시지·세션 통일)
  → [5인 전문위원 병렬 검토 — 모두 claude-sonnet-4-6]
       ① 기획·구조화 위원   : 목표·가설·단계·KPI로 체계화
       ② 현실성 검수 위원   : 악마의 변호인. 리스크·비용·실패 시나리오
       ③ 법률·규제 위원     : 공공조달/장애인기업/사회적기업 법적 쟁점
       ④ 확장·디자인 위원   : 확장안·시스템 구조·UX/제품 디자인
       ⑤ 재무·투자 분석 위원 : 수익모델·단위경제성·밸류에이션·주식/시장 리서치
  → 의견 취합(Merge 5입력) → 한 건으로 모으기(Aggregate)
  → 총괄 시너지 에이전트 (claude-opus-4-8 + 대화 기억)
       ├→ 아카이브 본문 → 파일 변환 → 구글 드라이브 업로드  (양 채널 공통)
       └→ 채널 분기 ─ telegram → 텔레그램 응답
                    └ web      → 웹 채팅으로 반환
```

- 위원 5명은 병렬 → 빠르고 관점은 다양. 종합만 Opus로 깊게.
- **대화 기억**은 세션(텔레그램 chat id / 웹 sessionId)별로 유지 → 이어지는 대화.
- 두 입력의 데이터 모양이 달라 **입력 정규화** 노드에서 `userMessage / sessionId / channel`로 통일.

## Import 후 세팅

### 1. 텔레그램 봇
1. 텔레그램 **@BotFather** → `/newbot` → 토큰 발급
2. n8n Credentials → **Telegram API** 생성 후 토큰 입력
3. `텔레그램 입력`, `텔레그램 응답` 노드에서 선택 (`REPLACE_TELEGRAM_CRED_ID` 대체)

### 2. 웹 채팅
- `웹 채팅 입력`(Chat Trigger) 노드의 **Chat URL**을 열면 바로 웹 채팅 UI. 별도 자격증명 불필요.
- 워크플로우가 Active여야 공개 URL 동작.

### 3. Anthropic 자격증명
- 6개 모델 노드(위원 5 + 총괄)에서 **Anthropic account** 선택 (`REPLACE_ANTHROPIC_CRED_ID` 대체)

### 4. 구글 드라이브 아카이브
1. n8n Credentials → **Google Drive OAuth2** 연결
2. `드라이브 아카이브` 노드에서 자격증명 선택 (`REPLACE_GDRIVE_CRED_ID` 대체)
3. `folderId`의 `REPLACE_DRIVE_FOLDER_ID`를 **아카이브용 폴더 ID**로 교체
   (드라이브에서 폴더 URL `.../folders/<이 부분>`. 비워두고 루트에 쌓아도 됨)
- 결과는 `전략아카이브_YYYYMMDD_HHMMSS.txt`로 매 대화마다 1개씩 저장.

### 5. 활성화(Active)
- 켜면 텔레그램 봇/웹 채팅 양쪽에서 위원회가 돌아간다.

## 커스터마이즈 포인트

| 바꿀 것 | 위치 |
|---------|------|
| 위원 역할/성격 | 각 위원 노드의 `시스템 메시지` |
| 위원 추가/삭제 | 위원 노드+모델 추가 → `입력 정규화`에서 팬아웃 연결 → `의견 취합` `numberInputs` 조정 → 총괄/아카이브 프롬프트에 `data[n].output` 추가 |
| 종합 답변 형식 | `총괄 시너지 에이전트` 시스템 메시지 |
| 기억 길이 | `대화 기억` 노드 `contextWindowLength` (기본 20턴) |
| 답변 품질 ↑ | 위원 모델을 `claude-opus-4-8`로 상향 (비용·속도 trade-off) |
| 아카이브 형식 | `아카이브 본문` 노드(텍스트), 또는 Google Docs/Sheets 노드로 교체 |

## 채널 메모

- **텔레그램 / 웹 채팅**: 둘 다 양방향 실시간. 현재 구성.
- **카카오톡**: 개인 양방향 자동화는 공식 미지원. 단방향 알림톡(결과 푸시)은 비즈니스 채널 세팅 시 별도 추가 가능.
