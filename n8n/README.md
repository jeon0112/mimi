# n8n 전략 자문 위원회 (멀티에이전트)

`strategy_council.json` — 텔레그램으로 수시로 대화하는 **실시간 전략 상담 파트너**.
나라장터 입찰 워크플로우와는 별개로, 아이디어를 체계화·검수·법률검토·확장설계해주는 두뇌 집단.

## 구조 — 합의형 위원회

```
텔레그램 입력
  → [4인 전문위원 병렬 검토 — 모두 claude-sonnet-4-6]
       ① 기획·구조화 위원 : 목표·가설·단계·KPI로 체계화
       ② 현실성 검수 위원 : 악마의 변호인. 리스크·비용·실패 시나리오
       ③ 법률·규제 위원   : 공공조달/장애인기업/사회적기업 법적 쟁점
       ④ 확장·디자인 위원 : 확장안·시스템 구조·UX/제품 디자인
  → 의견 취합(Merge 4입력) → 한 건으로 모으기(Aggregate)
  → 총괄 시너지 에이전트 (claude-opus-4-8 + 대화 기억)
       : 4관점 종합 → 결론·쟁점·다음 액션·열린 질문
  → 텔레그램 응답
```

- 위원 4명은 병렬 → 빠르고, 관점은 다양. 종합만 Opus로 깊게.
- **대화 기억**은 텔레그램 chat id별로 유지 → 이어지는 대화가 됨.

## Import 후 세팅 (필수)

### 1. 텔레그램 봇 만들기
1. 텔레그램에서 **@BotFather** → `/newbot` → 봇 이름/아이디 → **토큰** 발급
2. n8n → Credentials → **Telegram API** 새로 만들고 토큰 입력
3. `텔레그램 입력`, `텔레그램 응답` 두 노드에서 그 자격증명 선택
   (JSON의 `REPLACE_TELEGRAM_CRED_ID` 대체됨)

### 2. Anthropic 자격증명
- 5개 모델 노드(위원1~4 + 총괄)에서 **Anthropic account** 자격증명 선택
  (`REPLACE_ANTHROPIC_CRED_ID` 대체됨)

### 3. 워크플로우 활성화(Active)
- 활성화하면 봇에게 보낸 메시지가 바로 위원회를 돌림. 봇과 1:1 대화 시작.

## 커스터마이즈 포인트

| 바꿀 것 | 위치 |
|---------|------|
| 위원 역할/성격 | 각 위원 노드의 `시스템 메시지` |
| 위원 추가/삭제 | 위원 노드+모델 추가 → 텔레그램 입력에서 팬아웃 연결 → 의견 취합 `numberInputs` 증가 → 총괄 프롬프트에 `$json.data[n].output` 추가 |
| 종합 답변 형식 | `총괄 시너지 에이전트` 시스템 메시지 |
| 기억 길이 | `대화 기억` 노드 `contextWindowLength` (기본 20턴) |
| 답변 품질 ↑ | 위원 모델을 `claude-opus-4-8`로 상향 (비용·속도 trade-off) |

## 채널 메모

- **텔레그램**: 양방향 실시간. 현재 구성. (웹/로컬 테스트는 이 워크플로우에 `Chat Trigger` 노드를 추가로 붙이면 됨)
- **카카오톡**: 개인 양방향 자동화는 공식 미지원. 결과를 한쪽으로 보내는 알림톡(단방향)은 비즈니스 채널 세팅 시 별도 추가 가능.
