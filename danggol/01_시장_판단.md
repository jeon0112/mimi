# 당골 시장 판단 — 뮤즈가 이미 같은 자리에 있다

> 2026-09-10 · 시저님이 유튜브 분석 영상(`youtu.be/knGTxa-K9zQ`) 자막을 주셨다.
> ★ 출처는 **국내 유튜브 해설**이다. 안토니우스는 검증하지 못했다 (웹 검색 불가).
> **「기록」이지 「실측」이 아니다.** 다만 어제 메타AI 자기설명보다는 낫다 — 제3자다.

---

## 1. 안토니우스의 판단이 틀렸다

어제 나는 이렇게 썼다 —

> *"뮤즈와 당골은 마주 보는 물건이다. 뮤즈는 손님을 대신하고 당골은 가게를 대신한다.
>  같은 물건이 아니므로 기능을 따라갈 이유가 없다."*

**절반만 맞았다.** 영상에 이것이 있다 —

> *"지금 뮤즈가 이미 **비즈니스 에이전트**도 만들고 있거든요.
>  **이미 비즈니스 에이전트가 베타로 나와서 돌고 있습니다.**"*
> *"누가 케익을 사고 싶어. 그럼 마치 나의 직원인 것처럼
>  문의가 들어왔을 때 상담도 하고 예약도 하고 판매 이런 것들을 전부 다 진행"*

**당골과 같은 물건이다.** 케이크 가게 예시까지 같다 — 우리 `demo.json` 도 케이크집이다.

★ **기록해 둔다.** 내 판단이 틀렸고, 시저님이 자료를 가져오셔서 바로잡혔다.

---

## 2. 그런데 자리는 남아 있다 — 셋

### ① 국경 ★ 가장 크다

```
뮤즈 비즈니스 에이전트   인스타그램 · 왓츠앱 기반
한국 가게 문의           카카오톡 · 네이버로 온다
```

**카카오와 네이버가 메타에게 API 를 열어줄 리 없다.**
이건 기술 문제가 아니라 **국경 문제**라서 메타가 돈으로 못 산다.

★ 그리고 뮤즈는 지금 **미국 한정 · 웨이팅 리스트**다.
한국에 언제 올지, 와서 카톡을 볼 수 있을지 — **아무도 모른다.**

### ② 신뢰

> 영상: *"메타의 신뢰가 그렇게 미국에서 좋지만은 않거든요.
>  개인 정보나 결제 정보를 넘겨야 되는데 소비자가 과연 이걸 믿어 줄까"*

한국 소상공인이 **가게 정보와 손님 대화를 메타에 넘길까.**

→ 당골이 팔 수 있는 한 줄: **"손님 대화가 메타로 안 갑니다."**
  가게 데이터가 어디 있는지가 **기능이 아니라 상품**이 된다.

### ③ 규칙 기반

뮤즈는 LLM 이 웹사이트를 클릭해서 일한다. 강력하지만 **틀릴 수 있다.**
영상도 걱정한다 — *"에이전트가 데모에서 보여준 모습과 달리 좀 멍청할 수도"*

당골은 규칙 기반이라 **틀리지 않는 대신 못 하는 게 많다.**
**작은 가게에는 그게 맞다.** 케이크집에 필요한 건 창의성이 아니라 **정확한 영업시간**이다.

`00_컨펌.md` §5 에 적은 그대로다.

---

## 3. ★ 가장 실용적인 지적 — 텔레그램은 시험용이다

**한국 소상공인은 텔레그램을 안 쓴다.**

지금 텔레그램인 것은 **옳다** — API 가 쉽고 무료고 심사가 없다. **뼈대를 시험하기에 알맞다.**
그러나 **진짜 시장은 카카오톡 채널**이다.

| | 무엇 | 언제 |
|---|---|---|
| ① | 텔레그램으로 뼈대 검증 | **지금.** 옳다 |
| ② | 시저님 가게 첫 주 | 다음 |
| ③ | **카카오톡 채널로 옮긴다** | ★ **여기가 시장이다** |

★ ③은 **사업자 심사가 있고 시간이 걸린다.**
  ①② 를 돌리는 동안 **자격 요건을 미리 알아봐야 한다.**
  나중에 알아보면 "코드는 다 됐는데 두 달 기다림" 이 된다.

**확인할 것** — 카카오톡 채널 상담 API 자격 · 심사 기간 · 비용 ·
어떤 사업자등록증이 필요한가 (블루바이오로 되나).

---

## 4. 가격이 정해졌다 — 광고비가 아니라 인건비

영상에 저커버그 논리가 있다.

> *"이제 이것은 **광고비가 아니라 인건비**인 거죠. 원래 직원이 했어야 하는 일인데."*
> *"전 세계 광고 시장이 연 1조 달러인데,
>  그 광고와 광고 사이에 있는 **커뮤니케이션 시장은 연 3조 달러**"*

**당골이 파는 것도 인건비다.** 그러니 값을 매기는 자가 다르다.

| | 기준 |
|---|---|
| ✗ | 인스타 광고비와 비교 |
| **✓** | **알바 시급 × 절약한 시간** |

```
하루 1시간 응대에서 풀려난다  →  월 25시간
최저시급으로 치면            →  약 25만원어치
월 3~5만원이면              →  사장님이 계산기를 두드린다
```

★ 그리고 이 계산이 **성공 기준(70%)과 곧바로 이어진다.**
  70% 를 봇이 처리하면 사장님 시간이 얼마나 줄었는지 **숫자로 말할 수 있다.**
  그게 두 번째 가게 영업 자료다.

★★ **수수료 모델은 여전히 안 된다.**
  메타는 36억 유통망이 있어서 되고 우리는 없다 (`00_컨펌.md` 부록 ①).

---

## 5. 영상에서 확인된 것 / 여전히 모르는 것

**들은 것 (제3자 해설)**

| | |
|---|---|
| 미국 앱스토어 4위 · 초기 사용량이 테스트 그룹의 10배 | 시장이 실제로 반응했다 |
| 유저마다 **전용 가상머신**이 클라우드에 돌아간다 | 앱을 꺼도 일이 계속된다 |
| 주당 1억 토큰까지 무료, 그 이상은 파워/맥시멈 요금제 | **당장 광고 모델은 없다** |
| 거래 수수료를 기업에게 받겠다 | 커머스가 본체 |
| 메타 주가 +6%, 알파벳 −2% | 시장은 광고 패러다임 이동으로 읽었다 |

**여전히 모르는 것 — 당골 판단에 정작 필요한 것**

| | |
|---|---|
| 비즈니스 에이전트가 **모르는 것을 어떻게 다루나** | ← 우리가 이길 자리인데 **답이 없다** |
| 사장님이 **무엇을 얼마나 입력**해야 하나 | ← 소상공인이 쓰느냐 마느냐인데 **답이 없다** |
| 한국 진출 시점 · 카톡 연동 여부 | **아무도 모른다** |

★ 두 번 물었는데 두 번 다 ①②에 답이 없다.
  **마케팅은 할 수 있는 것을 말하고 못 하는 것은 말하지 않는다.**

## 6. 그래서 결론

**당골을 접을 이유가 없다.** 다만 **자리를 옮겨 잡는다.**

```
✗  뮤즈보다 똑똑한 비즈니스 에이전트를 만든다      → 진다
✓  한국 소상공인이 실제로 쓰는 통로(카톡)에서
   틀리지 않게 응대하고, 데이터가 밖으로 안 나간다  → 선다
```

**그리고 급할 것 없다.**
뮤즈는 미국 한정 베타이고, 한국에 오더라도 카톡을 못 본다.
**우리는 그 사이에 첫 가게를 제대로 돌려보면 된다.**

★ 다만 **③(카카오톡 채널) 자격 요건만은 지금 알아본다.**
  코드보다 심사가 오래 걸린다.

# 2차 판단 (2026-09-10) — 카톡 정면은 막혀 있다. 그런데 길이 보인다

## 1. 결정적인 한 줄

> **상담톡(양방향 1:1 — 당골과 같은 물건)은 「공식 딜러사와 계약」을 통해서만 가능.**
> 딜러 8곳: 스펙트라 · 블룸에이아이 · 트랜스코스모스코리아 · 인포뱅크 ·
> 한국클라우드 · **채널코퍼레이션** · 디케이테크인 · 더화이트커뮤니케이션

**그 뜻 셋**

```
① 우리가 가게와 직접 계약할 수 없다. 딜러를 끼어야 한다
② 딜러가 수수료를 가져간다
③ ★ 그 8곳이 이미 상담톡 사업을 하고 있다 — 카카오 공식 자격을 갖고
```

★ 딜러 목록에 **채널코퍼레이션**이 있다. **협회가 쓰는 채널톡**을 만든 회사다.

>  2025.09.25 출시 — omago.ai 기록. **카카오 공식 문서에서 확인 못 함.**
>  이게 사실이면 당골의 직접 경쟁"*

**사실이면 카카오가 직접 한다.** 메타보다 더 직접적이다.
**1차 출처로 확인해야 한다.**

## 3. ★★ 그런데 옮기려고 보니 — 같은 것을 두 번 짓고 있었다


**같은 물건이다. 통로만 다르다.**

★ **소상공인 문의의 상당수는 전화로 온다.**
  그리고 **전화는 카카오 허락도 메타 허락도 필요 없다.**

> **카카오가 못 막고 메타도 못 오는 자리 — 전화다.**

### 그래서 둘을 합친다

```
                    응답 엔진 (shop_agent/engine.py)

        ┌─────────────┬───────┴───────┬─────────────┐
```

**엔진은 하나면 된다.** 통로만 갈아 끼운다.

★★ **이건 판이 늘어나는 게 아니라 둘이 하나가 되는 것이다.**
  ROADMAP 「멈춤」에 있던 AICC 가 여기서 되살아난다.

# 3차 판단 (2026-09-10) — 소상공인 시장은 접는다. 엔진은 남긴다

## 1. 확인된 사실

**「카나나 상담매니저」는 실재한다.** 그리고 당골과 같은 물건이다.

| | 카나나 (카카오 공식 문구) |
|---|---|
| 무엇 | 톡채널 고객문의 자동 응답. 사업자 작성 답변 + 매장정보·메뉴·소식을 근거로 |
| **주문·예약** | **자동 접수한다** |
| 운영시간 | 가능시간만 / 불가시간만 / 24시간 |
| 통계 | 문의 분류·날짜별 응대 현황 리포트 |
| **켜는 법** | **"버튼을 몇 번만 클릭하면 적용"** — 딜러 계약 언급 없음 |
| 요금 | **보도자료에 없음** |
| 언제 | 베타 2024.10 → **정식 2025.09.25** |

★ **1년 가까이 베타를 돌리고 정식 출시했다.** 이미 다듬어졌다.
★ 보도자료 인용: *"특히 **문의가 많은 주문·예약 업종**에서 호응이 컸다"*
  **케이크 가게 — 우리 표적 그대로다.**

## 2. 세 겹으로 막혔다

```
메타     뮤즈 비즈니스 에이전트   (베타)
카카오   카나나 상담매니저       (정식·무료로 보임·클릭 몇 번)
딜러     상담톡 8곳
```

**그리고 우리는 가장 늦게 왔고 가장 작다.**

### 소상공인이 왜 당골을 쓰겠는가

```
카나나   이미 쓰는 톡채널에서 버튼 몇 번
당골     텔레그램을 새로 깔고, 손님에게 "텔레그램으로 문의하세요"
```

**안 쓴다.** 기능 문제가 아니라 **손님이 거기 없다**는 문제다.

> **판정 — 소상공인 응대 시장은 접는다.**
> 광주TP 때와 같다. **못 이길 싸움에 시간을 쓰지 않는다.**

## 3. ★ 그러나 엔진은 버리지 않는다

시저님이 처음에 하신 말씀으로 돌아간다 —

> *"예전에 **뭉킁비서**를 하나 만들어 놓은 것을 레벨업시킨다 생각하면 돼."*

**당골의 원래 값어치는 「비서」였다.** 소상공인 시장은 나중에 붙인 것이다.

그리고 엔진은 진짜다 — **N1~N11 통과.**
지어내지 않고, 프롬프트 주입이 안 통하고, 격리 시험까지 했다.
**그건 카카오가 뺏어갈 수 없다.**

## 4. 갈 자리가 이미 우리 손에 있다

```
협회/02_QA_구조.md    ← 이미 설계했다
shop_agent/engine.py  ← 엔진이 이미 있다
```

**둘이 같은 물건이다.**

| | 당골 | 협회 Q&A |
|---|---|---|
| 누가 묻나 | 손님 | **직원 10분** |
| 무엇을 | 영업시간 · 메뉴 · 예약 | 정산 절차 · 지침 · 회칙 |
| 답의 규율 | 지어내지 않는다 | **근거 줄이 없으면 답이 아니다** |
| 모르면 | 사장님께 | 사무국장님께 |
| 통계 | `kind` 별 | 같다 — *"무엇을 가장 많이 묻나"* |

★★ **엔진이 그대로 간다. 바꿀 것은 지식 파일뿐이다.**
  `stores/demo.json` → `협회/사무국.json`

### 그리고 협회에는 세 겹이 없다

| | |
|---|---|
| 카카오 허락 | **필요 없다.** 우리 조직이다 |
| 메타 허락 | **필요 없다** |
| **통로를 누가 정하나** | ★ **우리가 정한다** |

**★ 2026-09-10 정정** — 처음에 *"손님이 이미 채널톡에 있다"* 고 썼다. **덜 정확했다.**

| | 통로를 누가 정하나 |
|---|---|
| 소상공인 | **손님**이 정한다. 우리가 못 바꾼다 |
| **협회** | **우리가 정한다.** 시저님이 *"이거 씁시다"* 하면 된다 |

**이것이 협회로 가는 진짜 이유다.**
카카오가 톡채널을 막아도 **우리는 다른 문으로 갈 수 있다** —
채널톡이든 텔레그램이든 웹이든.

소상공인 시장에서 진 이유가 *"손님이 거기 없다"* 였다면,
협회에서 이기는 이유는 *"손님을 데려올 수 있다"* 이다.

## 5. 판이 또 하나 줄어든다

```
어제   AICC(멈춤) + 당골(새것) + 협회 Q&A(보류)   =  셋
지금   하나의 엔진 · 통로만 갈아 끼운다            =  하나
```

| 순서 | 통로 | 허락 | 왜 |
|---|---|---|---|
| ① | **협회 사무국** | 없음 | ★ 우리 것이고 손님이 이미 있다 |
| ② | 전화 (AICC 재개) | 없음 | 카카오·메타가 안 받는다 |
| ③ | 웹 위젯 | 없음 | 홈페이지 있는 곳 |
| — | 소상공인 카톡 | **접는다** | 세 겹으로 막혔다 |

## 6. 남은 미련 하나 — 적어 두고 넘어간다

★ 카나나가 답하지 못하는 두 가지를 **우리는 아직 모른다** —
  *"모르는 질문을 어떻게 다루나 (지어내는가)"* · *"낡은 정보를 어떻게 갱신하나"*
  뮤즈에 두 번 묻고 카나나에 한 번 물어 **세 번 다 답이 없었다.**

**만약 카나나가 지어낸다면** 우리 자리가 다시 생긴다.
그러나 **그건 확인되지 않았고, 확인하려면 실제로 써봐야 한다.**
지금은 접고, **누가 카나나를 쓰다 데이는 것을 보게 되면** 그때 다시 연다.

★ **접는 것과 지우는 것은 다르다** (E-31).
  왜 접었는지 여기 적어 두었으니, 판이 바뀌면 다시 펼 수 있다.
