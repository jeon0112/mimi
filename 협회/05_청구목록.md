## 2. ★ 그런데 넷을 다 기다리지 않는다

기다리면 이렇게 된다 —

```
문서를 청구한다 → 사무국이 바쁘다 → 2주 → 3주 →
그동안 뭉클이는 아무것도 안 한다 → 아무도 이 물건을 안 쓴다 → 잊힌다
```

**A 무리로 답할 수 있는 질문이 이미 있다.**

| A 로 답할 수 있는 것 | A 로 답할 수 **없는** 것 |
|---|---|
| 협회가 무엇을 하는 곳인가 | 정산 서류를 어떻게 내나 |
| **올해 무슨 사업을 하는가** (8개, 이름·소개) | 그 사업의 **지침이 무엇인가** |
| 어떤 사업을 하는가 | 이 지출이 인정되나 |
| 언제 생겼고 누가 있나 | 이사회가 뭘 의결했나 |
| 연락처 · 주소 | 올해 예산이 얼마인가 |

> **범위를 좁혀서 시작한다.**
> 답할 수 있는 것만 답하고, 나머지는 **「모릅니다 · 찾아본 곳 …」** 으로 돌려준다.

이건 물러서는 게 아니다. `협회/02_QA_구조.md` §2 에 이미 적어 둔 규율이다 —
**아는 것만 답하고, 모르면 「모릅니다」라고 한다.**
재료가 적으면 「모릅니다」가 많아질 뿐, 규율은 그대로다.

★ 그리고 「모릅니다」가 쌓이면 **어느 문서가 급한지 저절로 드러난다.**
   질문이 몰리는 쪽부터 받으면 된다. 지금 넷의 순서는 짐작이고, 그건 실측이다.

## 3. 청구 목록 — 넷

받는 순서를 매겼다. **위에서부터 한 종씩** 받아도 된다. 넷을 묶어 기다리지 않는다.

### 1순위 · 진행 중인 사업의 지침 · 요강

| | |
|---|---|
| **왜 먼저** | 질문이 가장 많이 나오는 곳. 그리고 **틀리면 환수**다 |
| **무엇을** | 지금 진행 중인 사업 전부. 공고문 · 운영지침 · 정산지침 · 서식 |
| **형식** | 원본 그대로. 한글·PDF·스캔 무엇이든 |
| **★ 꼭** | **개정 날짜**. 낡은 지침으로 답하면 그게 오답이다 |

### 2순위 · 정관 · 회칙

| | |
|---|---|
| **왜** | 한 번 받으면 오래 간다. 「누가 정하나」 질문의 바닥 |
| **무엇을** | 현행 정관 1부. 개정 이력이 있으면 최신본 |
| **형식** | 무엇이든 |

### 3순위 · 작년 사업계획서 · 정산보고서

| | |
|---|---|
| **왜** | 지침이 「이렇게 해라」면 이건 **「작년엔 이렇게 했다」**다. 실제 사례가 답을 구체적으로 만든다 |
| **무엇을** | 직전 회계연도 것 1세트 |
| **★ 주의** | 정산보고서에 **거래처·계좌**가 붙어 있으면 그 장은 빼고 주십사 한다 |

### 4순위 · 이사회 · 총회 회의록

| | |
|---|---|
| **왜 나중** | 결정의 근거지만 **개인 발언이 섞인다.** 넣기 전에 한 번 더 봐야 한다 |
| **무엇을** | 의결사항만 추린 것이면 더 좋다 |
| **★ 주의** | 발언자 실명·인사 논의가 있으면 **넣지 않는다** |

## 4. 청구하지 않는 것 — 경계선

| | 왜 |
|---|---|
| **회원 명부** | Q&A 에 필요 없다 |
| **계좌 · 통장 사본** | 필요 없다 |
| **장애 유형 · 진단서** | 필요 없다 |
| **인사 기록 · 급여** | 필요 없다 |

> **없으면 새어나갈 수도 없다.**

사무국에서 문서를 보낼 때 이것들이 **끼어 있으면 빼고 보내달라**고 미리 말한다.
받은 뒤에 지우는 것보다 안 받는 게 낫다.

## 5. 시저님이 사무국에 그대로 보내실 수 있는 문장

```
사무국에 부탁드립니다.

AI 비서에게 사무 질문(정산·지침·행사)을 물어보면 답하도록
준비 중인데, 근거로 삼을 문서가 필요합니다.
아래 순서대로 있는 것부터 주시면 됩니다. 한꺼번에 아니어도 됩니다.

1. 지금 진행 중인 사업의 지침·요강·정산지침·서식
   ※ 개정 날짜가 보이게 (파일명이나 표지에)
2. 현행 정관(회칙)
3. 작년 사업계획서와 정산보고서
4. 이사회·총회 회의록 (의결사항 위주면 더 좋습니다)

형식은 한글·PDF·사진 무엇이든 원본 그대로 주시면 됩니다.

★ 다음은 보내지 말아 주십시오 —
  회원 명부 · 계좌·통장 사본 · 장애 유형이나 진단서 · 인사/급여 기록
  질문에 답하는 데 필요 없고, 받지 않으면 새어나갈 일도 없습니다.
  문서에 섞여 있으면 그 장은 빼고 주십시오.
```

## 6. 그동안 뭉클이가 할 것

| | |
|---|---|
| **한다** | A 무리(홈페이지 기반)만으로 **0단계** 시작 — 읽고, 「이렇게 답했을 것」을 시저님께만 보고 |
| **한다** | 답 못 한 질문을 **모아 둔다** — 어느 문서가 급한지 이게 알려준다 |
| **안 한다** | 없는 문서를 짐작해서 답하지 않는다 |
| **안 한다** | A 무리를 「사무국 문서인 척」 근거로 달지 않는다 — **근거 줄에 「홈페이지 공개정보」라고 밝힌다** |

★ 마지막 줄이 중요하다.
  홈페이지에서 온 답과 지침에서 온 답은 **무게가 다르다.**
  같은 모양으로 근거를 달면 직원분이 구별할 수 없다.
