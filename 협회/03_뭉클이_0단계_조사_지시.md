## 순서 — 이것부터 하지 않는다

**지금 뭉클이 손에는 그래프 쓰기 문(`graph/02`)이 있다.**
그것이 끝난 뒤에 이 조사를 시작한다. **한 번에 하나만 바꾼다.**

---

## 이 조사의 계율

```
자격증명 없이 한다. 어디에도 로그인하지 않는다.
「무엇이 필요한가」만 알아온다. 「해보는」 것이 아니다.
```

협회 메일 계정도 채널톡 계정도 **아직 뭉클이에게 주지 않았다.**
주기 전에 **무엇을 주게 되는지**를 먼저 알아야 한다.

---

## ★ 먼저 알아둘 것 — 메일은 채널톡과 다르다

시저님이 확인해 주셨다: **채널톡에는 계좌번호·장애정보가 올라오지 않는다.**

**메일은 다르다.** 메일은 **밖에서 온다.** 누가 무엇을 보낼지 우리가 정할 수 없다.
기관이 계좌번호를 적어 보낼 수도, 회원이 주민번호를 적어 보낼 수도 있다.

그래서 0단계의 규칙은 이것이다:

```
메일 본문을 저장하지 않는다.
읽고 → 분류하고 → 보고하고 → 버린다.
남기는 것은 분류 결과와 기한뿐이다.
```

없으면 새어나갈 수도 없다.

■ 누가 말하는가

  조사다. 구축이 아니다.

  · 협회 메일함이나 채널톡에 접근을 시도하지 마라
  · 코드를 짜지 마라 (다음 단계다)

■ 답할 것 — 세 갈래

━━ A. 채널톡 Open API

  A-1 어느 요금제부터 열리나. 월 얼마인가
      ★ 협회가 돈을 더 내야 하는 일이면 시저님 결정 사항이다.
        금액을 정확히, 출처 링크와 함께 적어라. 어림하지 마라

  A-2 대화(메시지) 조회가 되나. 어디까지 되나
      과거 기록을 얼마나 거슬러 읽을 수 있나 · 건수/기간 제한 · 호출 한도

  A-3 답장 쓰기도 되나
      지금 쓸 것은 아니다. 되는지만 확인해라 —
      「나중에 열 수 있는 문」과 「영영 없는 문」은 설계가 다르다

  A-4 API 가 안 열리면, 공식 문서가 제시하는 다른 통로가 있나
      (웹훅 · 내보내기 · 알림 전달 등)
      ★ 네가 대안을 지어내지 마라. 문서에 있는 것만 적어라.
        없으면 "문서에 없음"이라고 써라

━━ B. 메일 읽기 — 무엇이 필요한가

  협회 메일이 어디 있는지는 아직 모른다. 세 경우를 모두 알아와라.
  (지메일 / 네이버 / 자체 도메인)

  B-1 각각 읽기에 무엇이 필요한가
      앱 비밀번호인가 · OAuth 인가 · IMAP 을 따로 켜야 하나

  B-2 ★★ 읽기만 열고 발송은 막을 수 있는가
      이것이 이 조사에서 가장 중요한 질문이다.
      우리 설계는 「발송은 언제나 사람」이다.
      그런데 계정 권한이 발송까지 열려 있으면
      그 규율은 코드가 아니라 약속이 된다.

      2026-09-07 에 우리는 같은 실수를 봤다 —
      is_stale 이 절차에만 있고 코드에 없어서 아무것도 막지 못했다.
      **막고 싶으면 막을 수 있는 자리에서 막아야 한다.**

      IMAP(읽기)만 켜고 SMTP(발송)는 끌 수 있는가 / 없는가.
      제공사별로 답해라.

  B-3 2단계 인증이 켜져 있으면 무엇이 달라지나

━━ C. VPS 쪽 준비 상태

  C-1 VPS 에서 밖으로 IMAP 연결(993)이 나가는가. 방화벽에 막히는가
      ※ 실제 계정으로 붙지 마라. 포트가 열려 있는지만 봐라
  C-2 필요한 파이썬 라이브러리가 이미 깔려 있나 (imaplib 은 표준이다)

■ 조사하지 말 것 — 시저님이 답하실 것이다
  · 협회 메일이 어디 호스팅인가
  · 채널톡 요금제가 지금 무엇인가
  · 하루 메일이 몇 통쯤 오나
  · 메일 계정이 공용인가 개인별인가
  이 넷은 묻지도 추측하지도 마라. "시저님 확인 사항"이라고만 적어라.

■ 보고 형식
  A-1~4 / B-1~3 / C-1~2 번호 그대로.
  각 항목에 출처(문서 URL 또는 명령과 출력)를 함께.
  확인 못 한 것은 "확인 못 함". **추정을 확인처럼 쓰지 마라.**

■ 막히면
  "제 권한 밖입니다"라고 써라.
  다른 자격증명을 찾거나 계정에 붙어보려 하지 마라.

## 조사가 오면 갈리는 길

| A-1 결과 | 다음 |
|---|---|
| 지금 요금제로 열린다 | 바로 0단계 관측 설계 |
| 상위 요금제가 필요하다 | **시저님 결정.** 금액 대비 값어치를 함께 본다 |
| 아예 안 열린다 | A-4 의 다른 통로로. 그것도 없으면 **채널톡 Q&A 는 접고 메일만 간다** |

| B-2 결과 | 다음 |
|---|---|
| 읽기만 열 수 있다 | **그렇게 한다.** 규율이 코드가 된다 |
| 못 나눈다 | 발송 가능한 권한을 주게 된다 → **시저님께 그 사실을 명확히 알리고 결정을 받는다.** 「조심하겠습니다」로 넘어가지 않는다 |

**메일은 채널톡보다 먼저다.** 시저님이 그렇게 지목하셨고,
놓치면 복구가 안 되는 쪽이 메일이기 때문이다.
