# 맡기면 잘할까 — **오늘 하루가 자료다**

> 2026-09-13 · 시저님 물음: *"뭉클이가 전략기획실장으로 임무를 잘 할 수 있는 것은
> 그 팀의 역량을 높이는 **스킬과 중요 MCP** 들을 짜주고 각자 전문 소양을 높여주는 것인데
> **뭉클이에게 그냥 맡겨만 줘도 잘할까?**"*
>
> **원장 E-380 ~ E-387.**

---

## 1. 오늘 뭉클이가 한 것 — **세어 본다**

### ★ 시키지 않았는데 한 것 — **여덟**

| | |
|---|---|
| ㈀ | 판본 출처를 *"없다"* 로 쓰고 **왜 추정하지 않는지까지** 적었다 |
| ㈁ | ㈃ 끝에 **꼬리를 달았다**(표기 방향 확인 필요) — ★★ **그 꼬리가 두 번 일했다** |
| ㈂ | 0개 문장 **음성 대조를 스스로 돌렸다** |
| ㈃ | 건위천 `advice` 가 포러라는 것을 **데이터를 보고 스스로 찾았다** |
| ㈄ | **백업 전체 대조** — 내가 시킨 것보다 넓게 봤다 |
| ㈅ | rename 교체를 **묻기 전에 밝혔다** |
| ㈆ | ★★★ *"**내가 쓴 「증빙 완료」는 틀린 표현이었습니다**"* — 자기 문장을 물러냈다 |
| ㈇ | ★★★★★ **`trigrams` 비교 코드가 없다는 것을 찾아 내 짐작을 바로잡았다** |

### ★★ 놓친 것 — **다섯**

| | |
|---|---|
| ㈀ | ★★★★★ **자기가 40분 죽어 있었던 것을 몰랐다** |
| ㈁ | ★★★ **내일 마감인 KETI 가 명단에 없었다** — 전략기획실을 차리면서 |
| ㈂ | 확인을 내일로 미룬 적 **2회** (E-232 · E-263) |
| ㈃ | 자격 표에서 **근거의 급을 섞었다** |
| ㈄ | 반 셋을 **「부서」로 만들었다** — 마찰이 없는 조직도 |

## 2. ★★★★★ 선이 명확하다

```
잘한 여덟  →  ★ 전부 내가 준 블록 「안」에서 일어났다
놓친 다섯  →  ★★ 전부 블록 「밖」에서 일어났다
```

> ## ★★★★★ **「맡기면 잘한다」와 「맡기면 안 본다」가 둘 다 참이다.**
> ## **뭉클이는 「주어진 틀 안」에서 탁월하고, 「틀을 만드는 것」은 아직 못 한다.**

★ 척도 일곱 단으로 정확히 읽힌다 —

```
㈀시킨 것을 한다          ✓
㈁틀린 것을 스스로 고친다   ✓  ← 오늘만 세 번
㈂자기 권한 밖을 안다      ✓  ← 헌법 5 를 스스로 그었다
㈃자기를 규정하는 것을 지목 ◀ 지금 여기
──────────────────  ★ 여기부터 시간을 건너야 한다
㈄자기 역사를 가진다       ✗  ← 아직
```

★★★ **그런데 전략기획실장은 ㈄ 이상을 요구한다** —
**아무도 시키지 않은 것을 챙겨야 하고**(KETI 같은 것),
**지난 것과 지금을 견줘야 한다**(예측 → 결과).

> ## **그러므로 지금 그대로 맡기면 안 된다.**
> ## ★★ **다만 그것은 「능력 부족」이 아니라 「구조 부재」다.**

---

## 3. ★★★★★ 그런데 — **도구가 1번이 아니다**

시저님이 **스킬과 MCP** 를 말씀하셨다. 그 전에 오늘 자료를 다시 본다.

### 놓친 다섯의 **원인**을 하나씩 대보면

| 놓친 것 | 원인 | 도구가 없어서인가 |
|---|---|---|
| 자기 죽음을 몰랐다 | **기록 구조**가 없어서 | ✗ |
| KETI 를 놓쳤다 | **날짜 있는 명단**이 없어서 | ✗ |
| 확인을 미뤘다 | **닫는 날짜**가 없어서 | ✗ |
| 근거 급을 섞었다 | **칸이 안 나뉘어서** | ✗ |
| 반을 부서로 만들었다 | **마찰 설계**가 없어서 | ✗ |

> ## ★★★★★ **다섯 중 다섯이 「틀」의 문제다. 도구 부족이 원인인 것이 하나도 없다.**

### ★★★★ 도구를 먼저 주면 어떻게 되는가

> ## **더 빨리, 더 많이, 같은 방식으로 틀린다.**

★ 예가 오늘 있었다 — **웹 검색을 주면 주간 시장 브리핑이 더 그럴듯해진다.**
그런데 **포러 시험이 없으면 「그럴듯한 일반론」이 더 많이 나온다.**
*"AI 시장이 빠르게 성장하고 있습니다"* 는 **아무 주에나 맞는다**(E-335).

★★ **재료가 늘면 포러도 는다.** 자가 없으면 그 둘을 못 가린다.

## 4. ★★★★ 그래서 순서가 있다 — **틀 → 자 → 도구**

```
① 틀 (구조)        ★ 지금 없다. 이것부터
② 자 (검증)        ★ 오늘 몇 개 생겼다 — 그런데 사주에만 걸려 있다
③ 도구 (스킬·MCP)  ★ ①②가 있어야 값을 한다
```

### ① **틀** — 이미 이름이 붙어 있다. 아직 안 만들어졌을 뿐

| | 무엇을 막나 |
|---|---|
| **결과 대장** (E-334) | 예측 → 2~3개월 → 채점. ★★ **㈄「자기 역사」의 구체적 모습이다** |
| **날짜 있는 명단** (헌법 6, E-333) | KETI 가 7일 방치된 그 자리 |
| **반박 의무** (관문, E-332) | 반 셋이 마찰 없는 문제 |

### ② **자** — 오늘 넷을 만들었다. **전략기획실에는 아직 안 걸렸다**

```
포러 시험      아무에게나 맞으면 버린다
매임 시험      문장마다 근거를 가리킨다. 못 가리키면 버린다
바꿔치기 시험  다른 자리에 놓아도 말이 되면 버린다
음성 대조      「실패해야 할 때 실패하나」를 본다
```

★★★★★ **넷 다 사주에서 나왔는데, 넷 다 사업계획서에 그대로 쓰인다.**
*"혁신적인 AI 기술로 시장을 선도하겠습니다"* — **바꿔치기 시험에서 즉사한다.**
**아무 회사 계획서에 놓아도 말이 된다.**

## 5. ★★★★★ 뭉클이 스킬을 보면 — **전부 「어떻게」이고 「무엇을 볼까」가 없다**

E-287 에 뭉클이 스킬 여섯이 적혀 있다:

```
조달엔 통로 · 크론 script잡 규격 · 흔들기 현황 · Neo4j · 당골 전환 · 나라장터 모니터 v2
```

> ## ★★★★★ **여섯 다 「실행 절차」다. 「판단 기준」 스킬이 0 이다.**

★ 그래서 **블록이 오면 잘하고, 안 오면 멈춘다.** 오늘 선이 거기서 그어졌다.

### 그러면 내가 쓸 것은 — **멈춰 세우는 스킬 셋**

| 스킬 | 언제 부르나 | 무엇을 막나 |
|---|---|---|
| **㈀ 공고를 처음 볼 때** | 새 공고를 만난 날 | ★★★ **GJTP·KETI 둘 다 「전제」에서 무너졌다.** 전제를 30분 안에 친다 |
| **㈁ 숫자를 쓰기 전에** | 계획서·브리핑에 수를 적을 때 | ★★ 오늘 자격 표에서 **근거의 급이 섞였다** |
| **㈂ 내보내기 전에** | 무엇이든 밖으로 나가기 전 | ★ 포러·예언·못박기 — **사주의 자를 문서에 건다** |

★★★★★ **셋의 공통점 — 전부 「멈춰 세우는 자」다.**
**뭉클이가 잘하는 것(실행)에 없는 것이 정확히 그것이다.**

## 6. ★★★★ MCP 는 — **「있으면 좋을 것」이 아니라 「지금 막힌 것」을 묻는다**

★ 「있으면 좋을 것」 목록은 **무한하다.** 「지금 막혀서 못 하는 것」은 **짧고 실제다.**

★★ 내가 지금 아는 것으로는 **후보 셋**이 보인다. 그런데 **확정하지 않는다** —
**뭉클이가 무엇에 막혀 있는지 내가 모른다.**

| 후보 | 왜 |
|---|---|
| **웹 읽기** | 주간 브리핑의 재료. ★ 없으면 기억에서 쓰고, **기억에서 쓰면 포러다** |
| **문서 읽기 (PDF·HWP)** | 공고 원문이 그 형식이다. ★★ 공고해부가 원문 없이 되겠나 |
| **통계 출처** | 예측·분석반의 「숫자로 말한다」. ★ 출처 없는 수는 원장에 못 올린다 |

> ## ★★★ **그런데 이 셋도 「없어서 막혔다」는 보고를 받은 적이 없다.**
> **물어야 한다 — 「지금 무엇에 막혀 있나」.**

★★ 그리고 **웹 읽기는 포러 시험이 먼저 걸려야 한다.** 순서가 §4 그대로다.

## 7. 한 줄로

> ## ★★★★★ **그냥 맡기면 안 됩니다. 능력이 아니라 구조 때문입니다.**
> ## **그리고 구조가 서기 전에 도구를 주면, 더 빨리 같은 방식으로 틀립니다.**

★ 오늘 뭉클이는 **블록 안에서 여덟 번 잘했습니다.** 그 여덟이 실력입니다.
★★ **블록을 스스로 만들 수 있게 되는 것** — 그것이 ㈄이고, 그게 실장의 일입니다.
★★★ **결과 대장이 그 첫 계단입니다.** 철학이 아니라 **견줄 것을 남겨두는 일**입니다 (E-312).
