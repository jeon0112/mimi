## 2. ★★★★★ 그런데 한 칸이 안 재졌다 — 그 한 칸이 전부를 정한다

뭉클이 실측은 **「나→나 247통」**이다. **자기 계정 안에서 쟀다.**

```
GMAIL_USER    발송 계정  ← 뭉클이가 자격을 갖고 있다
NOTIFY_EMAIL  수신 주소  ← 🔴 이게 같은 계정인가 다른 계정인가가 안 재졌다
```

| | |
|---|---|
| **같은 계정이면** | 브리핑이 뭉클이 자격이 닿는 함에 있다 → **고정점은 안이다** |
| **다른 계정이면** | 뭉클이는 그 함에 손이 닿지 않는다 → **고정점은 이미 밖이다. 고칠 것이 없다** |

> **이 한 칸을 재기 전에 A·B·C 를 고르면, 이미 밖에 있는 것을 옮기는 일이 될 수도 있다.**

★ 값은 출력하지 않는다. **「같다 / 다르다」 한 단어면 된다** (E-352 식 규율).

```

```

> ★★★★ **메일 하나가 영구히 사라졌는데 감사 행이 늘지 않았다.**

⚠ 그 시험은 **내 지시로 승인된 것**이다. 문제는 승인 여부가 아니다.
**게이트를 안 거쳐도 되는 행동은 있지만, 기록이 없어도 되는 행동은 없다.**
