# 스킬 ㈁ — **숫자를 쓰기 전에**

> 언제 : 계획서·브리핑·보고에 **수를 적을 때.**
> 왜 : 2026-09-13 자격 표에서 **근거의 급이 섞였다** — 「법인 확정」과 「유효기간 미확인」이 한 칸에 있었다.

---

## 1. 수에는 **출처가 붙는다.** 붙일 수 없으면 칸을 바꾼다

```
A. 잰 것      ★ 내가 세거나 돌려서 나온 값.  "무엇을 어떻게 셌나" 를 적는다
B. 받은 것    ★ 공고문·통계·시저님 보증.     "어디서 왔나" 를 적는다
C. ★★ 가설    ★★★ 근거가 없는 값. "가설" 이라 적으면 쓸 수 있다
```

> ## ★★★★★ **C 가 있다. 근거가 없다고 수를 못 쓰는 게 아니다.**
> **「가설」이라 적고 쓰면 된다. 감추고 쓰면 그게 허위다.**

★ 원장 종류에 **「물음」**이 그 자리다. 오늘 안토니우스도 자기가 모르는 것을 물음으로 올렸다(E-373).

---

## 2. 「시저님 보증」은 **B 다. 정당한 출처다**

★★ 대표가 자기 회사 등록증을 보고 말하는 것보다 앞선 1차 정보는 없다 (E-377).
★ 적는 법 — **`시저님 보증 (날짜) — 무엇을 보고`**. 이러면 A·B·C 가 갈린다.

---

## 3. ★★★ 급을 섞지 않는다 — **한 칸에 한 급**

```
✗  자격 | 법인 : 블루바이오(확정) | 유효기간 : 미확인
      ★ 같은 근거에서 나왔는데 하나는 확정, 하나는 미확인이다. 앞뒤가 안 맞는다

✓  A(증서를 봤다) 칸  /  B(못 봤다) 칸  을 나눈다
      ★★ 그리고 A 가 0 이면 0 이라고 적는다. 0 은 정확한 값이다
```

---

## 4. **「모른다」와 「없다」는 다른 값이다**

```
모른다  →  ★ 매번 다시 묻게 된다
없다    →  ★★ 한 번으로 끝난다
```

★ 중증장애인생산품을 **「없다(종결)」**로 닫은 것이 좋은 예다.
★★ 확인해서 없으면 **「없다」로 닫아라.** 그게 일을 줄인다.

---

## 5. 게이트 — **낮추지 않는다**

★ 코인퀀트 쪽 숫자(t>3 · DSR 0.95 · MDD 35% · TARGET_SHARPE 1.5 · **paper 400건**)는
**결과가 안 나온다고 낮추지 않는다.** 낮추면 그 뒤 모든 판정이 무의미해진다.
