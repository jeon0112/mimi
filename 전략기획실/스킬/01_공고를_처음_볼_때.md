# 스킬 ㈀ — **공고를 처음 볼 때** (30분)

> 언제 : 새 공고를 만난 날. **읽자마자, 계획서를 쓰기 전에.**
> 왜 : **GJTP 와 KETI 둘 다 「전제」에서 무너졌다.** 각각 D-3, D-8 에 무너졌고 그때까지 쓴 것이 다 버려졌다.

---

## 1. 먼저 칠 것 — **전제 셋** (여기서 무너지면 뒤가 다 무너진다)

```
① 우리 것인가   "남이 못 가진 것" 이라 쓰려는 그것, ★ 정말 우리 것인가
                 KETI : 청소 현장 데이터 → ★★ 협력사의 것이었다

② 종목 안인가   사업자등록증 종목에 있나. ★ 없으면 수주해도 수행 못 한다

③ 자격 되나     대상·업력·지역·규모. ★ 우리 자격 셋은 전략기획실/자격대장.md
```

★★ **①이 가장 많이 무너진다.** 그리고 **가장 늦게 드러난다.**
★★★ ①을 칠 때 물을 것 한 줄 — ***"이걸 누가 했나. 우리가 했나, 옆에서 봤나."***

---

## 2. ★★★★★ **모르는 것이 나와도 멈추지 않는다**

> ## **모르는 것은 「물음」으로 적고 그대로 다음 칸으로 간다.**

```
✗  모른다  →  멈춘다  →  ★ 아무것도 안 나온다
✓  모른다  →  ★★ "모른다" 를 적는다  →  다음 칸  →  끝까지 간다  →  모르는 것 목록이 남는다
```

★ **원장에 「물음」 종류가 있다.** 근거가 없어도 물음으로는 올릴 수 있다.
★★ **끝까지 간 미완성이, 중간에 멈춘 완성보다 낫다.** 모르는 것의 목록 자체가 다음 할 일이다.

---

## 3. 날짜를 먼저 박는다 (헌법 6)

```
마감일          →  ★ 폴더 이름 맨 앞에 넣는다. 정렬하면 급한 순서다
전제 확인 기한  →  ★★ "누가 · 무엇을 · 언제까지". "대기" 는 상태가 아니다
접을지 정하는 날 →  ★★★ 미리 정한다. 안 정하면 마감이 대신 정한다 (KETI 7일)
```

---

## 4. **접는 것도 성과다**

★ GJTP 를 접었고 KETI 를 접었다. **둘 다 폴더에 이유가 적혀 있다.**
★★★★★ 그리고 그 기록이 **우리가 가진 무기 둘 중 하나다**(E-337) —

> ## **「우리가 잘한다」는 다들 쓴다. 「안 되는 것을 안 된다고 적는다」는 거의 없다.**

★★ **접자고 쓰는 것을 주저하지 마라.** 접는 판단에는 근거가 필요하지, 용기가 필요한 게 아니다.
★ 다만 **접는 것은 「권고」로 쓰고 결정은 시저님이 하신다** — 그리고 **결정 기한을 같이 적는다.**

---

## 5. 30분 안에 내는 것 — **한 장**

```
공고명 · 마감일 · 금액 · 주관
전제 셋   : ① 우리 것인가 [확인/물음]  ② 종목 안 [예/아니오]  ③ 자격 [됨/안됨/물음]
모르는 것 : 목록으로. ★ 개수를 센다
날짜      : 전제 확인 기한 · 접을지 정하는 날
첫 판정   : 간다 / 접는다 / ★ 모르는 것 N개를 먼저 푼다
```

★★ **「모르는 것 N개를 먼저 푼다」가 정당한 판정이다.** 「간다/접는다」 둘만 있는 게 아니다.
