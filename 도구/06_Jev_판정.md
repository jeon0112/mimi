# Jev — 판정을 먼저 박고 쟀다

> 2026-09-22 · 안토니우스
> 시저님 지시: *「jev 에 대해 연구해서 뭉클이에게 제대로 적용하게 해봐. 내가 어떤 액션을 해야 할까?」*
> 근거: 원장 E-712 ~ E-718

---

## 1. 보기 전에 박은 판정 (4/4 맞음)

```
맞을 자리    ① 공고 필터링 (나라장터·정부지원) — 지금 Sonnet 20건 배치
             ② 브리핑 축 셋 (닿음·되돌릴수없음·놀라움)
             ③ 퀀트 신호 판정 (진입/관망)
안 맞을 자리  사주 서사 · 계획서 작성 · 대화
가장 큰 위험  한국어를 다루나
```

**넷 다 맞았다. 어제 Graft 는 0/4 였다**(E-570).

### ★ 그런데 이번이 쉬웠다는 것을 밝힌다

**Jev 는 「판단 전용」이라고 이름표가 명확하다.**
**Graft 는 「코드 지식 그래프」라 무엇에 쓰이는지 애매했다.**

**어려운 문제를 맞힌 것이 아니라 쉬운 문제였다. 4/4 를 실력으로 세지 않는다.**

## 2. 실측 (검색으로 확인한 값)

| | 값 |
|---|---|
| **가격** | **입력 $0.042/M · 출력 $0.00/M** · 결정 하나 평균 **$0.0004** |
| **속도** | **70~500ms** |
| **질문 형태 셋** | **Choice**(고르기) · **Score**(등급) · **Noul**(예/아니오 확률) |
| **출력** | **스키마 밖 값을 못 낸다** — 형식 에러 구조적 차단 |
| **확신도** | 모든 답에 **보정된 confidence** — 낮으면 사람에게 넘기라고 설계됨 |
| **접근 경로** | **OpenRouter · Cloudflare Workers AI** 등 여럿 |
| 🔴 **언어** | **50개 이상 사전학습** — 스페인·독일·프랑스·**일본**·중국어 **명시**. **한국어는 명시 없음** |

### ★ 출력 토큰이 $0 인 이유

**글을 안 쓰기 때문이다.** 고르기만 한다.
**그래서 싸고 빠른 것이고, 그래서 서사에는 못 쓴다.** 값과 한계가 같은 뿌리다.

---

## 3. ★★★★★ 우리에게 제일 맞는 것은 속도가 아니라 **확신도**다

**원장이 이미 그 자리를 여러 번 팠다.**

> **E-642**: *「52% 산출 근거 없음」 — 확률을 내려면 산출식을 같이 내고, 못 내면 확률을 쓰지 말고 조건만 쓴다*
> **금칙**: *「없는 값은 절대 지어내지 마라. 비면 비운 채로 둬라」*

**Jev 는 그것을 구조로 강제한다 — 답마다 확신도가 따라오고, 낮으면 넘기게 되어 있다.**

**어제 연구두뇌가 스스로 비판한 그 결함을, 이 도구는 설계로 막는다.**

---

## 4. 🔴 그런데 — **「보정됐다」는 TypeSafe 의 자기 신고다**

**RLCD 로 확신도를 정확도에 맞췄다고 회사가 말한다.**

> **어제 graft 의 「토큰 99% 절감」과 같은 자리다**(E-576).
> **판정의 재료가 피고인의 자기 신고면 안 된다.**

### 그리고 이건 우리가 직접 잴 수 있다

```
확신도 0.9 로 낸 판정 100개 중 실제로 몇 개가 맞았나?
   → 90개면 보정된 것이다.  70개면 안 된 것이다.
```

**이것이 보정(calibration)의 정의이고, 우리는 잴 재료가 있다 — 240판 · 공고 이력 · 원장.**

**★ 그리고 이 시험은 Jev 를 붙이기 전에는 못 한다. 붙인 뒤 첫 달에 재는 항목으로 둔다.**

---

## 5. 🔴 첫 관문은 **한국어**다

**50개 언어 목록에 스페인·독일·프랑스·일본·중국어는 이름이 있는데 한국어는 없다.**

**「50개에 포함될 것」은 추론이지 값이 아니다.**

> **우리 일은 전부 한국어다 — 사주 · 공고 · 브리핑 · 협회 문서.**
> **한국어가 안 되면 나머지 장점이 하나도 우리 것이 아니다.**

**그래서 이것이 1번이고, 나머지는 전부 그다음이다.**

| ✅ | **브리핑 축 셋** (닿음·되돌릴수없음·놀라움) | 아직 없음 | **Score 셋.** 기계 판정이 먼저 돌고 사람이 마지막 |

**뭉클이를 Jev 로 바꾸는 것이 아니다.**
**뭉클이가 판단할 때 부르는 도구를 하나 더 주는 것이다.**

**뭉클이는 대화하고 글을 쓴다. Jev 는 못 한다.**
