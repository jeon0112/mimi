# VPS 호스트에 두는 것 — **컨테이너 밖**

> 여기 있는 것은 **뭉클이가 못 만듭니다.** 뭉클이는 `hermes-vps` 컨테이너 안에 살고,
> 이것들은 **그 밖(호스트)** 에 있어야 뜻이 있습니다.
> **설치는 시저님이 VPS 콘솔에서 하십니다.**

| 파일 | 무엇 | 왜 밖인가 |
|---|---|---|
| `gw-watchdog.sh` | 게이트웨이가 `down` 이면 1분 안에 되살린다 | ★★★ **안에 있으면 같이 죽습니다** (E-215 · E-249) |

---

## `gw-watchdog.sh`

**2026-09-13, 게이트웨이가 40분간 죽어 있었습니다.** 자기를 재시작하다
`s6-svc -d`(내려라)에서 자기가 죽어 `s6-svc -u`(올려라)가 **영원히 실행되지 않았습니다.**
(`quant/07_40분간_죽어_있었다.md` · E-252)

### 보는 것

```
s6-svstat  →  "down (exitcode 0) ... normally up"   ★ 이것이 진실이었다
docker ps  →  "Up 6 days"                           ★ 컨테이너는 살아 있었다 (E-254)
```

★★ **「떠 있다」가 증거가 아닙니다**(E-14). **컨테이너가 떠 있는 것과 그 안의 서비스가 도는 것은 다른 말입니다.**

### 설치 — 호스트 `root` crontab, 1분마다

```
* * * * * /root/gw-watchdog.sh
```

★ 로그는 `/root/gw-watchdog.log`. **정상일 때는 아무것도 안 씁니다** — 줄이 있다는 것 자체가 사건입니다.

### ★★ 일부러 내리실 때

> **이 크론을 먼저 끄십시오.** 안 그러면 **1분 뒤 다시 올라옵니다.**

### 안 하는 것

★ **컨테이너 자체는 자동으로 켜지 않습니다.** `docker exec` 가 실패하면 **적기만 합니다** —
  컨테이너가 죽은 것은 **사람이 봐야 하는 일**입니다.
