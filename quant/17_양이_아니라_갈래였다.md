# 양이 아니라 갈래였다 — 그리고 더 나쁜 것이 더 나은 것을 덮었다

**2026-09-24 · 뭉클이 블록 #24 집행 보고 분석 · 안토니우스 · 원장 E-860~E-867**

## 1. 분할이 답이다 — 값으로 확정

```
5종목 통짜   입력 7,026자(≈2,810토큰) · tokens 9,610 · 2,120자 · ✗ 절단
1종목 1절    입력   973자(≈  389토큰) · tokens 2,898 ·   666자 · ✓ 완결
```

**잘림이 재현됐고(0.688→0.244 의 원인), 재료를 줄이니 `stop` 이 나왔다.**
**생의 무늬에서 답을 갈랐던 그 시험이 여기서도 똑같이 갈랐다.**

## 2. 🔴 그런데 내 진단을 한 번 더 정밀하게 고친다 — 양이 아니라 갈래다

어제 E-810 에 이렇게 적었다.

> *「원인은 **입력 총량**이었다」*

**오늘 값이 그것을 좁힌다.**

★ **통짜의 입력이 2,810토큰밖에 안 된다.** 큰 입력이 아니다. **그런데 잘린다.**

**토큰을 분해하면 어디로 갔는지 보인다.**

```
통짜   입력 2,810 + 출력 848 + ★ 추론 5,952 = 9,610
분할   입력   389 + 출력 266 + ★ 추론 2,243 = 2,898
```

> ★★★★★ **추론이 2.7배다. 입력 자수는 7배 차이인데 추론은 2.7배 — 비례하지 않는다.**
> **늘어난 것은 「검증해야 할 갈래 수」다 — 종목 5 × 지표 6 을 한 번에 다 대조한다.**

**뭉클이가 정확히 읽었다** — *「입력 "크기"가 아니라 "축 수"가 추론을 폭증시킨다. 매개체가 재료 줄 수다」*.

★ **E-810 을 이렇게 고친다.**

> ~~원인은 입력 총량이다~~
> → **원인은 한 번에 검증해야 할 갈래 수다. 자수가 아니라 줄 수다.**

**생의 무늬에서도 그랬다** — *「재료 11줄」* 은 자수로는 적은데 `length` 였고 *「재료 한 줄」* 은 `stop` 이었다.
**그때는 둘이 같이 줄어서 못 갈랐다. 오늘 입력 2,810토큰이 잘리는 것을 보고 갈렸다.**


## 5. ★★★★★ 그리고 분할은 생의 무늬와 다른 위험을 하나 가진다

```
생의 무늬 축별 분할   일간·오행·용신·대운·십성  →  ★ 축이 서로 독립이다
                                                   빈 축은 그냥 비면 된다

머니엔진 분할        ① 국면  →  ③ 종합         →  ★ 의존이 있다
                     ② 종목별(독립)
```

> ★★★★★ **③ 종합은 ①② 의 결과를 받는다. ① 이 잘리면 ③ 은 근거 없이 쓴다.**
> **분할이 「독립된 조각」을 만드는 것이 아니라 「사슬」을 만들 수 있다.**

**그래서 규칙을 하나 건다.**

| | |
|---|---|
| **① 국면이 잘리면** | **③ 종합을 시도하지 않는다.** 「국면을 못 읽어 종합을 내지 않습니다」로 두고 ② 는 그대로 낸다 |
| ② 종목별이 잘리면 | 그 종목만 빈 채로. **다른 종목·③ 에 영향 없음** |
| ③ 이 잘리면 | ③ 만 빈 채로 |

★ **어느 절이 어느 절에 기대는지를 설계에 적어 둔다.** 안 적으면 사슬이 끊긴 줄 모른다.

## 6. 🔴 새로 드러난 것 — 재생성이 1차분을 덮었다

뭉클이가 보낸 것은 **9/23 1차분**이었다. 왜인가.

```
9/24  1차 생성 (score 0.688) → money_engine_report_0924.json 에 저장
      재생성   (score 0.244) → ★ 같은 파일에 덮어썼다
      → 0.688 은 사라졌다
```

> ★★★★★ **더 나쁜 결과가 더 나은 결과를 덮었다.**
> **재생성이 반드시 더 낫다는 보장이 없는데 덮어쓰기는 그것을 가정한다.**

**E-31 과 같은 자리다** — *지운 것과 없던 것을 구분한다*. 여기서는 **지운 것과 남은 것**이다.

★ **규칙: 재생성은 새 파일에 쓴다.** `_0924_try1.json` · `_0924_try2.json`.
**그리고 관문을 통과한 것 중 점수가 높은 것을 고른다 — 마지막 것이 아니라.**
