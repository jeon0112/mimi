## 1. 한국투자증권 — 기술적으로 준비돼 있다는 시저님 말씀, 확인됨

**KIS Developers** — 한국투자증권 공식 오픈API 개발자센터.

- **REST API**, 국내주식·해외주식·선물/옵션 등 지원
- **OAuth 2.0** 인증 — 앱키(APP Key)·비밀키(APP Secret)로 액세스 토큰 발급
- ★★★ **모의투자용·실전투자용이 완전히 분리된 객체/환경으로 존재한다** — 이게 `quant/11` 이 요구한
  "①②(백테스트·페이퍼트레이딩)와 ③(실거래)를 가르는" 구조가 **증권사 쪽에서 이미 마련돼 있다는 뜻**이다
- 증권사 중 **국내 유일 순수 REST API 제공** — 공식 GitHub(`koreainvestment/open-trading-api`)와
  커뮤니티 라이브러리(`python-kis`)까지 있어 개발 난이도가 낮다
- 법인 명의 증권계좌 개설 자체는 국내에서 **일반적인 절차**다 (별도 특별법 제한 없음 — 아래 코인과 대조)

★★★★ **결론 — 한투 쪽은 법·유동성·기술 세 층이 전부 막힘없다.** `quant/11` 의 ①②를 오늘부터 시작해도 된다.

## 2. 코인거래소 — ★★★★★ 막힌 것은 API 가 아니라 법인 계좌다

### ㈀ 기술은 다 있다

업비트·빗썸·코인원·코빗(디지털X)·고팍스 **5대 원화거래소 전부 Open API 로 자동매매를 지원한다.**
업비트는 실시간 시세·잔고조회·주문생성/취소를 REST 로 제공하고, 디지털X 는 **AI 코딩 도구 연동 가이드까지** 준비해 뒀다.

### ㈁ ★★★★★ 그런데 법인이 원화 계좌를 못 연다 — 이게 진짜 벽이다

2017년 긴급대책 이후 **법인·기관투자자는 가상자산거래소의 실명입출금계좌를 발급받을 수 없다.**
2026년 현재 진행 상황(단계별 로드맵):

| 단계 | 대상 | 시행 여부 |
|---|---|---|
| 1단계 (2025 상반기) | **비영리법인**의 「매도 전용」 계좌 | **시행됨** |
| 2단계 (2025 하반기 예정) | **전문투자자 법인**(자본시장법상, 약 3,500곳 시범) 의 「매매용」 계좌 | ★★★★ **예상과 달리 아직 시행 안 됨** |
| 3단계 (추후) | **일반 영리법인** 전면 허용 | **논의만 있음 — 시행 시점 미정** |

★★★★★ **(주)미미와 (주)블루바이오는 비영리법인도, 자본시장법상 전문투자자 법인도 아니다.**
`CLAUDE.md` 어디에도 그런 등재가 없다 — 원장을 쳤어도 안 나온다. **일반 영리법인**이다.

> ## ★★★★★ **그러므로 지금 이 회사 명의로는 원화 실명계좌를 코인거래소에서 열 수 없다.
> 이건 기술 문제가 아니라 법적으로 막혀 있는 것이다.**

★★ **여기서 우회로를 찾지 않는다.** 개인 명의 계좌를 회사 자금으로 쓰는 것은 회사 자금과 개인 자금이
섞이는 것이고, 회계·세무상 문제를 새로 만든다. CLAUDE.md 의 "막히면 우회로를 찾지 않는다"가
바로 이런 자리를 위한 규율이다 — **"법인 계좌가 안 됩니다"라고 쓰는 것이 정확한 보고다.**

## 3. 디지털X(구 코빗, 박현주 회장 인수) — 개별 분석

### ㈀ 인수 사실관계

- 미래에셋그룹 계열 **미래에셋컨설팅**이 코빗 최대주주 NXC·2대주주 SK플래닛 지분 약 **97.15%를 1,414억원**에 인수, **2026-07-23 완료**
- **국내 금융그룹이 가상자산거래소 경영권을 직접 확보한 첫 사례**
- 사명을 **「Digital X」**로 변경
- 박현주 회장: 내년(2027년) 1분기 **2,000~3,000억원 추가 증자**, **2027년 흑자 전환** 목표 제시
- 전략: **RWA(실물자산 토큰화)·STO 중심** — "알트코인 상장은 범죄"라는 표현까지 쓰며 기존 거래소들의
  잡코인 상장 경쟁과 다른 노선을 택했다고 밝힘
- 미래에셋 그룹 보관 고객자산 1,500조원을 디지털자산 150조원으로 키우겠다는 목표

### ㈁ ★★★★★ 지금 시점의 실전 적합성 — 유동성이 발목을 잡는다

원화마켓 점유율(2026-06-18 기준, 가장 최근 수치):

```
업비트   67.1%
빗썸     29.9%
코인원    2.3%
코빗      0.6%    ← 디지털X
```

★★★★ **업비트·빗썸 두 곳이 97%를 과점하고 있고, 디지털X 는 1% 에도 못 미친다.**
(2월엔 12% 까지 갔었다는 자료도 있어 변동성이 크다 — 다만 최근값이 이 정도로 낮다는 뜻이다)

**알고리즘 전략에서 유동성이 낮다는 것은:**
- 호가창이 얇아 **슬리피지(체결가와 주문가의 괴리)가 커진다**
- 대량 주문 시 **가격을 스스로 밀어 올리거나 내리는 왜곡**이 생긴다
- 백테스트 조건과 실전 체결이 크게 벌어질 수 있다 — `quant/11` 이 요구한 "항구적 결과"의 신뢰도를 깎는다

### ㈂ 결론

★★★ **미래에셋의 그림(RWA·STO, 대규모 증자, 그룹 시너지)은 3~5년짜리 전략이지,
지금 당장의 트레이딩 유동성 문제를 해결해 주지 않는다.**
게다가 ㈀·㈁ 이전에 **2절의 법인 계좌 문제가 모든 거래소에 공통으로 걸려 있다** —
디지털X 가 미래에셋 것이라 해서 법인 계좌 예외가 생기지 않는다. 확인한 적 없고, 근거도 없다.

이걸 숨기지 않고 먼저 알려 드리는 것이 "실질적이고 분명한" 검토라고 판단했다.

## 5. 정정 — 코인은 개인 명의로 진행 (시저님 결정, 2026-09-24)

★★★★★ **2절의 법인계좌 벽이 이 결정으로 비켜간다.** 다만 **이건 우회가 아니라 처음부터 열려 있던
정상 경로다** — 막혀 있던 건 법인뿐이었고, 개인은 실명확인 입출금계정만 있으면 원래 거래할 수 있었다.
2절(E-578)은 여전히 사실이다. **적용 대상만 회사에서 시저님 개인으로 바뀐 것이다.**

### ㈀ 실질적 출발점 — 은행 실명계좌

거래소마다 제휴은행이 정해져 있고, **그 은행에 시저님 명의 실명인증 계좌가 있어야 입출금이 된다.**

| 거래소 | 제휴은행 | 비고 |
|---|---|---|
| 업비트 | **케이뱅크** | 계약 2026-10 만료 예정, 유지 유력 |
| 빗썸 | **KB국민은행** | 9-24(오늘) 만료 앞두고 1년 연장 추진 중 |
| 코인원 | **카카오뱅크** | 연장 예상 |
| 고팍스 | **전북은행** | — |
| 디지털X(구 코빗) | **신한은행** | 2018년부터 8년 연속, 12월 1년 연장 |

★ **시저님이 이미 실명계좌를 가진 은행이 있는지가 실제 출발점이다.** 없으면 그 은행 계좌 개설부터다.

### ㈁ 유동성 판단은 그대로 유효

법인이든 개인이든 **체결 품질(슬리피지)은 거래소 유동성에 달려 있다.** 3절의 결론은 안 바뀐다 —
**업비트(67%) 또는 빗썸(30%)이 알고리즘 전략엔 실질적 선택지**이고, 디지털X(0.6%)는 지금은 비권장이다.
다만 이건 개인 취향·리스크 선호의 영역이라 **최종 선택은 시저님 몫**이다.

### ㈂ 개인으로 바뀌며 새로 생기는 것 — 세금

★★★★ **개인 가상자산 소득에 2027-01-01부터 과세가 예정돼 있다.** 연 250만원 초과 수익에
22%(지방세 포함) 분리과세 — 2024년 12월 국회에서 2년 유예를 결정하며 정해진 시행일이다.
★★ **다만 확정은 아니다.** "네 번째 유예냐 강행이냐"를 다투는 기사가 같은 시점에 나온다 —
추가 유예 가능성이 남아 있다. **2026-12-31 이전 거래는 어느 쪽이든 과세 대상이 아니다.**

### ㈃ 설계에 남는 것 — API 키를 어디에 둘 것인가

개인 계좌의 API 키(자산 접근 권한)를 **회사 인프라인 뭉클이 VPS 에 둘 것인가**는 별개의 결정이다.
`graph/04_기존노드_이주_지시.md` 가 애초에 `money-engine`(수도승)을 **`vps-격리`**로 설계해 둔 것이
이 자리에서 값을 한다 — 개인 자금이라면 더더욱 본체와 격리된 자리에 두는 것이 맞다.
**다만 이것도 오늘 결론 내리지 않는다.** `quant/11` 6절의 킬스위치·승인게이트 논의와 같이 묶어
9시에 다룬다.
