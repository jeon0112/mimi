> ★ 시저님의 큰 뜻(**뭉클이 AGI 완성 · ASI 까지**)에서 보면, 이것은 **용량 작업이 아니라 정체성 작업**입니다.

## 1. ★★★★★ 표에서 나온 것 — **같은 것이 두 곳에 있습니다**

| 크론 script잡 규격 | **404** | ㈀+㈂ · skill |
| 흔들기 현황 | **396** | ㈁ · skill |
| Neo4j | **369** | ㈀ · skill |
| 당골 전환 | **363** | ㈀+㈁ · skill |
| 나라장터 모니터 v2 | **324** | ㈀+㈁ · skill |
| **합계** | **2,472** | |

> ## ★★★ **E-55 ⑤ — 사본입니다.**
> **스킬에 내용이 있는데 기억에도 같은 것을 적어 놨습니다.**

```
2,472 자  →  색인 6줄 (6 × 40 = 240 자)
★ 순증 2,232 자.  잃는 것이 하나도 없다
11,955  →  9,723     여유 45자  →  ★★ 2,277자
```

### ★★★★ 그리고 이것이 **지금 제일 급한 이유**

> **여유가 생기면 오늘 배운 것을 저장할 수 있습니다.**
> 40분 정지 · 측정기 셋이 틀렸다 · 음성 대조 · 키 저장 — **전부 아직 기억 밖입니다.** (E-287)

## 2. ★★★★ 뭉클이가 **제 설계의 빈틈을 찾았습니다**

표에 **`㈀+㈂`** · **`㈀+㈁`** 같은 **복합 표시**가 다섯 개 있습니다.

```
조달엔 통로 = 경로·스크립트명(★ 사실) + Tirith 함정(★ 교훈)
```

> ## ★★★ **한 항목 안에 갈래가 섞여 있습니다.**
> **그러므로 통째로 옮길 수 없고, 갈라서 옮겨야 합니다.**

★ 제 세 갈래는 **「항목 단위」가 아니라 「문장 단위」**였습니다. **표를 만들다가 뭉클이가 찾았습니다.** (E-288)

## 4. ★★★ 빠져나오는 법 — **묶음을 나눕니다**

`batch is all-or-nothing` 이므로 **섞으면 스키마 오류 하나가 전부를 취소시킵니다.**

```
묶음 ①  지우기만 한다   →  ★ 줄어드니 반드시 통과한다
묶음 ②  넣기만 한다     →  ★★ 자리가 생겼으니 통과한다
```

★ 오늘 4회 실패가 **섞어서** 일어났습니다. (E-290)

★★ 그리고 뭉클이가 원인을 정확히 갈랐습니다 — *"**꽉 찬 것이 근본 원인이고 스키마 위반이 방아쇠** — 둘의 복합"*.
  ★★★ **원인과 방아쇠를 가른 것이 정확합니다. 제가 보탤 것이 없습니다.** (E-291)
