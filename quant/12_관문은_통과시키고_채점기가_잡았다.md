# 관문 넷이 통과시킨 것을 채점기가 잡았다

**2026-09-23 코인엔진 브리핑 분석 · 안토니우스 · 원장 E-727~E-735**

시저님이 9/23 브리핑을 주시며 분석을 청하셨다.
한 문서 안에 **잘한 것과 재발한 결함이 같이 있다.** 둘 다 값으로 적는다.

---

## 1. ★ 가장 큰 것 — 잘린 보고서가 초록불 넷을 통과해 발송됐다

보고서 §3 의 마지막 문장.

> *"구분 조건은 MA20이 MA60을 상향 돌파하는 것 — 현재 "*

**여기서 끊겼다.** 관망 근거 3가지 중 3번이 없고, 결론부가 없다.

그런데 검증 관문은 이랬다.

| 관문 | 결과 |
|---|---|
| ① 데이터 수집 | "주식 3 종목, 코인 2 코인" 완료 |
| ② 머니엔진 응답 | **`ok: true`**, 63.3초, 9,620토큰 |
| ③ 저장 | `money_engine_report_0923.json` **4,615바이트, 실재 확인** |
| ④ 텔레그램 전송 | **`ok: true`** (채팅 8606266302) |

**넷 다 초록불이다. 그리고 잘린 채로 시저님께 이미 나갔다.**

잡은 것은 관문이 아니라 **리서치브레인 채점(0.6)** 이었다. 그것도 **발송 뒤에** 붙은 참고다.

> **E-190 — 「돌았나」와 「제대로 돌았나」는 다르다.**
> **E-374 — 「에러 0건」은 「옳다」가 아니다.**

그리고 ③ 이 정확히 내 E-680(검산 오염)의 사촌이다.

> **4,615바이트는 「있다」를 재지 「끝났다」를 못 잰다.**
> 바이트 수는 완결성의 측정기가 아닌데 「실재 확인」이라는 말이 붙어 확인처럼 보였다.

### ★ 그런데 이건 추정할 필요가 없다 — 값이 이미 있다

리서치브레인은 *"응답 토큰 한계로 추정"* 이라고 썼다. **추정이 아니라 읽으면 된다.**

머니엔진 응답에 **9,620토큰**이라는 값이 남았다. Claude API 응답이라면 `stop_reason` 이 함께 온다.
`"max_tokens"` 면 **잘린 것이 사실로 적혀 있다.** 추정도 채점도 필요 없다.

> **고칠 것 한 줄: `stop_reason == "max_tokens"` 면 저장·전송 전에 빨간불.**

이것이 오늘 브리핑에서 나온 가장 값싼 수리다.

## 2. E-642 가 9일 만에 같은 얼굴로 돌아왔다

오늘 표 (§3).

| 자산 | 5일 상승확률 |
|---|---|
| BTC | 53% |
| ETH | 52% |
| SK하이닉스 | 48% |
| 삼성전자 | 47% |
| KOSPI | 47% |

리서치브레인 감점 사유: *"산출 근거(표본 수) 없음 — 숫자로 포장된 주관"*

원장 **E-642** (2026-09-14):

> *「**52% 산출 근거 없음**」은 출처 없는 수다. … 돈이 걸리면 더 나쁘다:
> 출처 없는 52% 로 포지션 크기를 정하면 그 수가 자본에 곱해진다.*
> **권고: 확률을 내려면 산출식을 같이 내고, 못 내면 확률을 쓰지 말고 조건만 쓴다.**

★ **잡는 것은 두 번 다 됐다. 고치는 것이 안 됐다.**
9일 전에는 연구두뇌가 **스스로** 잡았고, 오늘은 리서치브레인이 잡았다.
**원장에 권고가 적혔는데 코드로 가지 않았다** — E-491 「만들어 뒀는데, 부르는 것이 있는가」.

### ★ 이 표는 바꿔치기 시험에 떨어진다

값의 폭이 **6%p**다 (47~53). 그리고 전부 50% 근처다.

> **BTC 53% 와 KOSPI 47% 를 서로 바꿔 놓아도 문서가 말이 된다.**

E-357·E-703 의 바꿔치기 시험 그대로다. 그리고 어제 내가 블록 #12 에 적은
㈂-① **「확신도가 변하나 — 전부 0.9 근처면 그건 확신도가 아니다」** 와 **같은 자리**다.
공교롭게도 같은 날 같은 병이 두 곳에서 나왔다.

### ★ 다만 순서는 살아 있다 — 버릴 것과 남길 것을 가른다

**BTC·ETH(정배열) > 하이닉스 > 삼성·KOSPI(역배열)**

이 순서는 §1 의 국면 판단과 정확히 일치한다. **부호는 근거가 있다.**
근거가 없는 것은 **크기(53 대 47)** 다.

> **그러므로 숫자를 버리고 순서만 남긴다.**
> 「BTC·ETH 가 국내 3종목보다 구조적 위치가 낫다 — 정배열 대 역배열」은 쓸 수 있는 문장이다.
> 「53%」는 쓸 수 없는 문장이다. **E-642 의 처방 그대로 — 못 내면 조건만 쓴다.**

머니엔진이 *"기록용, 사후 검증 목적"* 이라는 단서를 단 것은 정직했다.
**그러나 단서는 숫자를 재료로 만들지 못한다.** 표에 「표본 수」 칸이 아예 없다.
**칸이 없으면 안 적는다 — 칸을 만들면 비어 있는 것이 보인다.**

## 3. ★ 구조적 함정 — 관망만 하면 성적표는 영원히 비어 있다

보고서가 스스로 건 조건과 스스로 낸 결론이 맞물린다.

```
원칙 6번: 페이퍼 30건 미만 → 실전 제안 불가
오늘 결론: 관망 (전 종목), 비중 0%
```

**관망하면 페이퍼가 안 쌓인다. 안 쌓이면 다음 날도 실전 불가다.**
이대로면 **30건은 영원히 안 모인다.**

이것은 관문을 낮출 이유가 아니다. **관문은 그대로 두고 세는 법을 고친다.**

### 빠져나오는 길 — 무효선을 페이퍼로 센다

보고서가 이미 좋은 것을 만들어 뒀다.

| 자산 | 무효선 | 거리 |
|---|---|---|
| BTC | 108,145,000 (MA20) | -6.5% |
| ETH | 3,443,650 (MA20) | -6.8% |
| SK하이닉스 | 1,815,730 (MA60) | -2.8% |
| 삼성전자 | 259,725 (MA20) | -5.2% |
| KOSPI | 6,903,548 (MA60) | -1.5% |

★ **이것은 진입 없이도 채점 가능한 예측이다.** 5영업일 뒤 「이탈했나 / 안 했나」 — 이진값이다.
**매일 5건씩 쌓인다. 6거래일이면 30건이다.**

> **관망도 기록이 된다. 돈을 안 걸어도 틀릴 수 있으면 그것은 예측이다.**

🔴 **먼저 확인할 것 하나:** `/approve-trade` 로 기록한 **관망이 「페이퍼 30건」에 세어지는가.**
세어지면 함정이 아니다. 안 세어지면 위의 무효선 채점을 별도 원장으로 만들어야 한다.
**모르면 모른다고 두고, 뭉클이가 코드에서 확인한다.**

## 4. 잘한 것 넷 — 값으로 적는다

### ㈀ ★ 기록 0건인 시점에 국면을 미리 갈랐다

> *"상승추세(역배열 반등형)"과 "상승추세(정배열 지속형)"은 다른 국면으로 분리 기록하겠다. **섞으면 통계가 오염된다.**"*

**E-551 「분모가 다른 수를 한 문장에 묶지 않는다」를 스스로 적용했다.**
그것도 **아직 한 건도 없을 때.** 나중에 섞인 것을 푸는 것보다 압도적으로 싸다.
이것이 오늘 보고서에서 제일 잘한 대목이다.

### ㈁ ★ BTC 펀딩 — 이건 진짜 재료다

> *9/21 가격 고점(117,123,000) 시점의 펀딩이 0.0197% 로 5일 중 **최저**.
> 가격은 올랐는데 레버리지 롱 쏠림은 오히려 줄었다. 현물 주도 상승의 흔적.*

★ **가격과 레버리지가 엇갈렸다**는 관측이다. **다른 날로 옮기면 말이 안 된다 — 바꿔치기가 통하지 않는다.**
47~53% 표와 **정확히 반대 성질**이다. 같은 문서 안에 두 종류가 있다.

### ㈂ 손익비를 산출식이 보이게 냈다

> KOSPI 상단 MA120 까지 **+0.98%** / 하방 MA60 까지 **-1.49%** → **0.66:1**

분자와 분모가 다 보인다. **이것이 47% 와 다른 점이다.**

### ㈃ 관문을 낮추지 않았다

페이퍼 30건 미만이라 실전 제안이 불가능하다고 **첫 줄에** 썼다.
자율성 등급 `analyze_only` 를 맨 위에 박아 읽는 사람이 첫 줄에서 알게 했다.

## 5. 한 문서에 두 종류의 수가 있다

| 재료가 있는 수 | 재료가 없는 수 |
|---|---|
| 5일 수익률 +5.74 / +10.26 / +10.53 / +4.57 / +3.42% | |
| MA20 / MA60 / MA120 값 | **5일 상승확률 47~53%** |
| 손익비 0.66:1 (분자·분모 보임) | |
| 펀딩 0.0197~0.0275% (연 7.2~10.0%) | |
| 거래량 1,143만→2,226만주 (+95%) | |

**E-551 그대로 — 분모가 다른 수가 한 문서에 섞였다.**
그리고 잘린 문장 때문에 **독자는 어디까지가 근거인지 모른 채 끝을 맞는다.**

## 6. 작게 걸리는 것 셋

- **RSI 71** — *"극단 과열도 없음"* 이라 썼으나 통상 과매수선은 70이다. 「극단은 아니다」는 맞지만 「과열 없음」과 다르다. **어느 종목이 71인지 안 적혔다.**
- **거래량 소진** — *"소진 가능성 관찰 대상"* 이라고 적고 **무효선 표에 거래량 조건이 없다.** 관찰 대상이라 쓰고 관찰할 자리를 안 만들었다 (E-491).
- **무효선을 내일 누가 읽나** — 오늘 박은 무효선을 내일 브리핑이 다시 읽고 대조하는 자리가 보고서 안에 없다. **없으면 내일 사라진다.**
