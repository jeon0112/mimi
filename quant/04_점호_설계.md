# 점호(roll call) 설계 — **일곱 잡 전부를 하루 한 번 센다**

> 2026-09-12 · **시저님 승인 받음.** 설계는 안토니우스. 실행은 뭉클이.
> 앞 지시서: `quant/03_감시_시간판정_지시.md` (감시 판정 규율 — E-52·E-53·E-63)

---

## 0. ★★★ 먼저 — **승인은 받았고, 순서는 안 바뀝니다**

제가 어제 이렇게 썼습니다.

> *"찾기 전에 만들면 감시가 둘이 됩니다."*

★ **시저님 승인은 「만들어도 된다」이지 「지금 만들라」가 아닙니다.**
★★ **`quant_watch.py` 가 이미 돌고 있으면, 만들 일이 아니라 고칠 일입니다.**

```
① 찾는다  →  ② 있으면 고친다 / 없으면 만든다
```

> ## ★★ **승인이 왔다고 제 규율을 제가 깨면, 이 원장이 아무 소용이 없습니다.**

---

## 1. 점호가 하는 일 — **한 문장**

> ## **하루 한 번, 반복 잡 일곱이 지난 24시간에 「제 일을 했나」를 세어 한 줄로 알린다.**

★ **「퀀트를 본다」가 아닙니다.** `quant_watch.py` 는 **퀀트 데이터가 신선한가**를 봅니다.
점호는 **잡이 돌았는가**를 봅니다. **다른 물음입니다.**

| | 무엇을 묻나 | 놓치는 것 |
|---|---|---|
| `quant_watch.py` | 퀀트 데이터가 신선한가 | ★ **나라장터·코인·시구의회가 죽어도 모른다** |
| **점호** | **일곱이 다 돌았나** | 데이터 품질은 안 본다 |

★★ **둘 다 필요합니다. 겹치지 않습니다.**

---

## 2. ★★★ 원장 일곱 줄이 **전부 이 설계에 걸립니다**

**이게 이 문서의 핵심입니다.** 점호는 새 물건이 아니라 **지금까지 당한 것들의 방비**입니다.

| 원장 | 당한 것 | ★ 설계에 어떻게 거나 |
|---|---|---|
| **E-14** | 죽은 키를 쥐고 **22h46m** `Up` | **「떠 있다」를 증거로 안 쓴다** |
| **E-48** | 감시가 **옛 로그 마지막 줄**을 읽고 「정상」 | ★★ **줄이 「언제」 쓰였는지를 본다** |
| **E-49** | 크론이 **한 줄도 안 돌았다** (shebang) | 산출물이 안 바뀐 것으로 잡힌다 |
| **E-53** | 에이전트가 스스로 판단해 오판 | ★★★ **판정은 스크립트가. 잡은 전달만** |
| **E-62** | `status=completed error=None` **인데 실패** | ★★★ **실행기 대장을 믿지 않는다** |
| **E-63** | 「마지막 성공의 나이」만 재고 「마지막 시도의 결과」는 안 쟀다 | **둘 다 본다** |
| **E-67** | **0바이트 파일**이 성공의 증거가 아니다 | mtime 만 보지 않는다. **크기도 본다** |

> ## ★★★ **E-62 가 제일 무섭습니다.**
> **실행기 대장(`executions.db`)은 「돌았다」고 적혀 있는데 한 줄도 안 돌았습니다.**
> **점호가 대장을 읽으면 E-62 를 그대로 먹습니다. 대장은 증거가 아닙니다.**

---

## 3. ★★★ 판정은 **두 값이 아니라 세 값**입니다

```
✅ 정상 :  돌았다는 증거가 있다
🚨 이상 :  안 돌았다는 증거가 있다
❓ 모름 :  ★★★ 볼 것이 없다
```

★ **「모름」을 「정상」에 섞으면 E-48 이 그대로 재발합니다.**
**볼 것이 없는 것과 봤더니 괜찮은 것은 다릅니다.**

> ## ★★ **그리고 「모름」의 개수가 그 자체로 수치입니다.**
> **오늘 몇 개가 「모름」인지 세고, 그 수가 줄어드는 것을 잽니다.**
> **이 체계가 얼마나 눈이 밝아지는지를 재는 자입니다.**

---

## 4. ★★★ 「감시를 누가 감시하나」 — **침묵을 없앱니다**

점호 잡 자신이 죽으면 누가 압니까. **감시를 또 만들면 끝이 없습니다.**

### 답 — **이상이 없어도 한 줄 보냅니다**

```
✅ 09-12 점호  정상 5 · 이상 0 · 모름 2        ← 이상 없는 날에도 온다
🚨 09-13 점호  정상 4 · 이상 1 · 모름 2  (코인엔진 01:00 산출물 없음)
(아무 소리도 없음)                            ← ★★★ 이게 이상 신호다
```

> ## ★★★ **매일 오는 것을 만들어 두면, 「안 오는 날」이 경보가 됩니다.**
> **사람이 감시의 감시가 됩니다. 기계를 하나 더 만들지 않습니다.**

★ **반론이 있습니다 — 매일 ✅ 가 오면 안 보게 됩니다**(경보 피로).
★★ 그래서 **두 가지를 지킵니다** —

| | |
|---|---|
| **한 줄이어야 한다** | 길면 안 읽습니다. **정상 n · 이상 n · 모름 n** 이 전부입니다 |
| ★★ **그 줄에 날짜가 있어야 한다** | **어제 것이 다시 온 건지 알 수 있어야 합니다.** E-48 이 정확히 그 사고였습니다 |

---

## 5. 증거의 등급 — **셋**

점호가 무엇을 보고 판정하나. **단단한 순서대로** 봅니다.

| 등급 | 증거 | 판정 |
|---|---|---|
| ㈀ ★★ | **잡 자신이 쓴 줄** — 시각 + 종료코드 (`EXIT=0 ...`) | 제일 단단하다 |
| ㈁ | **산출물 파일** — ★ mtime **그리고** 크기 **그리고** 내용의 날짜 | 다음 |
| ㈂ | 아무것도 없다 | ❓ **모름** |

### ★★ ㈁ 에서 조심할 것 — **mtime 과 내용의 날짜는 다릅니다**

```
mtime      :  ★ "썼다"        ← 오늘 썼을 수 있다
내용의 날짜 :  ★★ "무엇을 썼나"  ← 사흘 전 데이터를 오늘 다시 쓴 것일 수 있다
```

★★★ **둘 다 봅니다.** E-60(주식 결손을 삼켰다)이 정확히 이 자리였습니다.

★ 그리고 **크기 0 은 성공이 아닙니다**(E-67).

---

## 6. ★★ 두 단계로 갑니다 — **한 번에 다 하지 않습니다**

### 1단계 (지금) — **있는 것을 본다**

각 잡의 **기존 산출물**을 봅니다. 볼 것이 없는 잡은 **정직하게 「모름」**.
★ 일곱 잡을 건드리지 않습니다. **읽기만 합니다. 위험이 없습니다.**

### 2단계 (나중) — **공통 줄을 만든다**

각 잡이 끝날 때 **한 줄을 공통 로그에 쓰게** 합니다.

```
/opt/data/logs/heartbeat.log
2026-09-12T21:00:26Z  45227ed5ef59  퀀트CSV갱신  EXIT=0  coin_last=2026-09-12
2026-09-12T22:03:11Z  3cabeaac7e51  주식분석     EXIT=0
```

★★ 그러면 점호는 **이 한 파일만** 읽으면 됩니다. **그리고 「모름」이 사라집니다.**
★★★ **다만 이건 일곱 잡을 전부 건드리는 일입니다. 지금 하지 않습니다.**

> ## ★★ **1단계의 「모름」 개수가 2단계를 언제 할지 알려줍니다.**
> **모름이 하나면 안 해도 됩니다. 다섯이면 해야 합니다.**

## 7. 규격

| | |
|---|---|
| **이름** | ★ **`[매일] 점호`** — once 가 아님이 이름에 보이게 (E-203 의 짝) |
| **시각** | **02:00 UTC** (KST 11:00). 마지막 잡(코인 01:00) 뒤 **1시간 여유** |
| **보는 창** | **지난 24시간** — 전날 02:00 ~ 오늘 02:00 |
| **창에 드는 잡** | 21:00 · 22:00 · 23:00 · 23:30 · 00:00 · 00:00 · 01:00 **+ 전날 05:00** ✅ **여덟 전부** |
| **판정** | ★★★ **스크립트가 한다.** 잡은 종료코드와 문구를 **전달만** 한다 (E-53) |
| **출력** | **한 줄** — `✅ 09-12 점호  정상 5 · 이상 0 · 모름 2` + 이상·모름은 잡 이름 |
| **이상 없어도** | ★★★ **보낸다.** 안 오는 날이 경보다 |
| **되돌리기** | **잡 하나 삭제.** 다른 잡을 건드리지 않으므로 **위험 없음** |

---

## 8. ★★★ 지금 모르는 것 — **그래서 조사가 먼저입니다**

**정직하게 씁니다.**

> ## **저는 일곱 잡이 각각 무엇을 남기는지 모릅니다.**
> **모르면 판정 기준을 쓸 수 없습니다. 지어내면 E-177 입니다.**

조사할 것 둘 —

```
① quant_watch.py 를 지금 누가 돌리나        ← 어제 지시한 것
② ★ 일곱 잡이 각각 무엇을 남기나            ← 새로 더한 것
   (로그 줄 / 산출물 파일 / 아무것도 없음)
```

★★ **둘 다 「찾기」입니다. 한 번에 합니다.** 그러면 다음 회차에 바로 만들 수 있습니다.

---

## 9. ★ 그리고 점호도 **예측을 먼저 적습니다**

첫 실행 전에 적습니다 — **일곱 중 몇이 「모름」일 것 같은가.**

★★ 지금까지 어림은 **6/6 과대**였습니다(E-199). **그러니 보정을 겁니다.**
★★★ 그리고 이번엔 **「어림」인지 「앎」인지 표시합니다**(E-200).

> **점호를 만드는 일 자체가 월드 모델 고리의 다음 바퀴입니다.**
