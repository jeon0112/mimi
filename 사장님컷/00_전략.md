# 사장님 컷 — 전략과 시범 운영

> 서비스 이름 **「사장님 컷」**(시저님 결정 2026-09-26). 원래 가칭 「사장님 1인칭 콘텐츠 공장」.
> **정체 정정(E-1115)**: 공장이 아니라 **실험실**이다 — 장인으로 레시피를 얻고, 그 레시피로 공장을 세운다.
> 1단계 치밀한 설계는 **`01_설계.md`**. 이 문서의 §5(시범 운영)는 그 설계로 대체된다.

## 0. 패러다임 — 광고의 독자가 사람에서 AI 로 바뀐다 (E-1112)

시저님: *"서비스는 흔하다. 관건은 퀄리티와 배포의 마케팅 역량. AI 전용 광고 같은 패러다임 변화가 필요하다."*

| | 어제의 광고 | 사장님 컷 |
|---|---|---|
| 독자 | 사람 | **AI**(네이버 플레이스 에이전트·AI 브리핑·챗GPT·제미나이·안경 속 비서) |
| 싸움 | 눈에 띄기 | **AI 가 고르게 하기** |
| 재료 | 예쁜 사진·문구 | **증거**(1인칭 작업 영상) + **AI 가 읽는 사실**(메뉴·영업·재료·과정) |
| 성적표 | 조회수 | **AI 추천 점유율** — "광주 ○○동 빵집 추천"에 우리 가게가 나오나 |

- **이미 시작됐다(실측)**: 네이버 「플레이스 에이전트」(2026-09-17) — 대화로 장소를 추천하고 예약까지. 주소·영업시간·메뉴·방문자 리뷰·**블로그 후기**·예약 가능 여부를 읽는다. 「AI 브리핑」은 여러 웹 문서를 읽고 출처와 함께 요약한다.
- **AI 는 가게가 직접 관리하는 곳을 가장 많이 인용한다(해외 조사, 참고)**: Yext 680만 인용 분석 — 86%가 브랜드 관리 출처(웹사이트 44%·업체 정보 42%), 구조화된 정보가 작은 브랜드 노출을 36% 늘렸다.
- **안경 시대에 더 날카로워진다**: 스마트폰 검색은 열 곳을 보여 준다. **안경 속 AI 는 귀에 한 곳만 말한다.** 그 한 곳이 되는 싸움이다.
- **세 겹 제품**: ①증거 콘텐츠(일하는 모습 → 한국 채널) ②AI 가 읽는 가게 카드(사실만, 모든 채널 일관, 나중엔 에이전트 커넥터 — E-760·E-776) ③AI 추천 점유율 측정(사장님이 체감하는 새 성적표이자 영업 도구).
- **지어내지 않는 것이 무기다**: AI 는 여러 출처가 서로 맞는 사실을 믿는다. 가짜 후기·과장은 AI 앞에서 오히려 깎인다(가설). 이 저장소의 원장 규율이 그대로 제품 철학이 된다.

> 2026-09-26 · 시저님 결정, 안토니우스 정리. 근거 `proposals/LEDGER.md` E-1103 ~ E-1110.
> 이 문서는 **전략 모드** 문서다(E-1106). 「가설」 딱지가 붙은 것은 확인 전이다.
> 여기서 지원사업 계획서·투자 자료로 옮겨 갈 때는 가설을 전부 실측으로 바꾼 뒤에만 쓴다.

## 1. 한 줄

**일하는 모습이 곧 광고가 된다.**
사장님이 평소처럼 일하면, 그 1인칭 영상이 한국 채널(네이버·당근·카카오·스마트스토어)에
맞는 마케팅 콘텐츠로 바뀌어 올라간다.

## 2. 왜 이 자리인가

| | |
|---|---|
| 판 | 메타 안경 한국 정식 판매(2026-05-25~). 외부 앱 공개 배포는 아직 닫힘 — **지금은 준비 기간** |
| 제3지대 | 거인은 가로축(메신저·검색·커머스)을 가져간다. 남는 칸은 **업종별 · 한국 채널별 · 동네별** |
| 급소 | 모든 사장님이 콘텐츠가 필요한데 찍을 시간이 없다. 안경은 일하는 동안 저절로 찍는다 |
| 심장 | **시저님 마케팅.** 편집 도구는 흔하다. 「무엇을 어떻게 올려야 손님이 오나」가 희소하다 |
| 메타가 못 하는 이유 | 메타는 자기 집(인스타·페북)으로만 보낸다. 한국 사장님 손님은 네이버·당근·카카오에 있다 |
| 메타 문에 안 묶인다 | 안경 영상은 메타 AI 앱으로 폰에 넘어온다(가설 — 확인 필요). 폰으로 찍어도 돈다 |

## 3. 돈 흐름

- **소진공 「스마트상점 기술보급사업」** — 국비 70%, S/W 소상공인형·렌탈형 있음, S/W·렌탈 지원기간 최대 2년(실측, 2026 공고).
  2026 기술공급기업 모집은 1월에 끝났다 → **2027 모집(1월 추정)이 전술 시한.**
- 월 구독(가격 가설) · 안경 렌탈 번들(도소매·전자상거래) · 사장님 AI 마케팅 교육(AI 교육).
- 공급기업 신청 요건(업력·인증·실적)은 **확인 필요** — 12월 전에 공고 원문으로 대조.

## 4. 플라이휠 (비전)

사장님 콘텐츠 → 매출(사장님이 남는다) → **동의 받은 한국인 1인칭 작업 영상 축적** → 피지컬 AI 학습 재료.
동의·비식별은 **1일차 설계**에 넣는다. 나중에 붙이면 이미 모은 것을 못 쓴다.

## 5. 시범 운영 — 「앱보다 서비스 먼저」

**앱을 먼저 만들지 않는다.** 사람 + 뭉클이가 손으로 서비스를 돌려서
「사장님 매출이 움직이는가」를 먼저 잰다. 움직이면 그 손작업을 앱으로 옮긴다.
안 움직이면 앱 개발비를 아낀 것이다.

### 5-1. 참여 매장 — 4업종 × 3곳 = 12곳 (시저님 모집)

| 업종 | 1인칭 장면 예 | 주 채널(가설) | 주의 |
|---|---|---|---|
| 빵집 | 반죽·굽기·진열 | 인스타·당근·플레이스 | — |
| 꽃집 | 꽃다발 묶기·포장 | 인스타·블로그·스마트스토어 | — |
| 미용실 | 시술 과정·완성 | 인스타·블로그 | **손님 얼굴 — 매 건 손님 동의, 없으면 뒷모습·손만** |
| 식당 | 조리·플레이팅 | 플레이스·블로그·당근 | 주방 위생 장면 노출 주의 |

### 5-2. 흐름 (0단계, 손작업)

```
사장님이 폰(또는 안경)으로 일하는 모습을 찍는다
  → 정해진 통로로 보낸다 (카카오톡 채널 또는 공유 폴더 — 확정 필요)
  → 뭉클이: 업종별 틀로 숏폼 자막·블로그 글·플레이스 소식·당근 문구 초안
  → 사람 검수 (지어낸 후기·가짜 할인·과장 표현 금지)
  → 사장님 승인
  → 게시 (처음엔 사장님이 직접 올리거나 대행 — 채널별 자동 게시 가능 여부 확인 필요)
```

### 5-3. 재는 것 — 조회수가 아니라 손님

| 지표 | 어디서 | 비고 |
|---|---|---|
| 게시 수 · 사장님 소요 시간 | 운영 기록 | 「사장님 시간 0분에 가깝게」가 목표 |
| 조회·저장 | 각 채널 통계 | 보조 지표 |
| **전화·길찾기·문의** | 네이버 플레이스 통계 등(가설 — 매장별 확인) | **주 지표** |
| **신규 손님 체감** | 사장님 주 1회 한 줄 | 주 지표 |
| **AI 추천 점유율** | 고정 질문("광주 ○○동 빵집 추천")을 여러 AI 에 주 1회 — 우리 가게 언급 여부·순서 | **새 성적표.** 네이버 플레이스 에이전트는 사람이 손으로 잴 수 있음 |

**기준선 2주(지금 상태) → 서비스 4주 → 전후 비교.** 기준선 없이 시작하면 좋아졌는지 모른다.

| 9/28 ~ 10/4 | 동의서 · 업종별 콘텐츠 틀 · 측정표 · 12곳 모집 |

### 5-5. 처음부터 지킬 것

- **사장님 동의서** — 콘텐츠 이용 / (별도 항목) 향후 학습 데이터 활용.
- **손님 얼굴** — 동의 없으면 흐림 처리 또는 제외. 매장에 촬영 고지.
- **지어내지 않는다** — 가짜 후기·없는 할인·과장 효능 금지. 이게 오래 가는 브랜드의 차이다.

## 6. 위험

| 위험 | 대응 |
|---|---|
| 메타가 인스타 자동 편집을 직접 한다 | 쐐기는 한국 채널 동시 발행 + 업종별 전략. 인스타 단독 경쟁은 안 한다 |
| 채널별 자동 게시 통로가 막혀 있다 | 0단계는 사람이 올린다. 자동화는 확인된 채널부터 |
| 매출 변화가 4주에 안 보인다 | 주 지표를 문의·전화·길찾기로 잡아 선행 신호를 본다 |
| 사장님이 찍어 보내는 것 자체를 귀찮아한다 | 그게 바로 안경이 풀 문제 — 셋째 주 안경 투입으로 비교 |
| 메타 앱 공개 배포가 늦다 | 폰으로 도는 설계라 막히지 않는다 |

## 7. 시저님 결정 (2026-09-26)

1. **「앱보다 서비스 먼저」 — 동의.**
2. 영상 통로 — **카카오 또는 텔레그램.** 텔레그램 수신 봇은 경보 봇·대화 봇과 **분리**(E-1094: 같은 방에 섞이면 묻힌다).
3. 이름 — **「사장님 컷」.**
4. 안경 — **지금 사지 않는다.** 시저님: *"관건은 퀄리티와 배포 마케팅. 그게 좋으면 안경에서 엄청난 시너지를 낸다. 그때 결정해도 늦지 않다."* → §5-4 셋째 주 안경 투입은 **삭제**, 서비스 성과가 확인된 뒤 결정.
