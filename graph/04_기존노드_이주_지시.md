# 뭉클이 지시 — 기존 Agent 노드 6개를 문으로 들여보낸다

> 2026-09-10 · 안토니우스 · 2차 시험 g) 에서 드러난 것 (E-38)
> **원장 적재보다 먼저 한다.**

---

## 무엇이 드러났나

2차 시험 `g)` 가 결함 하나를 잡았다. 그런데 그것보다 큰 것이 함께 나왔다.

```
Agent 6 / Evidence 0 / 관계 0     ← 며칠째 「정상」으로 확인해 온 숫자
```

그 6개에 **`key` · `source` · `asserted_by` · `confidence` 가 하나도 없다.**

> **문을 세우기 전에 들어온 것은 문을 통과하지 않았다.**
> 그리고 문을 세운 뒤에는 그것들이 **정상처럼 보인다.**

## 왜 원장 적재보다 먼저인가

두 가지다.

**① 지금 문에 임시 다리가 걸려 있다.**
`Agent` 를 `key` **또는** `name` 으로 찾는다. 이건 이주용 다리지 완성형이 아니다.
다리를 놔둔 채 35건을 부으면 부채가 커진다.

**② 6건은 35건보다 안전하다.**
문의 첫 실전으로 알맞은 크기다. 여기서 어긋나면 6개만 되돌리면 된다.

---

## ★ 함정 — 그냥 부르면 노드가 12개가 된다

```
assert_node("Agent", "hermes", …)
  → MERGE (key="hermes")
  → key 없는 기존 노드와 안 맞음
  → 새로 만든다
  → Agent 12개
```

**뭉클이가 넣은 다리(`key` 또는 `name`)가 바로 이걸 막는다.**
임시방편으로 쓰고 버릴 게 아니라 **이주 경로로 쓴다.**
다리는 건너간 뒤에 걷는다.

---

## 지어내지 않는다

넣을 값은 **이미 그래프 안에 있는 것**이다. 새로 만드는 게 아니라 옮기는 것이다.

| key | role | location |
|---|---|---|
| `hermes` | 오케스트레이터 | vps |
| `agent-radio` | 교환대 | vps |
| `research-brain` | 박사 | vps |
| `content-factory` | 작가 | vps |
| `money-engine` | 수도승 | vps-격리 |
| `limb` | 로컬 팔 | local-pc |

- `source` = `Neo4j 기존 Agent 노드 (2026-09-09 뭉클이 조사)`
- `asserted_by` = `뭉클이`
- `confidence` = **`기록`** — 실측이 아니다. 기존 노드에 적혀 있던 값을 옮기는 것이다

★ `실측` 이 아닌 이유를 새겨라. **누가 언제 왜 그렇게 적었는지 우리는 모른다.**
  나중에 코드를 읽어 확인하면 그때 `실측` 으로 **승격**하면 된다.
  2차 시험 `i)` 가 그 길이 열려 있음을 확인했다.
