# 배수관 연결 — 뭉클이를 Neo4j 네트워크에 붙인다

> 2026-09-09 · 2순위(`assert_node`/`assert_edge`)의 **전제조건**
> E-32 에서 밝혀진 것: 그래프는 「나중에 좋은 것」이 아니라 **기억의 배수구**다.
> 배수구를 만들기 전에 **배수관**이 연결돼야 한다.

---

## 이 단계의 계율

```
한 번에 하나만 바꾼다. 붙는 것까지만 하고 멈춘다.
```

함수는 다음 단계다. 지금은 **붙었는지만** 본다.

---

## 왜 시저님이 직접 하셔야 하는가

`docker network connect` 는 **호스트에서** 실행해야 한다.
뭉클이 컨테이너에는 `/var/run/docker.sock` 이 없다 — **없는 게 맞고, 앞으로도 없다.**

그러니 ①은 뭉클이 일이 아니라 **시저님 터미널 일**이다.

---

## ① 붙이기 — 🐧 VPS 셸에서 (한 줄씩)

**먼저 창 확인** (PowerShell 과 헷갈리지 않기 위해):

```
hostname
```

VPS 이름이 나오면 계속. 아니면 SSH 부터 다시.

**붙이기:**

```
docker network connect mungkle_factory hermes-vps
```

아무것도 출력되지 않으면 **성공**이다. (도커의 습관이다)

> **안전한가** — 그렇다.
> · 컨테이너를 **재시작하지 않는다**
> · 기존에 붙어 있던 네트워크는 **그대로 유지**된다. 추가로 하나 더 붙는 것이다
> · Neo4j 의 `127.0.0.1` 바인딩은 **건드리지 않는다.** 그건 그대로 둔다

이미 붙어 있으면 `already exists in network` 가 나온다. 그것도 성공이다.

---

## ② 확인 — 🐧 VPS 셸에서 (한 줄)

```
docker network inspect mungkle_factory --format '{{range .Containers}}{{.Name}} {{.IPv4Address}}{{println}}{{end}}'
```

**보고 싶은 것:** 목록에 `hermes-vps` 가 있고, Neo4j 컨테이너도 함께 있는 것.
Neo4j 는 `172.16.3.2` 로 확인돼 있다.

이 출력을 그대로 안토니우스에게 주시면 된다.

---

## ③ 뭉클이에게 — 붙었는지 확인만

②까지 되고 나서 보낸다.

```
[뭉클이 — Neo4j 도달 확인]

■ 누가 말하는가
  안토니우스(설계). 시저님이 방금 호스트에서 네트워크를 붙이셨다.

■ 성격
  확인만이다. 붙었는지 본다. 아무것도 쓰지 않는다.

■ 하지 말 것
  · Cypher 로 데이터를 쓰지 마라 (아직 assert_node/assert_edge 가 없다)
  · 노드를 만들거나 지우지 마라
  · Neo4j 설정을 바꾸지 마라
  · 비밀번호 값을 출력하지 마라 ★

■ 답할 것 — 셋

  1) TCP 가 닿는가
     172.16.3.2 의 7687 포트에 도달하는지만 본다. 인증은 하지 않는다.
     닿는다 / 안 닿는다 와, 쓴 명령을 함께 적어라.
     ★ 이걸 먼저 하는 이유 — 「네트워크가 안 붙었다」와 「비밀번호가 틀렸다」는
       완전히 다른 문제다. 섞으면 지난번처럼 또 헤맨다.

  2) Neo4j 컨테이너 이름으로도 닿는가
     IP 말고 이름으로 붙을 수 있으면 IP 가 바뀌어도 안 깨진다.
     같은 네트워크의 컨테이너 이름을 확인하고, 그 이름으로도 7687 에 닿는지 봐라.
     이름을 모르겠으면 "모르겠다"고 써라.

  3) 비밀번호를 읽을 수 있는 경로가 컨테이너 안에 있는가
     ★★ **값은 절대 출력하지 마라. 「있다/없다」와 「경로」만 적어라.**
     없으면 없다고 써라. 그게 정확한 보고다.
     ※ 호스트의 /root 아래는 컨테이너에서 읽을 수 없다 (0700).
       읽으려고 시도하지 마라. 우회하지 마라.

■ 보고 형식
  세 항목 번호 그대로. 명령과 출력을 함께.
  확인 못 한 것은 "확인 못 함".

■ 막히면
  "제 권한 밖입니다"라고 써라. 다른 길을 찾지 마라.
```
