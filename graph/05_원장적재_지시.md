## ★ 안토니우스가 미리 잰 것 — 함정 넷

**무턱대고 파싱하면 오염된다.** 원장 표는 한 가지 모양이 아니다.

| 열 수 | 몇 건 | 무엇 | 처리 |
|---:|---:|---|---|
| **6열** | **32** | 정식 근거 행 | **이것만 적재한다** |
| 4열 | 6 | E-11·12·13·16·19·20 — 「필요한 근거 / 어떻게 잰다 / 상태」 | **넣지 않는다** |
| 3열 | 4 | E-25·26·27·29 가 산문 요약표에 **다시** 나온다 | **넣지 않는다** |

**왜 4열을 넣지 않는가** — 그건 근거가 아니라 **아직 재지 않은 계획**이다.
`confidence` 가 없다. 억지로 붙이면 그게 지어내는 것이다.
재고 나면 그때 6열 행이 되고, 그때 넣는다.

**왜 3열이 위험한가** — 같은 번호가 두 번 나온다.
순서대로 밀어 넣으면 **나중 것이 앞 것을 덮는다.**
그리고 3열이라 `confidence` 자리에 엉뚱한 글자가 들어간다.
E-23(결손 1행이 전 지표를 NaN 으로)과 **같은 종류의 사고**다.

> **→ 규칙 하나로 셋이 다 걸러진다: 열이 정확히 6개인 행만 읽는다.**

**넷째 — E-21 은 방금 고쳤다.**
산문에는 「E-21 (지뢰)」가 있는데 표 행이 없었다. 우리 규칙 위반이다
(*가리킬 행이 없으면 그 문장은 쓰지 않는다*). 행을 추가했으니 32건이다.

### 값 분포 (미리 확인함)

```
confidence:  실측 21 · 기록 11        ← 전부 허용값. 추정은 없다
```

## 열 대응

```
| E-01 | 무엇을 발견했나 | 값 | 근거유형 | 출처 | 날짜 |
   ↓         ↓            ↓      ↓        ↓      ↓
  key      finding      value  confidence source  observed_at
```

| 함수 인자 | 어디서 |
|---|---|
| `label` | `Evidence` 고정 |
| `key` | 1열 (`E-01` …) |
| `props` | `finding`(2열) · `value`(3열) · `observed_at`(6열) |
| `confidence` | **4열 그대로.** 바꾸지 마라 |
| `source` | 5열 + `" / proposals/LEDGER.md"` |
| `asserted_by` | `뭉클이` |

★ **`confidence` 를 네가 판단하지 마라.** 원장이 이미 정했다.
  「이건 실측 같은데」라고 고치면 그 순간 원장과 그래프가 갈라진다.

## 관계 — 안토니우스가 목록으로 준다

원장 표에는 관계가 없다. **산문에 있다.**
그걸 네가 읽어내면 그건 **해석**이고, 해석은 지어내기에 가깝다.

**그래서 여섯 건만 준다. 이것만 걸어라.**

| from | 관계 | to | 근거 (원장에 적힌 말) |
|---|---|---|---|
| E-24 | `DERIVED_FROM` | E-23 | E-24 행: *"NaN 을 고치자 드러남"* |
| E-33 | `DERIVED_FROM` | E-27 | E-33 행: *"「Neo4j 접속 불가」는 네트워크 문제가 아니었다"* |
| E-26 | `SAME_KIND_AS` | E-25 | 산문 「부재를 고장으로 착각한다」 |
| E-27 | `SAME_KIND_AS` | E-25 | 〃 |
| E-29 | `SAME_KIND_AS` | E-25 | 〃 (네 번째) |
| E-37 | `SAME_KIND_AS` | E-25 | 〃 (다섯 번째) |

- `source` = `proposals/LEDGER.md 산문 (안토니우스 지정 2026-09-09)`
- `asserted_by` = `안토니우스`
- `confidence` = `기록`

**나머지는 걸지 않는다.** 걸 만해 보여도 걸지 마라.
애매한 것을 걸면 나중에 어느 선이 확실한 것인지 구분이 안 된다.
**적게 걸고 확실하게 거는 편이 낫다.**

## 이것이 끝나면 물어볼 수 있게 되는 것

```
「부재를 고장으로 착각」 계열에 몇 건이 있나        → E-25 로 들어오는 SAME_KIND_AS 를 센다
E-23 을 고치자 무엇이 드러났나                     → DERIVED_FROM 을 거슬러 올라간다
확인 안 된 근거(추정)가 몇 건인가                  → confidence 로 센다
```

**이게 표로는 못 하고 그래프로만 되는 것이다.**
「비슷한 것」이 아니라 **「연결된 것」**을 보려고 그래프를 골랐다.
