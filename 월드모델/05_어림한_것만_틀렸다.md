뭉클이가 이렇게 썼습니다.

## 3. ★★★ 그런데 **왜 하나는 맞고 하나는 틀렸나** — 갈래가 깨끗합니다

오늘까지 나온 예측 전부를 한 줄에 놓아 봅니다.

| 누가 | 무엇을 | 결과 | ★ 어디서 나온 수인가 |
|---|---|---|---|
| 안토니우스 | 설치시간·디스크·RAM·1만step·step/초 | ❌ **5/5 과대** | **어림** |
| 뭉클이 | 총 잡 수 15~20 | ❌ 과대 | **어림** |
| 뭉클이 | 학습 감싸개 10~30배 | ❌ 과대 (실제 4.7배) | **어림** |
| ★★ 뭉클이 | **once 3~4개** | ✅ **맞음** | ★★★ **자기가 만든 것. 아는 것** |

> ## ★★★ **어림한 것은 전부 과대. 아는 것은 맞았다.**
> **일곱 중 여섯이 어림이었고 여섯 다 틀렸습니다. 하나가 앎이었고 맞았습니다.**

### ★★ 그리고 방향이 하나입니다 — **저와 뭉클이가 같은 쪽으로 틀립니다**

★ 이건 개인의 버릇이 아닙니다. **둘 다 무거운 이름에 큰 수를 붙입니다**(E-178).
*「물리 시뮬레이터」* · *「크론 잡들」* · *「PPO 학습 루프」* — 전부 무겁게 들립니다.

> ## ★★★ **그러면 규칙이 나옵니다.**
> **① 예측을 쓸 때 「어림」인지 「앎」인지 표시한다.**
> **② 「어림」에는 보정을 건다 — 지금까지 6/6 과대였으니 낮춘다.**
> **③ 「앎」이면 근거를 한 줄 댄다(내가 만들었다 / 로그에서 봤다).**

★★ **이게 고리를 닫는 구체적인 방법입니다**(E-190 이 물은 바로 그것).

## 4. 학습 포함 step/초 — **수는 좋고, 이름을 정확히 붙입니다**

```
물리만 (mj_step)   :  619,504 step/초
학습 포함          :  132,655 step/초
비                 :  ★ 4.7배
```

★ **재현성이 확인됐습니다** — 진자 물리만: 어제 **598,282** · 오늘 **619,504**. **차이 3.5%.**
**같은 자로 재니 같은 답이 나옵니다.** 작지만 이게 0번 자 검사의 정신입니다.

### ★★★ 다만 **이 수의 이름은 「학습 포함」이 아닙니다**

뭉클이가 **스스로 한계를 밝혔습니다** — 좋은 줄입니다.

> *"numpy 수작업 신경망(3→32→1 소형) 기준이고, 실전 PPO(큰 네트워크+GAE+클리핑+미니배치)는 이보다 무겁습니다.
> 진짜 PPO 를 붙인 수는 아직 모릅니다"*

★★ **그러니 원장에 이렇게 적습니다.**

```
✅ "numpy 수작업 3→32→1 신경망 포함 시 4.7배"
❌ "학습 포함 4.7배"       ← ★★★ 이렇게 적으면 한 달 뒤 이 수를 PPO 수로 쓴다
```

> ★★★ **이름을 크게 붙이면 나중에 크게 쓰입니다.** E-125(「있다」는 개수가 아니다)와 같은 자리입니다.

★ 그리고 **지금은 여기까지가 맞습니다.** 제가 *「pip 로 큰 패키지를 더 깔지 마라」* 고 했고 뭉클이가 지켰습니다.
**진짜 PPO 수는 미뤄둔 것에 넣습니다.**

## 6. 시저님께 — **결정 하나 여쭙니다**

★ 뭉클이가 정확히 짚었습니다 — *"밤 확인이 상시 필요하다면 그건 새로 만들어야 할 잡이고, 그건 시저님 승인 자리입니다"*

### 지금 상태

**반복 잡이 일곱 개 돕니다**(하나는 일부러 꺼둠). **그리고 그 일곱이 돌았는지 매일 보는 것이 없습니다.**

★★ 이 원장의 첫 줄부터 반복된 모양이 정확히 그것입니다 —

```
E-14  :  죽은 키를 쥐고 22시간 46분 Up
E-49  :  크론이 한 줄도 안 돌았는데 대장엔 성공
E-62  :  executions.db status=completed  error=None   ← ★ 실패가 성공으로 적혔다
```

> ## ★★★ **감시의 요점은 「퀀트를 본다」가 아니라 「일곱이 다 돌았나」입니다.**
> **잡 하나가 조용히 죽으면 지금은 아무도 모릅니다.**

### 제 권고 — **점호(roll call) 잡 하나**

| | |
|---|---|
| **무엇** | 하루 한 번, **반복 잡 일곱 개가 지난 24시간에 돌았는지** 확인해 한 줄로 알린다 |
| **언제** | 마지막 잡(코인 01:00)이 끝난 뒤 — **02:00 UTC** 쯤 |
| **어떻게** | ★ 판정은 **스크립트가** 한다. 잡은 결과만 전달한다 (**E-53 에서 이미 정한 규율**) |
| **왜 하나로** | ★★ 감시를 여럿 두면 **감시를 감시할 것**이 필요해진다. 하나면 그 하나만 보면 된다 |
| **되돌리기** | 잡 하나 삭제. **위험이 없습니다** |

★ **다만 만들기 전에 1순위(`quant_watch.py` 가 지금 누가 돌리나)를 먼저 알아야 합니다.**
**이미 도는 것이 있으면 새로 만들 게 아니라 고칠 일입니다.**

> ★★★ **순서: ① 찾는다 → ② 시저님께 여쭌다 → ③ 만든다.**
> **찾기 전에 만들면 감시가 둘이 됩니다.**
