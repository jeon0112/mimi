# 참조 음성 녹음 가이드

> 시저님 목소리로 더빙하기 위한 참조 음원. **엔진과 무관하게 조건은 같다.**
> 이 폴더에 녹음 파일을 넣지 마라 — 저장소는 Public 이다 (`.gitignore` 에 이미 막혀 있다).

---

## 1. 조건

| | |
|---|---|
| 장소 | 조용한 방. **에어컨·선풍기·공기청정기를 끈다.** 창문을 닫는다 |
| 시간 | 밖이 조용한 때. 낮보다 늦은 저녁이 낫다 |
| 마이크 | 있는 것 중 제일 나은 것. 스마트폰도 된다 |
| 거리 | 입에서 **한 뼘.** 처음부터 끝까지 같은 거리를 유지한다 |
| 각도 | 입 정면을 살짝 비껴 놓는다 (ㅍ·ㅂ 발음의 바람 소리를 피한다) |
| 저장 | **WAV 또는 무압축.** MP3 로 저장하지 않는다 |

### 반드시 지킬 것 두 가지

**하나 — 시작 전에 3초 동안 아무 말 없이 녹음한다.**
그 3초가 방의 소음이 어떤 것인지 알려주는 표본이 된다. 나중에 그걸로 잡음을 지운다.
말부터 시작하면 이 표본을 못 만든다.

**둘 — 카카오톡·문자로 보내지 않는다.**
전송 과정에서 압축되어 음질이 깎인다. 깎인 음원으로 만든 클론은 되돌릴 수 없다.
파일 그대로 VPS 로 올린다 (아래 §4).

---

## 2. 톤

**평소 설명하실 때처럼 읽는다.** 아나운서 흉내를 내지 않는다.

- 우리가 만들 것은 **강의 낭독**이다. 뉴스도 광고도 아니다
- 감정을 싣지 않는다. 담담하고 고르게
- 너무 천천히 읽지 않는다. 평소 말하는 속도
- 문장 끝을 흐리지 않는다. 끝까지 또렷하게

**틀리면 그 문장만 다시 읽는다.** 처음부터 다시 하지 않는다.
틀린 자리에서 **3초 쉬고** 그 문장을 다시 읽으면, 나중에 앞엣것만 잘라내면 된다.

---

## 3. 읽을 글

아래를 순서대로 읽는다. 3분 안팎이 나온다.
**더 필요하면 한 번 더 읽는다.** 같은 글을 두 번 읽어도 괜찮다.

```
안녕하세요. 오늘은 돈이라는 것이 어떻게 생겨났는지 이야기해 보겠습니다.

사람들은 오래전부터 무언가를 주고받았습니다. 소금 덩어리를 쓴 곳도 있었고,
조개껍데기를 쓴 곳도 있었습니다.

값을 매긴다는 것은 서로가 같은 기준을 믿는다는 뜻입니다.
그 믿음이 깨지면, 아무리 반짝이는 것도 값을 잃습니다.

은행이라는 것도 처음부터 은행이었던 것은 아닙니다.
금을 맡아 두던 사람들이 영수증을 써 주면서 시작되었습니다.

블록체인, 비트코인, 스테이블코인 같은 말이 요즘 자주 들립니다.
낯선 말처럼 들리지만, 묻고 있는 것은 옛날과 같습니다.
누가 기록을 관리하느냐 하는 것입니다.

숫자를 하나 읽어 보겠습니다.
천구백칠십일 년, 이천구 년, 그리고 이천이십육 년입니다.
백사십오만 원, 삼점 일사 퍼센트, 열두 시 삼십 분입니다.

짧은 문장도 읽겠습니다.
그렇습니다. 아닙니다. 잠깐만요. 다시 말씀드리겠습니다.

이제 조금 긴 문장을 읽겠습니다.
어떤 제도가 오래 버티는 이유는 그것이 완벽해서가 아니라,
그것을 대신할 만한 것을 아직 아무도 만들지 못했기 때문인 경우가 많습니다.

끝으로 발음이 까다로운 말들을 읽겠습니다.
깻잎, 꽃밭, 넓적하다, 밟히다, 읊조리다, 희망, 의사, 예의,
값어치, 삯, 닭갈비, 맑다, 옳지 않다.

여기까지입니다. 고맙습니다.
```

**왜 이 글인가**

- 실제로 더빙할 내용(화폐·은행·블록체인)의 어휘가 들어 있다.
  클론이 이 말들을 편하게 발음하게 된다
- 긴 문장과 짧은 문장, 숫자, 겹받침이 고루 들어 있다
- 남의 글이 아니다. 저작권 문제가 없다

## 4. 파일 보내는 법

**대화창에 올리지 않는다. 카톡으로 보내지 않는다.**

```powershell
scp "녹음파일경로.wav" root@145.79.8.136:/root/jarvis-cloud/hermes-data/voice_ref/
```

받는 자리를 미리 만들고 권한을 좁힌다 (VPS 에서).

```bash
mkdir -p /root/jarvis-cloud/hermes-data/voice_ref
chown -R 10000:10000 /root/jarvis-cloud/hermes-data/voice_ref
chmod 700 /root/jarvis-cloud/hermes-data/voice_ref
```

**클론 모델과 이 원본 녹음은 VPS 밖으로 나가지 않는다.**
저장소에 커밋하지 않고, 외부 서비스에 올리지 않는다.
음성 클론은 그 자체가 사칭 도구다 (`03_뭉클이_합성_지시.md` §0).
