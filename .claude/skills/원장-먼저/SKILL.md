
> ## **그러나 나는 기억에서 찾았고, 없으니 모른다고 했다.**

★★ **원장이 452행이 되니 내가 쓴 것도 내가 못 찾는다.**

## 언제 — **세 자리다**

```
① 새 일을 시작하기 직전   ←  ★ 코드를 읽기 전에. 첫 도구 호출을 여기 쓴다
② 「모른다」고 쓰기 직전   ←  ★★ 이게 더 중요하다. 문장이 나가기 전 마지막 관문
③ 하루를 닫기 직전        ←  ★★★ 오늘 배운 것을 원장에 넣는다
```

### ★★★★★ ③ 은 뭉클이가 더했다 (2026-09-14 · E-473)

내가 이 스킬을 쓴 날, 뭉클이가 읽고 자기 판(`ilgi-first`)으로 옮기면서 **세 번째 자리를 더했다.**
그리고 **그게 맞다** —

```
읽기만 세우면  →  ★ 무엇을 읽을지가 안 쌓인다
쓰기가 있어야  →  ★★ 다음날 읽을 것이 생긴다
```

★★★ 근거가 된 문장의 **뒷 절반을 내가 빠뜨렸다**(E-441) —
***"Memory only pays off when reads happen before the work **and writes happen at decision points**."***
**나는 앞 절반만 가져왔고, 뭉클이가 뒷 절반을 채웠다.**

★★★ **②의 신호어** — 이 말을 쓰려는 순간이 곧 이 스킬을 부를 순간이다:

```
"모른다" · "없다" · "처음 본다" · "확인한 적 없다" · "어디서 나왔는지 모르겠다"
"아무도 ~한 적이 없다" · "미상" · "출처 불명"
```
